# 네이버 블로그 글쓰기 규칙 (검색 노출용)

네이버 검색은 블로그의 주제 전문성과 꾸준함(C-Rank), 글 자체의 경험·정보 품질(D.I.A+)을 본다.
키워드를 많이 넣는 것보다 **직접 경험한 내용과 구체적인 정보**가 중요하다.

## 제목
- 메인 키워드를 앞쪽에 넣는다. 예: "비트코인 볼린저 밴드 스퀴즈, 11월 7일 차트 점검"
- 25~35자. 특수문자 남발이나 낚시성 표현("충격", "무조건")은 쓰지 않는다.
- 같은 제목을 반복해서 쓰지 않는다 (유사 문서로 판정될 수 있다).

## 본문
- 분량은 1,500~3,000자. 짧으면 정보가 부족하다고 보고, 지나치게 길면 이탈이 늘어난다.
- 메인 키워드는 본문에 자연스럽게 4~7회 넣는다. 첫 문단과 마지막 문단에 꼭 넣는다.
- 첫 3줄 안에 이 글에서 무엇을 알 수 있는지 말한다.
- 소제목 3~5개로 나눈다. 소제목에도 연관 키워드를 섞는다.
- "제가 직접 ~해 보니", "제 기준은 ~" 같은 1인칭 경험과 판단을 넣는다. 네이버가 경험 정보를 높게 평가한다.
- 숫자, 날짜, 출처를 구체적으로 쓴다.
- 이미지는 3~6장. 직접 찍거나 캡처한 이미지를 쓴다. 같은 이미지를 여러 글에 재사용하지 않는다.
- 외부 링크는 1~2개 이하로 한다. 광고나 제휴 링크를 넣으면 노출이 떨어질 수 있다.

## 문체·서론 (사용자 지정 스타일)
- 문장 끝맺음은 한 가지 어미만 반복하지 않는다. "~래요/~했대요"에 "~인데요/~했는데요", "~랍니다/~했답니다", "~이에요/~예요"를 섞어 쓰고, 같은 어미가 세 문장 넘게 연달아 오지 않게 한다.
  예: "아일릿이 빌보드 200에서 6위에 올랐는데요. 데뷔 후 처음 들어간 톱10이랍니다. 이전 최고 기록은 26위였대요."
- 서론(첫 문단)은 오늘 다룰 주제를 한두 문장으로 먼저 말하고, 이어서 "이 내용 제가 살펴봤어요."로 시작하는 맥락으로 쓴다.
  예: "아일릿이 미국 빌보드 메인 앨범 차트에서 데뷔 후 처음으로 톱10에 들었는데요. 이 내용 제가 살펴봤어요."

## 피해야 할 것 (저품질·어뷰징 판정 위험)
- AI가 쓴 티가 나는 글: 모든 문단이 같은 길이, "결론적으로", "다양한", "중요합니다"의 반복, 이모지 과다.
  → 문장 길이를 섞고, 구어체 표현과 개인 의견을 넣는다.
- 뜸 들이거나 스스로 묻고 답하는 도입 멘트: "혹시 들으셨어요?", "혹시 들으셨나요?", "도대체 무슨 일이냐면요", "그럼 ~는 언제냐고요?", "정확히 뭐가 어떻게 된 건지 같이 정리해 볼게요" 같은 표현은 도입·소제목·본문 어디에도 쓰지 않는다. 소제목도 "~냐면요", "~일까요" 같은 묻는 형태 대신 내용을 바로 말하는 문장으로 쓴다. (글 맨 끝에 독자 의견을 묻는 마무리 한 줄은 괜찮다.)
- 권유·다짐형 마무리: "~지켜보면 좋겠어요", "응원하면 좋을 것 같아요", "저도 다음에 다시 확인해 볼게요"처럼 독자에게 권하거나 앞으로 할 일을 약속하는 말투는 쓰지 않는다. 대신 "싱글 차트에서도 얼마나 가는지 궁금하네요."처럼 글쓴이의 궁금함·느낌을 짧게 말하는 "~궁금하네요", "~기대되네요" 형태로 쓴다.
- 짧은 시간에 여러 글 발행 (하루 1~2개 권장).
- 다른 글 복사, 키워드만 바꾼 비슷한 글.
- 금지·민감 키워드 (도박, 성인, 의약품 효능 단정, 확정 수익 표현).

## 태그
- 10개 안팎. 메인 키워드, 연관 키워드, 블로그 대표 주제 순서로 넣는다.
- 띄어쓰기 없이 쓴다. 예: #비트코인 #볼린저밴드 #코인차트분석
