# 5단계 작성 흐름 (주제 선정·본문 작성 공통)

모든 모드(A 키워드 / B 시황 / C 연예)에서 글을 쓰기 전에 이 순서를 따른다. 네이버는 검색 결과와 공개 글을 **읽기만** 한다. 입력·첨부·임시저장·발행은 사용자가 직접 한다.

## STEP 1. 잘되는 글의 구조 찾기
- 네이버 블로그 검색(`search.naver.com/search.naver?ssc=tab.blog.all&query=<검색어>`)에서 같은 주제 글 3~5개를 골라 `m.blog.naver.com/<아이디>/<글번호>` 로 실제로 읽는다.
- 인플루언서 여부와 검색 상위 노출(그 검색어·그 시각의 순서)을 구분해 적고, 확인한 검색어·날짜·원문 링크를 남긴다.
- 제목·도입·이미지·설명 방식의 공통점, 내가 적용할 점, 차별화할 점을 정리한다. 순위·성과는 확인 못하면 추정하지 않는다. 남의 문장·구성을 베끼지 않는다.

## STEP 2. 독자가 검색하는 이유 찾기
- 메인 키워드의 검색 의도를 정보 탐색·비교·선택 등으로 나눈다.
- 구체적 상황을 담은 확장 키워드 10개와 각 키워드가 해결할 질문·글 방향을 적는다.
- 검색량·경쟁도는 출처와 기준일이 있을 때만 적고, 없으면 "확인 불가". 숫자를 만들지 않는다.

## STEP 3. 한 편에 하나의 고민 해결 (기획)
- 핵심 고민 하나와 독자가 얻을 결과를 먼저 정한다.
- 제목 후보 3개, 도입, 소제목 5개. 각 소제목에 설명·사례·이미지 역할을 연결한다.
- 기존 제목 목록과 겹치지 않게 하고, 과장된 효과나 상위 노출 보장은 넣지 않는다.

## STEP 4. 원고와 시각 자료
- 정한 분량과 톤으로 원고를 쓴다. 사실·수치의 출처를 남기고, 확인 못한 내용과 직접 경험하지 않은 이야기는 꾸며 쓰지 않는다.
- 이미지마다 역할과 캡션을 만든다. 참고 자료를 복제하지 않는다.
- 원고 TXT와 이미지 파일을 따로 제공한다.

## STEP 5. 게시 전 검수
- 사실·출처·오타·중복 주제·이미지 사용 권한, 이미지와 캡션 일치를 점검한다.
- "수정한 부분 / 수정이 필요한 부분 / 확인하지 못한 부분"을 나누고, 최종 원고·이미지 순서·체크리스트를 준다.
- 체크리스트 마지막 줄: "네이버 입력·첨부·임시저장·발행은 직접 하기".
