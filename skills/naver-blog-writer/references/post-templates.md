# 글 구조 템플릿

본문은 코드 블록 하나에 넣는다. 소제목은 `【 】`, 이미지는 `[이미지: ...]`, 강조는 `▶` 로 표시한다.

## A. 키워드 정보성 글

```
(서론 2~3줄: 오늘 다룰 주제 + 메인 키워드를 말한 뒤 "이 내용 제가 살펴봤어요."로 이어 간다)

[이미지: 대표 이미지 - 주제를 한눈에 보여주는 사진]

【 메인 키워드란? / 핵심 요약 】
(정의나 결론을 먼저. 3~4문장)

【 연관 키워드 1 – 구체 정보 】
(숫자, 방법, 순서. 직접 경험 1개)

[이미지: 과정이나 비교 사진]

【 연관 키워드 2 – 비교·주의할 점 】
(장단점, 자주 하는 실수)

【 제가 정리한 핵심 포인트 】
▶ 포인트 1
▶ 포인트 2
▶ 포인트 3

(마무리 2~3줄: 메인 키워드 다시 언급 + 공감·댓글 유도 한 문장)
```

## B. 주식·코인 시황/차트 글

```
(서론: 날짜 + 종목 + 오늘 한 줄 요약 뒤 "이 내용 제가 살펴봤어요.". 예: "11월 7일 비트코인은 밴드가 몇 달 만에 가장 좁아졌는데요. 이 내용 제가 살펴봤어요.")

【 오늘 시세 요약 】
현재가 ○○ (전일 대비 ○○%), 최근 20일 고가 ○○ / 저가 ○○
(5일, 20일 흐름을 한두 문장으로)

[이미지: 일봉 차트 캡처 – 볼린저 밴드(20,2) 표시]

【 볼린저 밴드로 본 현재 위치 】
상단 ○○ / 중심 ○○ / 하단 ○○
(%B 위치 해석, 밴드폭·스퀴즈, 중심선 기울기, 최근 이탈·돌파 이벤트)

【 보조 지표 체크 】
(RSI, 이동평균 배열, 거래량 배수. 밴드 해석과 맞는지 어긋나는지)

[이미지: RSI·거래량 보조지표 캡처]

【 테마·글로벌 이슈 】
(금리·환율·미국 지수·관련 테마·코인이면 ETF 자금 흐름 등, 날짜와 함께)

【 제 대응 시나리오 】
▶ 상승 시나리오: (조건 + 가격)
▶ 하락 시나리오: (조건 + 가격)
▶ 제가 지켜볼 것: (확인할 신호 1~2개)

(마무리: 다음 글 예고나 질문 한 줄)

이 글은 개인 공부 기록이며 투자 권유가 아닙니다. 투자 판단과 책임은 본인에게 있습니다.
```
