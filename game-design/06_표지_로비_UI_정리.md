## 1. 표지: 설명글 빼기

### 문제
표지 왼쪽 위의 설명 두 줄(`.cover-story`)이 한별·달래 그림 위에 겹쳐서 일러스트를 가립니다. 가로 화면 휴대폰에서는 글자도 작아서 잘 읽히지 않습니다.

### 바꾸는 안
- `.cover-story` 문단을 **지웁니다.** 같은 내용은 이미 프롤로그(`PROLOGUE`) 첫 장면에 있습니다.
- 위쪽 어둡게 하는 그라데이션을 줄여서 그림을 더 밝게 보이게 합니다.
  - `.cover::after` → `linear-gradient(180deg, rgba(5,6,14,.7), rgba(5,6,14,0) 22%, rgba(5,6,14,0) 75%, rgba(5,6,14,.75))`
- 제목은 그대로 두고, 위쪽 여백을 조금 줄입니다(`.cover-txt` top 4cqw → 2.5cqw).
- 「화면을 눌러 탑에 오르기」는 그대로 둡니다.
- 두 번째 실행부터 프롤로그가 안 나오므로, 이야기를 다시 보고 싶은 사람을 위해 일시정지 「도움말」 창 맨 위에 **「이야기 다시 보기」** 버튼을 둡니다.

## 2. 첫 화면(로비): 너무 빡빡함

### 지금 화면에 한꺼번에 있는 것
오른쪽 한 칸에 이름, 정보 한 줄(잘려서 `Lv4…`), 강화 버튼, 능력 막대 3개, 동료 ◀▶, 구간 ◀▶, 출발, 캐릭터 13칸 가로 줄이 있습니다. 그림 위에는 장비 4칸이 올라가 있고(글자가 넘침), 왼쪽 아래에는 버튼 5개가 있습니다.
**한 화면에서 고르는 것이 6가지**(캐릭터, 동료, 구간, 난이도, 장비, 강화)라 무엇부터 해야 할지 안 보입니다.

### 원칙
1. **화면의 주인공은 「출발」:** 가장 크고, 가장 자주 누르는 버튼입니다.
2. **자주 바꾸는 것만 첫 화면에:** 구간과 동료. 가끔 바꾸는 것(캐릭터, 장비, 강화)은 눌러서 여는 창으로 옮깁니다.
3. **같은 성격끼리 묶기:** 「다음 도전」 카드(구간·난이도·추천 동료), 「동료」 카드, 「장비」 카드, 아래쪽 메뉴 줄.
4. **그림 위에는 글자를 올리지 않기:** 이름과 레벨만 그림 아래쪽 가장자리에 둡니다.

### 새 배치 (모형 ②)
```
┌──────────────────────────────┬──────────────────────────────┐
│ [골드 2,440] [달조각 10]      │                     (⏸)(🔊) │
│                               │ ┌ 다음 도전 ──────────────┐ │
│                               │ │ ◀  1-1 새벽 산마루    ▶ │ │
│        캐릭터 큰 그림         │ │    문지기 셋·수문장 ★☆☆ │ │
│   (그림을 누르면 캐릭터 창)   │ │ [보통][어려움🔒][추천 동료]│ │
│                               │ └──────────────────────────┘ │
│                               │ ┌ 동료 ─────┐ ┌ 장비 ─────┐ │
│                               │ │[얼굴] 설녀 │ │ ▢ ▢ ▢ ▢   │ │
│ 한별                          │ └───────────┘ └───────────┘ │
│ 부채 도사 · 넓게 퍼지는 바람  │ ┌──────── 출 발 ──────────┐ │
│ [Lv 1] [화력 +0%] [강화 500]  │ └──────────────────────────┘ │
│                               │ [탑지도][임무][무한의탑][캐릭터][상점] │
└──────────────────────────────┴──────────────────────────────┘
```

| 영역 | 내용 | 누르면 |
|---|---|---|
| 왼쪽 위 | 골드·달조각 알약 | 상점(달조각) |
| 오른쪽 위 | ⏸ 🔊 동그라미 아이콘 | |
| 왼쪽 그림 | 캐릭터 큰 그림(외형 반영, 기획 4) | **캐릭터 고르기 창** (③) |
| 그림 아래 | 이름(큰 글씨), 직업·한 줄 설명, `Lv`, `화력`, **강화 버튼** | 강화 |
| 다음 도전 카드 | ◀ 구간 이름 ▶, 구성·별, 난이도 칩, **추천 동료 칩**(기획 5의 3-5) | 칩: 난이도 바꾸기 / 추천 동료로 바로 바꾸기 |
| 동료 카드 | 동료 얼굴, 이름, 능력 한 줄 | 동료 고르기 창(캐릭터 창과 같은 모양, "같이 갈 동료") |
| 장비 카드 | 무기·부적·장신구·옷 아이콘 4개(빈 칸은 흐리게) | 장비 창(`ovEq`) |
| 출발 | 가로로 꽉 찬 큰 빨간 버튼 | 시작 |
| 아래 메뉴 줄 | 탑 지도 · 임무(남은 보상 있으면 빨간 점) · 무한의 탑 · 캐릭터 · 상점 | 각 화면 |

- **능력 막대 3개(빠르기·화력·범위)** 는 첫 화면에서 빼고 캐릭터 고르기 창의 카드를 눌렀을 때 보여 줍니다.
- **난이도 버튼**은 아래 줄에서 빼고 「다음 도전」 카드의 칩으로 옮깁니다. 구간과 난이도는 함께 고르는 것이기 때문입니다.
- 기획 1의 "단계적으로 열기"와 맞춥니다: 아직 안 열린 메뉴는 아래 줄에서 **숨기고**, 열린 메뉴만 같은 크기로 나눠 채웁니다.

### 캐릭터 고르기 창 (모형 ③)
- 가로 줄 대신 **7칸 × 2줄 격자**에 13명이 다 보입니다(가로로 밀 필요 없음).
- 카드: 게임 캐릭터 그림, 이름, `Lv` 또는 "○층 대장", 잠긴 동료는 🔒와 어둡게, 값이 있으면 `1만3천`.
- 카드를 한 번 누르면 아래쪽에 능력 막대 3개와 「고르기」 버튼, 잠긴 동료는 「골드로 데려오기 / 달조각으로 데려오기 / 한 판 써 보기」가 나옵니다.
- 같은 창을 **동료 고르기**에도 씁니다(제목만 "같이 갈 동료", 지금 조종하는 캐릭터는 흐리게).

### 작은 화면(세로 높이 400px 이하) 대응
- 그림 아래 설명 한 줄(직업·설명)을 숨깁니다.
- 「다음 도전」 카드의 구성 줄(문지기 셋·수문장)을 숨기고 별만 남깁니다.
- 아래 메뉴 줄은 아이콘만, 글자는 숨깁니다.

## 3. Tenkai 방 요청 순서
1. 표지 설명글 지우기, 그라데이션 줄이기, 도움말에 「이야기 다시 보기」 (1번)
2. 첫 화면 배치 바꾸기 (2번, 모형 ② 그대로)
3. 캐릭터·동료 고르기 창 (모형 ③)
4. 작은 화면 대응

모형 그림은 실제 게임 그림과 글꼴로 만든 것이라 크기·색을 그대로 따라 하면 됩니다.
