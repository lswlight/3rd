# 그믐: 달을 훔친 자 · 기획 19. 달래 각성 「그림자 칼날」

대상 코드: 브랜치 `claude/amazing-johnson-jj1z6o` (기획 17-6 각성 모습·각성판 스킬 위에 얹음)
그림: `art/달래각성_그림자칼날/` (사용자 확정 11/21)

## 0. 한 줄 요약
평소엔 활잡이인 달래가 각성하면 **활을 둘로 갈라 그림자 칼날 두 자루**로 바꿔 8초 동안 날아다니며 베고 던진다. 끝날 때 칼날이 다시 활로 합쳐지며 큰 화살 한 발로 마무리한다.
- 활(원거리) → 칼날(던지고 돌아오는 중거리 + 돌진 근접)로 **공격 방식 자체가 바뀌어** "각성했다"가 바로 느껴지게 한다.
- 달래의 평소 장기인 **표식**을 칼날이 터뜨려, 각성 전과 각성 중이 이어진다.

## 2. 각성 중 공격

### 2-1. 기본 공격(자동): 그림자 칼날 던지기
| 항목 | 내용 |
|---|---|
| 모양 | 활대 모양 초승달 칼날이 **빙글빙글 돌며** 앞으로 날아감. 검보라 연기 꼬리, 칼날과 손 사이에 **그림자 실**(가는 보라 선)이 이어져 보임 |
| 움직임 | 왼손·오른손 칼날을 **번갈아** 던짐. 앞으로 화면 폭 60%까지 날아가 멈칫한 뒤 **실을 따라 손으로 돌아옴**(부메랑). 갈 때와 올 때 모두 맞힘, 꿰뚫음 |
| 간격 | 0.32초마다 한 자루(화면에 칼날은 최대 2자루 + 돌아오는 중 2자루 = 4) |
| 실 피해 | 손과 칼날 사이 **그림자 실에 닿은 적도 약한 피해**(초당) → 위아래로 움직이면 실로 쓸어 담는 느낌 |
| 조준 | 캐릭터 정면(오른쪽). 위아래로 움직이면 돌아오는 칼날 궤적이 휘어져 넓게 쓺 |
| 피해 | 칼날 1회 = 각성 기본 공격 1발의 1.2배(갈 때 + 올 때 2번), 실 = 초당 0.5배 |

### 2-2. 캐릭터 스킬(각성판): 그림자 돌진
평소 스킬 「꿰뚫는 세 발」 대신.
| 항목 | 내용 |
|---|---|
| 동작 | 두 칼날을 엇갈려 쥐고 **화면 오른쪽 끝까지 0.35초 만에 돌진** → 원래 자리로 그림자처럼 돌아옴. 그림 `1_dive_blades` 자세 |
| 피해 | 지나간 줄의 모든 적에 큰 피해 + 0.3초 뒤 지나간 자리에 남은 **그림자 베기 자국이 한 번 더 터짐**(2타) |
| 지키기 | 돌진 중 무적, 지나가며 적 탄을 지움(줄 폭만큼) |
| 쿨 | 평소 스킬 쿨의 60% (8초 동안 2~3번 쓰도록) |
| 연출 | 출발 때 짧은 히트스톱 0.04초, 지나간 자리에 보라 잔상 3겹, 「그림자 돌진」 붓글씨 작게 |

### 2-3. 표식 연계 (달래만의 맛)
- 평소 달래의 「표식 사격」으로 찍힌 표식, 또는 꿰뚫는 화살에 맞은 표식이 **각성 중 칼날에 닿으면 터짐**: 그 적에 추가 피해 + 둘레 작은 그림자 폭발.
- 그래서 **각성 전에 표식을 많이 찍어 두면 각성 때 연쇄 폭발** → 각성 타이밍을 고르는 재미.
- 표식이 터질 때마다 각성 시간 +0.3초(최대 +2초).

### 2-4. 마무리: 다시 활로
- 각성이 끝나는 순간 두 칼날이 손으로 돌아와 합쳐지며 활이 되고, **그림자 화살 한 발**(굵은 보라 광선 화살)이 화면을 가로지름. 지나간 줄 큰 피해 + 남은 표식 모두 터짐.
- 기존 각성 끝 폭발(`awakeBlast`)을 달래는 이 화살로 바꿈.

### 2-5. 무기 스킬·협력·부적
- 그대로 씀. 각성 중 무기 스킬 탄만 보라 테두리를 입힘(각성 중임이 보이게).

## 4. 수치 (한곳에 모음: `AWK_DL`)
```
AWK_DL = {
  throwGap: 0.32,     // 칼날 던지는 간격(초)
  reach: 0.6,         // 화면 폭 대비 날아가는 거리
  blade: 1.2,         // 칼날 1회 피해(각성 기본 공격 1발 대비)
  thread: 0.5,        // 그림자 실 초당 피해(같은 기준)
  maxBlades: 4,
  dashTime: 0.35, dashCdK: 0.6, dashDmg: 6, dashScar: 3, // 돌진: 시간, 쿨 배율, 피해, 2타 피해
  markBurst: 2.5, markRadius: 60, markTime: 0.3, markTimeMax: 2, // 표식 터뜨리기
  finalArrow: 8,      // 마무리 그림자 화살 피해
  speedK: 1.2,
}
```
- 목표(기획 16): 각성·연계·필살기 합쳐 대장전 피해의 15% 안. 개발판 `?dps=1` 로 각성 8초 동안의 피해를 재서 평소 달래 8초의 **약 2.5배**가 되게 맞춘다(각성 게이지 60이 차는 데 걸리는 시간을 생각하면 과하지 않게).

## 5. 그림 작업 (기획방, 그림 규칙 0·0-1대로)
| 그림 | 내용 | 참고(첫 참고 = 원본) |
|---|---|---|
| `aw1` 각성 일러스트 | `3_split_moment` 를 1344×752 로 | 완료 |
| `aw1p` 각성 게임 그림 | 두 칼날을 쥔 날아드는 자세, 투명 배경, 280px | 첫 참고 `hp1_o0`(원본 게임 그림), 옷 C안, 무기 `0_weapon_design` |
| `dl_blade` 칼날 탄 | 칼날 한 자루(가로, 투명), 게임이 돌려서 씀 | `0_weapon_design` 오른쪽 칼날 |
| 정보 화면 「각성」 그림 | `1_dive_blades`, `2_throw_blades` (수집용) | 완료 |

그림이 오기 전에는: 칼날은 보라 초승달 도형 + 연기 꼬리로, 각성 모습은 지금 `aw1p` 에 보라 덧칠로 먼저 만든다.

## 6. 요청 순서 (개발방)
1. 2-1 칼날 던지기(부메랑 + 그림자 실) — 가장 중요, 이것만으로 각성이 달라 보여야 함
2. 1 흐름 ①②④ (가르는 일러스트, 갈라지는 0.3초, 다시 활로 + 그림자 화살)
3. 2-2 그림자 돌진
4. 2-3 표식 연계
5. 4 수치 맞추기(`?dps=1`)
6. 그림 들어오면 교체

## 7. 확인할 것 (사용자 검토판)
- 각성 순간 "활이 칼날로 바뀌었다"가 한눈에 보이는가
- 칼날이 돌아오는 궤적이 화면을 너무 가리지 않는가(연기 60% 반투명)
- 표식을 찍어 두고 각성하는 재미가 느껴지는가
