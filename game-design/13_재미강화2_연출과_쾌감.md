## 0. 왜 기획 12가 안 먹혔나
- 기획 12의 대부분은 **점수를 올리는 장치**였습니다. 점수 경쟁을 즐기는 사람에게는 재미지만, 모바일에서 가볍게 하는 사람은 숫자보다 **눈에 보이는 화려함과 "내가 세졌다"는 느낌**에 반응합니다.
- 반대로 반응이 좋았던 합체 기술은 **"큰 연출 + 동료 두 명이 함께"** 였습니다.
- 그래서 방향을 바꿉니다: **숫자 → 장면.** 화면 전체가 바뀌는 순간, 강해지는 순간, 예상 못 한 순간을 늘립니다.
- 기획 12의 장치는 지우지 않고 **조용히 둡니다**: 「連」 숫자는 10연 이상일 때만 작게, 스치기는 소리만. 순위표가 생기면 그때 다시 앞으로 꺼냅니다.

## 1. 합체 기술 다시 만들기 (2.6초 → 약 6초, 4막 구성)

지금: 두 사람 컷인(약 2초) → 효과가 바로 게임 화면에 조금 나오고 끝(`comboStart`).

### 1-1. 4막 구조 (모든 합체 공통)
| 막 | 길이 | 장면 |
|---|---|---|
| ① 부름 | 1.2초 | 지금의 대각선 두 사람 컷인 + **두 사람의 대사 한 줄씩**(번갈아 말풍선) |
| ② 모임 | 0.6초 | 게임 화면으로 돌아오며 **화면이 어두워지고**, 동료가 날아와 주인공과 나란히 섬. 둘 사이에 빛 고리가 커짐 |
| ③ 기술 | 3.0초 | **배경이 합체 전용 색과 무늬로 바뀜**(아래 표). 화면 가득 효과가 여러 겹, 적에게 **여러 번** 맞으며 피해 숫자가 튀어 오름. 화면 위에 **누적 피해 숫자**가 빠르게 올라감 |
| ④ 마무리 | 1.0초 | 0.5초 느린 화면 → 마지막 큰 일격 → 하얀 번쩍임 + 큰 흔들림 → 화면 가운데 **붓글씨 기술 이름이 도장처럼 찍힘**(붉은 낙관 테두리) |

- 이 동안 주인공은 무적이고, 적 탄은 ②에서 모두 사라집니다.
- 소리: ①북 세 번 → ②음이 올라가는 바람 소리 → ③기술별 소리 연타 → ④큰 북 + 징.
- 다시 볼 때 지루하지 않게: **같은 판에서 두 번째부터는 ①을 0.5초로 줄임**(설정에서 "합체 연출 짧게"도 선택 가능).

### 1-2. 합체마다 ③ 장면
| 합체 | 배경 | 화면 효과 (여러 겹) | 마지막 일격 |
|---|---|---|---|
| 눈보라 부채 (한별+설녀) | 하얗게 눈 내리는 밤, 화면 가장자리에 서리 | 거대한 부채 실루엣이 화면을 위→아래로 두 번 휘두름, 눈보라 줄기, 모든 적이 얼음에 갇힘(파란 덮개) | 얼음이 한꺼번에 **깨지며** 파편이 사방으로 |
| 여우불 화살비 (달래+구미호) | 붉은 노을, 여우불 수십 개가 떠다님 | 화살 40발이 하늘로 올라갔다가 비처럼 쏟아짐, 화면 위에 아홉 꼬리 실루엣 | 금빛 화살 하나가 화면을 가로지르며 큰 폭발 |
| 은하수 승천 (나린+이무기) | 밤하늘 은하수가 화면 가득 | 물기둥 5줄이 차례로 솟고, 그 사이로 이무기가 S자로 솟구쳐 오름 | 이무기가 화면 위로 사라졌다가 **용이 되어** 내리꽂힘 |
| 도깨비 잔치 (탈 도깨비+여왕) | 금빛 잔칫날, 등불과 꽃가루 | 모든 탄이 엽전으로 바뀌어 쏟아지고, 꼬마 도깨비들이 화면을 뛰어다니며 적을 때림 | 거대한 금 방망이가 「뚝딱!」 글자와 함께 내려침 |
| 쇠 먹는 대장간 (불가사리+쇠 도깨비) | 붉은 용광로 불빛 | 탄을 빨아들이는 소용돌이 → 불가사리가 크게 부풀어 오름 | 빨아들인 수만큼 칼이 **부채꼴로 한꺼번에** 날아감 |
| 수호진 (장승 자매+용왕의 장수) | 푸른 바다와 장승이 선 마을 | 물결 방벽 + 장승 기둥 셋이 땅에서 솟아 차례로 내리침 | 바다 전체가 일어나는 큰 파도가 화면을 덮음 |

- 그림: 새 그림 없이 **기존 컷인·캐릭터 그림 + 색 덮개 + 실루엣(그림을 검게 칠해 크게) + 입자 효과**로 만듭니다.
- 필살기 화질 개선(기획 7) 때 만든 고해상도 구간(컷인 동안 캔버스 해상도 올리기)을 ③④에도 적용.

### 1-3. 대사 예시 (①에 쓰는 것)
- 눈보라 부채: 한별 「바람을 빌리겠소.」 / 설녀 「내 눈으로 덮어 줄게.」
- 여우불 화살비: 달래 「한 발이면 충분하다 했지?」 / 구미호 「후후, 마흔 발은 어때?」
- 도깨비 잔치: 탈 도깨비 「잔치다!」 / 여왕 「금 나와라, 뚝딱!」
(나머지도 같은 결로, 결정사항에 확정본 기록)

## 2. 달빛 각성 (누구나 느끼는 "세졌다" 순간)

| 항목 | 내용 |
|---|---|
| 게이지 | 화면 왼쪽 위 초승달 모양. 적을 잡을수록 차오름(잔챙이 1, 문지기 8, 수문장 20). 구간 하나에 1~2번 찰 정도 |
| 켜는 법 | 가득 차면 초승달이 보름달로 빛남 → **캐릭터를 두 번 톡톡** 누르면 각성 |
| 각성 8초 | 캐릭터 1.4배 크기 + 금빛 기운, **기본 공격이 화면 절반을 덮는 굵기**, 모으기 공격이 자동으로 1초마다, 무적, 화면 가장자리에 달빛 테두리, 배경 음악이 빨라짐(음악이 생기면) |
| 끝날 때 | 주변 적에게 충격파 + 탄 지우기 |
| 캐릭터별 | 한별: 회오리가 계속 따라다님 / 달래: 화살이 세 갈래 관통 / 나린: 은하수 물줄기 / 동료로 바꾸면 동료 기술로 |

- 합체 기술과 다른 점: 합체는 **"보는 장면"**, 각성은 **"내가 직접 휩쓰는 시간"**.
- 게임 흐름: 잔챙이를 잡다 → 게이지 참 → 각성으로 문지기를 순식간에 처리 → 큰 쾌감.

## 3. 본편에서도 강화 고르기 (판마다 달라지게)

그믐의 탑에 이미 있는 **달빛 축복 27개**를 본편 구간에도 씁니다.

- 각 구간에서 **문지기를 쓰러뜨릴 때마다** 축복 카드 3장 중 1장을 고름(구간당 2~3번).
- 고른 축복은 **그 구간 안에서만** 유지(구간이 1~2분이라 짧고 굵게).
- 축복이 겉모습에 보이게: 갈래가 늘면 탄 수가 늘고, 관통이 붙으면 탄이 길어지고, 방패가 붙으면 캐릭터 둘레에 부적이 돎.
- 처음 하는 1층은 끔(기획 1의 첫 10분 단순하게). 2층부터 켬.

## 4. 돌발 사건 (예상 못 한 순간)

구간마다 30% 확률로 하나. 시작 전 「!」 경고와 짧은 글.

| 사건 | 내용 | 보상 |
|---|---|---|
| 보물 도깨비 | 금빛 꼬마 도깨비가 엽전 자루를 메고 화면을 가로질러 **도망**. 8초 안에 잡아야 함 | 엽전 폭죽(골드 많이), 가끔 장비 |
| 요괴 떼 습격 | 15초 동안 잔챙이가 **화면 가득** 몰려옴(약하고 많음) | 각성 게이지 가득, 쓸어버리는 쾌감 |
| 엽전 비 | 10초 동안 하늘에서 엽전이 쏟아짐, 적은 안 나옴 | 골드 |
| 길 잃은 동료 | 아직 없는 동료가 잠깐 나타나 **같이 싸워 줌**(10초) | 그 동료 체험(영입 동기) |
| 대장의 그림자 | 다음 층 대장의 그림자가 잠깐 나타나 탄 몇 줄 쏘고 사라짐 | 다음 층 예고, 긴장감 |

- 기존 그림 재사용: 보물 도깨비 = 문지기 「방망이 쌍둥이」 그림을 금빛으로, 습격 = 잔챙이, 길 잃은 동료 = 동료 그림.

## 5. 대장전 연출

| 순간 | 연출 |
|---|---|
| 등장 | 화면이 어두워지고 **대장 컷인**(기존 대장 그림 크게) + 붓글씨 이름 + 「○층 대장」, 2초 |
| 체력 50% (2단계) | 지금의 변신 + **대장 대사 한 줄**(말풍선) + 짧은 컷인 |
| 체력 20% | 대장 몸이 붉게 깜빡이고 「발악!」 패턴(탄이 빨라짐), 동료 대사 「조금만 더!」 |
| 쓰러뜨림 | 지금의 느린 화면 + 대장이 원래 모습으로 돌아오는 짧은 장면 + 동료 제안으로 연결 |

## 6. 동료가 말을 거는 순간 (애착)

전투 중 동료가 짧게 말합니다(말풍선 1.5초, 자주 나오지 않게 20초에 한 번 이하).

| 때 | 예 |
|---|---|
| 내가 맞았을 때 | 설녀 「괜찮아? 내가 얼려 둘게.」 |
| 각성 켤 때 | 구미호 「어머, 멋진데?」 |
| 합체 준비됐을 때 | 이무기 「지금이야, 같이 하자!」 |
| 대장 체력 20% | 탈 도깨비 「끝이 보인다!」 |

- 동료마다 6~8줄. 글만 쓰면 되므로 이 방에서 대사집을 써서 넘깁니다.
