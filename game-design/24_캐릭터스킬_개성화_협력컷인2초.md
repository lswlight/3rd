# 그믐: 달을 훔친 자 · 기획 24. 캐릭터 스킬 개성화 · 협력 컷인 더 길게

사용자 요청(11/23):
1. 협력 일러스트가 나오고 없어지는 시간이 아직 짧다 → 더 늘림.
2. 캐릭터 스킬을 **캐릭터마다 다르게**.

지금(개발판): 캐릭터 스킬 쿨 23명 모두 5초·각성 3초(기획 23, 유지). 기술은 기획 14·15 표대로 들어갔지만 대부분 **「앞으로 무언가를 쏜다」** 하나라, 이름·색만 다르고 손맛이 비슷함(관통 탄 4명, 묶는 탄 6명).

## 1. 협력 컷인 더 길게
| 항목 | 지금(기획 23-5) | 바꿈 |
|---|---|---|
| 맞손 컷인(게임 멈춤) | 1.2초 = 0.3 + 0.6 + 0.3 | **2.0초** = 들어옴 0.3 + **멈춰 보여 줌 1.4** + 나감 0.3 |
| 같은 판 반복 | 0.8초까지 | **1.4초**까지 |
| 각성 협력·쌍각성 | 1.5초 | **2.4초** |
| 보여 주는 동안 | 정지 | 두 일러스트가 **천천히 서로 다가감(살짝 확대 1.0→1.05)** + 금빛 선 반짝 + 연계 이름이 붓으로 써짐 → 멈춘 그림처럼 안 보이게 |
| 건너뛰기 | 없음 | 컷인 중 화면 톡 = 바로 다음 장면(급할 때) |
| 설정 「협력 컷인」 | 길게/짧게/끄기 | 그대로, 길게 = 2.0초, 짧게 = 1.0초 |

캐릭터 스킬 컷인(지금 1.0초, 게임 멈추지 않음)은 그대로.

## 2. 캐릭터 스킬: 23명 모두 다른 「종류」
원칙
- **같은 종류를 두 명이 쓰지 않음.** 종류 = 움직임·조작·효과가 다른 것(직선 탄, 설치, 돌진, 회전, 지형, 반사 등).
- 버튼은 대부분 **톡**. 일부만 **누르는 동안**(빔·조준)으로 조작 손맛을 다르게(표에 「누름」 표시).
- 쿨 5초·각성 3초 그대로. 각성 중에는 같은 종류의 강화판(기획 20 ③ 스킬).
- 모양·소리는 기획 23 속성 이펙트를 바탕으로, 종류마다 **고유 모양 하나**를 더함.
- 피해: 공격형 = 기준 1, 방어·회복·보조형 = 0.5~0.7(대신 효과). 기획 23 SK23.dmgK(0.55) 위에서 종류별 배수.
