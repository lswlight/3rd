# 그믐: 달을 훔친 자 · 기획 26. 오토배틀 모드 「달밤 진법」

사용자 요청(11/23): 그믐 캐릭터로 오토배틀 모드를 기획.
자리: 「도깨비 오락실」(기획 9)의 새 오락기. 장르 = 오토배틀러(캐릭터를 모아 배치하면 싸움은 자동).
원칙(기획 9): 장르의 **놀이 방식**만 가져오고, 다른 게임의 이름·화면 구성·규칙 세부·그림은 쓰지 않음. 그믐 세계관(설화·달·봉인·요괴)으로 **우리만의 규칙**을 만든다.

---

## 0. 한 줄 요약
**혼자 하는 오토배틀 로그라이트.** 그믐 동료 23명과 봉인한 요괴로 「진(陣)」을 짜서, 달이 차오르는 15밤 동안 요괴 행렬을 막는다. 달의 모양(초승→보름→그믐)에 따라 매 밤 규칙이 바뀌는 것이 그믐만의 특징.

| 항목 | 내용 |
|---|---|
| 한 판 | 15밤(라운드), 약 15~20분. 중간 저장 가능 |
| 상대 | 다른 사람이 아니라 **요괴 행렬**(PvE). 5밤마다 대장(본편 대장 10명 중 무작위). 나중에 친구 진 기록과 비동기 겨루기(6절) |
| 지면 | 목숨(「등불」) 5개. 밤을 못 막으면 등불 1개 꺼짐, 다 꺼지면 끝 |
| 재화 | 판 안: **엽전**(진 짜기 전용, 판 끝나면 사라짐). 판 밖 보상: 달조각·요괴 부적·의상 조각 |

## 1. 판 짜기 화면: 「장터 진판」 (가로 화면, 11/23 정정)
- 게임 화면은 가로(640×360). 본편 슈팅처럼 **요괴는 오른쪽에서 몰려오고 우리 진은 왼쪽**.
- 싸움터: 화면 위쪽 약 70%. 우리 진 = **왼쪽 3열 × 5줄(15칸)**, 오른쪽 넓은 공간 = 요괴 행렬이 들어오는 길.
- 아래 띠(약 30%): 왼쪽 대기석 6칸 · 가운데 주막 카드 5장 · 오른쪽 진 엽전·등불 단계·「밤 시작」 버튼.
- 열의 뜻: 오른쪽 열(적에 가장 가까움) = 막는 열, 가운데 = 섞는 열, 왼쪽 열 = 쏘는 열. 칸마다 바닥 문양(물·불·바람 등)이 밤마다 바뀜(3절).

## 2. 캐릭터

### 2-1. 단위: 「인연 카드」
- 주막에서 엽전으로 캐릭터 카드를 삼. 같은 캐릭터 **2장이 모이면 「짝」, 짝 둘이면 「각성」** — 각성하면 기존 **각성 그림(aw*p)·각성 공격**으로 바뀜(그림 새로 안 그림).
  (3장 합치기 대신 2장씩 두 번: 2 → 4장. 그믐의 「인연」·「각성」과 맞춤)
- 비싼 정도(엽전): 1~5. 주인공 3명은 5, 대장 출신 동료 10명은 2~4, 새 캐릭터 10명은 1~3.
- 싸움 중 자동 행동: 기본 공격 + 기운이 차면 **캐릭터 스킬(기획 24 그대로)** 자동 사용. 스킬 탄 그림(t*.webp)·속성 이펙트(기획 23) 그대로 씀.

### 2-2. 비용표 (안)
| 엽전 | 캐릭터 |
|---|---|
| 1 | 우렁각시, 처용, 직녀, 홍길동, 탈 도깨비 |
| 2 | 저승사자, 바리공주, 세오녀, 불가사리, 장승 자매 |
| 3 | 해태, 산군, 강림도령, 구미호, 설녀 |
| 4 | 이무기, 용왕의 장수, 쇠 도깨비, 두억시니, 도깨비 여왕 |
| 5 | 한별, 달래, 나린 |

## 3. 그믐만의 규칙

### 3-1. 「뿌리」 시너지 (설화가 나온 곳)
같은 뿌리 캐릭터를 진에 여럿 두면 힘이 생김(2·4명).
| 뿌리 | 캐릭터 | 2명 | 4명 |
|---|---|---|---|
| 하늘 | 나린, 직녀, 세오녀, 한별 | 스킬 기운 +20% | 밤 시작에 하늘에서 별빛 일격 |
| 저승 | 저승사자, 바리공주, 강림도령, 두억시니 | 쓰러진 아군 1명 1번 되살림 | 쓰러진 적이 아군 편 넋으로 3초 싸움 |
| 용궁 | 용왕의 장수, 이무기, 우렁각시, 설녀 | 젖음 상태 오래감 | 밤마다 물결 방벽 1번 |
| 도깨비 | 탈 도깨비, 쇠 도깨비, 도깨비 여왕, 불가사리 | 처치마다 엽전 +1(밤당 최대 5) | 뚝딱: 아군 하나 무작위로 1밤 동안 짝 단계 +1 |
| 산 | 산군, 해태, 장승 자매, 구미호 | 앞줄 막는 힘 +25% | 산신 울음: 첫 5초 적 느려짐 |
| 마을 | 달래, 홍길동, 처용 | 기본 공격 속도 +15% | 마을 사람들 응원: 등불 1개 되살림(판당 1번) |
(한 캐릭터는 뿌리 하나. 주인공은 하늘·마을에 나눠 넣음)

### 3-2. 「속성」 연계 (기획 23 연계표 재사용)
- 이웃한 칸(위아래·옆)에 놓인 두 캐릭터의 속성이 연계표에 있으면 **연계 고리**가 이어짐(진판에 두 색 실로 표시).
- 둘 다 스킬을 쓰면 그 사이에서 **연계 일격**(증기 폭발·감전 연쇄 등 24종 그대로) 자동 발동.
→ 「누구를 누구 옆에 두나」가 그믐만의 배치 고민.

### 3-3. 달의 모양 (밤마다 바뀌는 규칙)
15밤 = 달이 초승에서 보름을 지나 그믐으로. 밤 시작 전에 하늘에 달 모양과 그 밤 규칙이 보임.
| 밤 | 달 | 규칙 예 |
|---|---|---|
| 1~4 | 초승 | 바닥 문양 1종, 요괴 약함 |
| 5 | 보름 전 | 대장 1 |
| 6~9 | 보름 | **각성 밤**: 짝 단계 캐릭터도 3초 각성 / 요괴도 강해짐 |
| 10 | 보름 | 대장 2 |
| 11~14 | 이지러짐 | 어둠 칸(아무 효과 없는 칸) 생김, 「하늘」 약해지고 「저승」 강해짐 |
| 15 | 그믐 | 마지막 대장: 「달을 훔친 자」 그림자(본편 마지막 대장의 그림자판) |

### 3-4. 봉인 (요괴를 내 편으로)
- 싸움 중 체력 20% 아래 요괴가 「封」 표시 → 밤 끝에 **봉인 부적 1장**으로 하나만 잡을 수 있음(기획 23처럼 1장).
- 봉인한 요괴는 **대기석에 「요괴 카드」**로 들어옴: 진에 놓으면 1밤 싸우고 사라짐(1회성, 기획 23과 같은 원칙). 요괴 부적함 레벨(기획 15)이 높을수록 셈.

### 3-5. 주막(상점)
- 밤마다 엽전 5 + 이긴 밤 +1 + 연속 승패 보너스 없음(단순하게) + 모은 엽전 10마다 +1(최대 +3).
- 주막 카드 5장, 「새로 고르기」 1엽전. 「주모에게 묻기」(밤당 1번 무료): 진에 있는 뿌리 하나를 골라 그 뿌리 카드만 나오게.
- 진에 놓을 수 있는 수 = 「등불 단계」(1~8). 엽전 4로 단계 +1 경험치(기존 장르의 레벨 대신 「등불을 밝힌다」로 표현).

### 3-6. 증강 대신 「밤손님」
- 3·8·13밤 시작에 「밤손님」 셋 중 하나를 고름: 기존 탑 축복(기획 8)·장비(기획 15) 효과를 오토배틀용으로 바꾼 것. 예: 「삼신할미」 = 짝 완성 때 체력 +20%, 「물레방아 도깨비」 = 새로 고르기 1번 무료/밤.

## 4. 화면·연출 (새 그림 거의 없음)
| 쓰는 것 | 이미 있는 그림 |
|---|---|
| 캐릭터 카드 | 원본 일러스트 얼굴 쪽 잘라 쓰기 |
| 싸움터 캐릭터 | 게임 그림 p*·hp*(평소), aw*p(각성) — 작게 |
| 스킬·연계 | 스킬 탄 t*.webp, 속성 이펙트, 협력 연계 이펙트 |
| 요괴 | 본편 요괴·대장 그림 |
| 새로 필요한 것 | 진판 배경 1장(장터 밤 마당, 16:9 가로), 달 모양 15단계 아이콘(코드로 그림), 뿌리 문양 6개(코드 또는 작은 그림) → 크레딧 약 1~3 |

## 5. 보상과 본편 연결
- 판 끝 순위 대신 **막은 밤 수**로 보상: 달조각, 요괴 부적, 의상 조각, 오토배틀 전용 칭호.
- 오토배틀에서 처음 2장 짝을 만든 캐릭터는 본편 **인연(기획 21) +10**.
- 15밤 모두 막으면 「달밤 진법 완성」 + 진판 꾸미기(돗자리 무늬 등).

## 6. 나중(2단계)
- **비동기 겨루기**: 다른 사람의 15밤 진 기록(진 배치)을 「그림자 진」으로 불러와 겨룸. 실시간 대전 없음(서버 부담·과금 문제 없게).
- 주간 「달 행사」: 그 주의 달 규칙 고정(예: 내내 보름).

## 7. 개발 범위 (대략)
1. 진판·대기석·주막·엽전·등불 단계(밤 1~5만, 캐릭터 10명) — 시험판
2. 자동 싸움(기본 공격·스킬·속성 연계), 짝·각성
3. 뿌리 시너지 6종, 달 규칙 15밤, 대장 3번
4. 봉인 요괴 카드, 밤손님
5. 보상·본편 연결, 저장

## 8. 확정 (사용자 11/23: 「니가 생각하는 안대로」)
1. 이름 **「달밤 진법」**
2. 짝·각성 = **같은 캐릭터 2장 → 짝, 짝 둘(4장) → 각성**
3. 상대 = **혼자 PvE(요괴 행렬)**, 비동기 겨루기는 2단계
4. 시험판 = 캐릭터 10명·5밤부터(7절 1번), 이어서 15밤 전체

## 9. 장터에서 들어가기: 새 건물 「진법 마당」
오락실(족자 창) 안의 오락기 하나로 숨기지 않고, **장터 거리에 건물을 따로 하나 둠**(기획 10의 건물 방식).

### 9-1. 장터 거리의 자리
| 항목 | 내용 |
|---|---|
| 건물 | **진법 마당**: 장터 한쪽 공터에 멍석을 깔고 둘레에 청사초롱, 가운데 큰 나무판(5×3칸 진판)이 세워져 있고 장기짝 같은 나무 패가 놓임. 마당 위 하늘에 지금 달 모양 |
| 이름표 | 먹물 띠(기획 10 3-0) 「진법 마당」 |
| 열림 | 본편 **2층 대장을 깬 뒤**(동료가 5명 넘게 모였을 때). 그전엔 멍석이 말려 있고 「달이 차면 열린다」 |
| 알림 | 도깨비불(기획 10): 주간 달 행사 시작, 받을 보상, 새 기록 |
| 오락실과 관계 | 오락실 족자 창에도 「달밤 진법」 오락기가 하나 있어, 누르면 같은 화면으로 감(두 길) |
| 새 그림 | 장터 거리 배경에 진법 마당 자리(멍석·초롱·진판)를 그려 넣은 판 1장, 진판 배경 1장 → 약 2~3크레딧 |

### 9-2. 진법 마당 메뉴 (전체 화면, D 화면 형식)
들어가면 진판 나무판이 크게 보이고(가로 화면), 그 위에 족자 메뉴.
```
┌─────────────── 달밤 진법 ───────────────┐
│  [하늘: 오늘의 달 모양 + 이번 주 달 행사]  │
│                                          │
│   ▶ 새 판 펼치기        (엽전 1닢)        │
│   ▶ 이어 하기           (저장한 판, 몇째 밤) │
│   ▶ 진법 책             (뿌리·연계·밤손님 도감) │
│   ▶ 진법 배우기         (연습 3밤, 처음 1번 필수) │
│   ▶ 기록과 보상         (최고 밤, 받을 보상)  │
│   ▶ 그림자 진 겨루기    🔒 2단계            │
│                                          │
│  아래 부적 탭: 市 장터로 · 出 출격 · 人 캐릭터 · 裝 장비 │
└──────────────────────────────────────────┘
```
| 메뉴 | 하는 일 |
|---|---|
| **새 판 펼치기** | 「진법 고르기」 3개 중 하나를 고르고 시작: 보통 / 보름 진법(내내 보름 규칙, 보상 1.5배) / 그믐 진법(어려움, 15밤 등불 3개). 처음엔 보통만 열림 |
| **이어 하기** | 판은 밤이 끝날 때마다 자동 저장. 저장이 있으면 맨 위에 크게 「셋째 밤부터 이어 하기」 |
| **진법 책** | ① 뿌리 시너지 6종(모은 사람 수별 효과) ② 속성 연계표(24종, 써 본 것만 밝게) ③ 밤손님 목록 ④ 캐릭터별 진법 정보(비용·뿌리·속성·스킬). 오토배틀 전용 도감 |
| **진법 배우기** | 3밤짜리 연습판: 카드 사기 → 놓기 → 짝 만들기 → 연계 고리 → 봉인 카드. 처음 한 번은 꼭 거쳐야 새 판이 열림. 다 하면 달조각 10 |
| **기록과 보상** | 최고로 막은 밤, 진법별 기록, 「15밤 완성」 횟수, 가장 많이 쓴 뿌리·캐릭터. 처음 달성 보상(5·10·15밤) 받기 |
| **그림자 진 겨루기** | 2단계(6절): 다른 사람 진 기록과 비동기 겨루기. 지금은 자물쇠 |

### 9-3. 엽전 1닢
- 기획 9 공통 규칙대로 판 시작에 엽전 1닢(하루 3판 무료). 판 안의 엽전(진 짜기용)과는 다른 것 → 판 안 엽전은 **「진 엽전」** 으로 이름을 나눠 헷갈리지 않게.

### 9-4. 본편과 오가기
- 진법 마당에서 캐릭터 카드를 길게 누르면 그 캐릭터 정보 화면(기획 15)으로.
- 본편에서 데려오지 않은 캐릭터도 진법에서는 쓸 수 있음(판 안에서만). 다만 판 끝 「인연 +10」은 데려온 캐릭터만.

## 10. 시험판 반영 기록 (개발방 커밋 d1f27c0, 11/23)
개발방이 문서에 없던 것을 정해 넣은 것(기획방 확인):

## 12. 싸움 방식 바꿈: 진 대 진 맞붙기 (사용자 확정 11/23)
처음 안(요괴 행렬이 길을 따라 지나가고 막는 방식)은 **타워 디펜스**였음 → 오토배틀러답게 **진과 진이 맞붙는** 방식으로 바꿈. 1절·0절의 「요괴 행렬을 막는다」는 이 절로 대체.

| 항목 | 바뀐 규칙 |
|---|---|
| 배치 | 우리 진 = 왼쪽 3열 × 5줄(멍석), **요괴 진 = 오른쪽 3열 × 5줄(돌판), 거울처럼 마주 봄**. 가운데는 좁은 흙길 |
| 요괴 진 | 밤 시작 전에 요괴 진이 보임(무엇이 어디 있는지 보고 우리 진을 고칠 수 있음) → 배치 고민의 핵심 |
| 싸움 | 「밤 시작」을 누르면 양쪽이 **동시에 움직임**. 막는·베는 캐릭터는 가장 가까운 적에게 다가가 칸 경계를 넘어 싸움, 쏘는 캐릭터는 사거리 안 적을 쏨. 칸에 묶이지 않고 자유롭게 움직이다 밤이 끝나면 제자리로 돌아감 |
| 이기고 지기 | **한쪽이 전멸하면 끝.** 지면 살아남은 요괴 수 + 밤 단계만큼 등불이 깎임(초승 밤 1, 보름 밤 2, 대장 밤 3, 최소 1). 45초가 지나면 비김(남은 체력 합이 적은 쪽이 진 것으로 1만 깎임) |
| 등불 | 5개 → 진 판마다 깎이는 양을 위처럼 바꿨으므로 **등불 10개**로 늘림 |
| 대장 밤 | 대장이 요괴 진 가운데 칸에 서고 둘레를 졸개가 지킴. 대장은 체력이 크고 기술 3개를 차례로 씀 |
| 봉인 | 그대로: 싸움 중 체력 20% 아래 요괴에 「封」, 밤 끝에 부적 1장으로 하나 잡음 |
| 진법 배우기 | 연습 3밤도 맞붙기 방식으로 |
| 없앤 것 | 「진을 지나간 요괴 3마리면 패배」, 오른쪽 요괴 길 |
| 배경 | 진판 배경을 대칭(왼쪽 멍석 · 오른쪽 돌판)으로 다시 그림 |
- 반영(개발방 커밋 63da742): 요괴 진 표시 弓 = 쏘는 요괴 · 將 = 대장. 요괴 수 1밤 2마리 → 밤마다 늘어 최대 9, 대장 밤 = 대장 + 졸개 4. 대장 기술 3개 = 내려찍기 · 도깨비불 세 발 · 포효(0.8초 기절). 45초 판정 = 남은 체력 비율 합 비교. 용궁 4명 효과 「물결 방벽」은 길이 없어져 **싸움 시작 보호막 40**으로 바꿈.

## 17. 속성 구분: 문양 + 발밑 고리 + 연계 칸 빛 (사용자 확정 11/24)
색만으로는 작은 카드에서 헷갈리고 색약도 고려해 **모양으로도** 구분.
| 항목 | 내용 |
|---|---|
| ① 속성 문양 | 카드 왼쪽 위 글자(한자/한글) 대신 **문양 아이콘**: 바람 = 소용돌이, 물 = 물방울, 불 = 불꽃, 얼음 = 눈꽃, 번개 = 번개 줄기, 표식 = 과녁, 사슬 = 고리, 무거움 = 돌덩이. 테두리 속성 색은 그대로(색 + 모양 두 겹). 코드로 그림(크레딧 없음) |
| ④ 진판 발밑 고리 | 진판 위 캐릭터 발밑에 속성 색 고리 + 같은 문양(작게). 싸울 때도 누가 무슨 속성인지 보임 |
| ⑤ 연계 칸 빛 | 카드를 집거나 진판 캐릭터를 끄는 동안, 놓으면 **연계 고리가 생기는 칸**(가로·세로·대각 이웃에 짝이 되는 속성)이 은은히 빛나고, 같은 속성 캐릭터 발밑 고리가 깜빡임 |
- 안 한 것: 카드 바탕 무늬, 테두리 모양 바꾸기(작은 화면에서 산만).
- 진법 책 속성 목록도 같은 문양으로.

- (11/25 사용자 확정) **장승 자매 카드는 카드 전용 그림 `art/게임용/jcard6.webp`(420×640)** 를 씀: 원본 컷인에서 두 얼굴(파란 머리 자매 위, 빨간 머리 자매 아래)을 잘라 카드 모양으로 쌓은 그림(그림체 그대로, 크레딧 없음). JFACE 자르기 대신 이 그림을 카드 안쪽에 통째로 맞춤. 전후: `art/달밤진법/장승자매_카드_전후.png`.

## 21. 속성에 의미: 같은 속성끼리만 연계 (사용자 확정 11/25)
문제: 이웃이면 어떤 속성이든 연계 고리가 생겨 속성이 거의 의미가 없었음(기획 26 16절).
- **연계 고리는 같은 속성 캐릭터가 이웃(가로·세로·대각)일 때만** 생김. 다른 속성끼리의 「○·○ 합」 고리는 없앰.
- 30명 속성 수: 🌀바람 4 · ✦표식 4 · 💧물 4 · 🔥불 4 · ⛓사슬 5 · ❄얼음 3 · ⚡번개 3 · ⬛무거움 3 → 어느 속성이든 2~3명은 모을 수 있음.
- **사슬 잇기**: 같은 속성이 3명 이상 이어지면(이웃끼리 연결된 한 무리) 연계 일격 피해 ×1.5, 발동 간격 -30%. 4명 이상 ×2.
- 연계 일격(둘이 함께 스킬을 쓰면 그 사이에서 자동 발동, 기존 방식 그대로):

| 속성 | 연계 이름 | 하는 일 |
|---|---|---|
| 🌀 바람 | 돌개바람 | 두 사람 사이에서 회오리가 앞으로 굴러가며 적을 끌어모음 |
| ✦ 표식 | 겹표식 | 앞 적 셋에 겹표식: 4초 동안 받는 피해 +30% |
| 💧 물 | 물결 | 젖음 + 물결이 적 줄을 한 칸 뒤로 밀어냄 |
| 🔥 불 | 불바다 | 앞 두 칸 바닥에 3초 화상 지대 |
| ❄ 얼음 | 얼음꽃 | 맞은 적 1초 얼림(대장은 느려짐) |
| ⚡ 번개 | 연쇄 번개 | 적 4명에게 차례로 튐 |
| ⛓ 사슬 | 포박 | 적 둘을 1.5초 묶음 |
| ⬛ 무거움 | 땅울림 | 앞 줄 적 0.5초 기절 + 밀려남 |

- 화면: 진판 발밑 고리(19절) 그대로, 같은 속성 이웃끼리 **속성 색 실**로 이어짐. 카드를 집으면 같은 속성이 있는 이웃 칸만 빛남(17절 ⑤를 같은 속성 기준으로). 진법 책 「연계」 쪽에 위 표.
- 균형: 연계 고리 수가 줄어든 만큼 연계 일격 피해 기본값 ×1.3(측정 후 조정). 진영·특별 짝·역할 조합은 그대로.

## 22. 별(짝·각성)마다 공격이 달라지게 (사용자 11/25, 안)
