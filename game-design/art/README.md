- 각성 모습은 11/21 2차본: 원래 게임 그림(hp0·hp1_o0·hp2n)을 참고로 다시 그려 그림체를 맞춤. 강림도령 게임 그림도 갓·창을 고친 2차본.
- 스프라이트는 대부분 오른쪽을 봄. 저승사자·우렁각시처럼 몸이 정면에 가까운 그림은 게임에서 좌우 뒤집지 말고 그대로 씀.
- 15세 기준 확인: 해태(배 드러남)·달래 각성(수영복 수준)은 기준 안. 확대·정지 연출은 얼굴과 무기 쪽만.
