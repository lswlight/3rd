## 게임용 (11/21 3차, 테두리 정리)
`게임용/` 은 게임 `assets/` 에 **이름 그대로 덮어쓰면 되는** 파일입니다: `p13`~`p22`(게임 그림 280px), `cut13`~`cut22`(일러스트 1024px), `aw0p`~`aw2p`(각성 모습 280px).
- 흰 배경을 지운 뒤 가장자리에 남던 흰 띠(배경과 섞인 픽셀)를 1픽셀 다듬어 없앰. 테두리 흰 비율 28~62% → 대부분 3~16%(선녀는 옷이 금빛·흰빛이라 39%).
- 한별 각성 모습은 머리카락 사이에 갇힌 흰 배경이 남아 있어 다시 지움.

## 각성 일러스트 2차 · 협력 기술 그림 (11/21)
- `각성2/awake_*.webp`: (11/21 3차: 기존 각성 일러스트를 그림체 참고로 넣어 다시 그림, 그림체 맞춤) 주인공 3명 각성 일러스트 새 자세(한별 뛰어올라 부적 초승달, 달래 공중 회전하며 달 쪽으로 활, 나린 호수 위 물 용). 옷은 각성 모습과 같음, 15세 기준(몸 강조·다리 벌린 자세 없음, 비치는 천 없음). 게임용은 `게임용/aw0~aw2.webp`(1344×752).
