# 두억시니 (달빛 극화체, 11/23)
참고 = 극화체 기준 T3_front + S4 두 장만, 두억시니는 글로만(원본 `../동료원본/cut11x`, `p11b`).
- 원본 일러스트 교체(사용자 확정): `../게임용/cut11x.webp`(job 3951dc1a). 원본 🔴 「가슴 확대 구도」 해결: 엉덩이에서 자르는 상체 구도. 검보라 긴 머리, 금 초승달 뿔, 연보라 피부, 혼천의 속 초승달, 검은 일식 달, 보라 그림자 소매·금 발톱.
  - 힉스필드 크레딧이 떨어져 배경은 직접 지움(흰색 테두리 flood fill + 큰 흰 덩어리 제거, 혼천의 속 초승달은 보호). 금 발톱 위쪽 흰 반사광이 배경과 붙어 조금 얇아짐.
