# 두억시니 (달빛 극화체, 11/23)
참고 = 극화체 기준 T3_front + S4 두 장만, 두억시니는 글로만(원본 `../동료원본/cut11x`, `p11b`).
- 원본 일러스트 교체(사용자 확정): `../게임용/cut11x.webp`(job 3951dc1a). 원본 🔴 「가슴 확대 구도」 해결: 엉덩이에서 자르는 상체 구도. 검보라 긴 머리, 금 초승달 뿔, 연보라 피부, 혼천의 속 초승달, 검은 일식 달, 보라 그림자 소매·금 발톱.
  - 힉스필드 크레딧이 떨어져 배경은 직접 지움(흰색 테두리 flood fill + 큰 흰 덩어리 제거, 혼천의 속 초승달은 보호). 금 발톱 위쪽 흰 반사광이 배경과 붙어 조금 얇아짐.
- 원본 게임 그림 교체(사용자 확정): `../게임용/p11b.webp`(266×280)·`p11b_hi`(job fb8fa366 → 상의 아래 가림 58ceeb8b, 배경 제거 65c3450c). 초승달에 앉은 자세 → 금빛 초승달 위에 두 발로 서서 혼천의를 들고 다른 손은 그림자 불꽃. 원본 🟡 「비키니」는 상의를 키워 해결.
- `A10_twin_moon_rings`: 각성 일러스트(1344×752) → 게임 `../게임용/aw11.webp`. 사용자 확정.
  - 1안 그림자 낫(job 5a256f0a)은 설녀(얼음 낫)·저승사자(명부 낫)와 겹쳐 사용자 선택 3안 「검은 달 쌍고리」로 바꿈(48559a25).
  - 고리칼 고침: 캐릭터 오른손(화면 왼쪽) 칼날 반대편 손잡이 쥐기(cd2ece5d) → 캐릭터 왼손(화면 오른쪽) 같은 구조로(81eb92bb, 팔 끊김은 직접 맞춤) → 90도 돌려 칼날 앞쪽·손바닥 쪽으로 쥠(e963c59a) → 손잡이를 곡선으로(fbfc7287, 최종). 모두 잘라 고쳐 붙임.
  - 검보라 그림자 두루마기, 금 초승달 뿔, 연보라 피부, 검은 일식 밤하늘, 날아가는 검은 초승달 칼날.
