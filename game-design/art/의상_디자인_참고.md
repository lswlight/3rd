# 의상 디자인 참고 노트 (스킨·각성2용)

사용자가 11/26 다른 게임의 스킨 화면 11장을 보여 주며 "추후 캐릭터 의상 디자인에 참고하도록 공부해"라고 함. 아래는 그 그림들에서 **디자인 원리만** 뽑아 정리한 것.

- **베끼지 않는다**: 다른 게임 캐릭터의 옷·이름·소품 조합을 그대로 가져오지 않는다. 원리(구조·비율·리듬)만 쓰고, 소재는 우리 세계관(한국 설화·한복·무속·도깨비)으로 바꾼다.
- 그 그림들은 저장소에 넣지 않고, 힉스필드 참고 이미지로도 쓰지 않는다(참고 그림은 극화체 기준 두 장만, 그림 규칙 그대로).
- 노출 고정값(그림 규칙): **가슴 약 65% 가림 · 배 드러냄 · 엉덩이는 살짝만 가림**. 아래 원리는 이 값 안에서 쓴다.

## 1. 본 것에서 뽑은 원리

### 1-1. 윗옷(가슴 65%를 가리는 여러 방법)
| 갈래 | 모양 | 우리식으로 바꾸면 |
|---|---|---|
| 홀터 + 가운데 고리 | 목에 걸고 가슴 가운데를 고리로 모음, 가운데가 깊게 파임 | 고리 대신 **노리개 매듭·옥가락지**로 모음 |
| 삼각 비키니형 | 끈으로 묶는 두 장, 위쪽이 드러남 | 비단 천 두 장 + **댕기 끈**으로 묶음 |
| 털 띠(반두) | 털 뭉치로 가슴만 감쌈, 몸에 끈을 감음 | 산군·불가사리류: **범 털·곰 털 띠 + 붉은 오랏줄** |
| 깊은 V 레오타드 | 목부터 배꼽 아래까지 길게 파임 + 가운데 끈 엮기 | 무녀복을 깊게 트고 **오방색 매듭 끈**으로 엮음 |
| 코르셋 + 하트 창 | 허리를 조이고 가슴 위만 창처럼 열림 | **저고리 깃을 뒤집은 창** + 허리띠(대대) |
| 차이나 깃 + 열쇠구멍 | 목은 닫히고 가슴 가운데만 동그랗게 뚫림 | **동정 달린 깃** + 가운데 열쇠구멍, 매듭 단추 |
| 짧은 캐미솔 + 잎 장식 | 가슴 바로 아래에서 끝나는 짧은 윗옷, 가장자리에 잎 무늬 | 짧은 **배자/저고리**, 가장자리에 매화·연잎 무늬 |
| 속 드러나는 갈라진 바디 | 몸 가운데를 따라 세로로 갈라지고 보석 이음 | 저승·귀신 계열: **가운데 세로 트임 + 옥 이음** |

### 1-2. 배(드러내는 방법을 다양하게)
- 맨배에 **허리 장신구**를 얹어 비어 보이지 않게: 금 사슬 허리띠에 술·작은 장식(노리개·방울·엽전·별 구슬)을 늘어뜨림.
- 레오타드처럼 이어진 옷이면 **옆구리를 크게 파서** 배·허리선을 보임.
- 세로 한 줄 장식(보석 이음·매듭)으로 배꼽 쪽 시선을 모음.
- 몸 그림(문신·무늬): 붉은 줄무늬 전투 문양, 푸른 덩굴 문신 → 우리식은 **부적 문양·오방색 줄·단청 무늬**.

### 1-3. 아래옷(엉덩이는 살짝, 다리는 길게)
- **짧은 아래 + 긴 겉천**: 짧은 아래옷 위에 앞이 열린 긴 천(뒤로 끌리거나 옆으로 날림). 우리식: 짧은 속바지 + **트인 겉치마·쓰개치마·도포 자락**.
- 허리에 두르는 **파레오**(한쪽으로 묶은 천) + 깃털·술 장식 → 우리식: 치마 한쪽을 걷어 묶고 **댕기·술**.
- **허벅지 띠**: 고리·리본·가터·끈을 허벅지에 한 줄 → 우리식: **비단 매듭 띠, 옥고리, 방울 띠**.
- **허벅지 스타킹** 무늬(비늘·망사·레이스) → 우리식: 용궁 = 비늘, 저승 = 망사, 하늘 = 구름 자수.
- 깃털·찢긴 천처럼 끝이 갈라진 치맛단(움직임이 보임).

### 1-4. 한 벌의 "대표 실루엣" 하나
멀리서도 누군지 알아보게 **크게 튀는 것 하나**만 둔다(여러 개면 산만).
- 아주 큰 모자(챙 넓은 모자, 레이스 모자) → 우리식: **큰 갓·전모·족두리·화관**
- 머리 뒤 큰 장식(초승달 고리, 가시 원) → 우리식: **달 바퀴·해 원반·부채 후광**
- 날개(흰 깃·검은 깃) → 우리식: **까치 깃·학 날개·도깨비불 날개**
- 큰 털 깃 → 우리식: **범 털 목도리**
- 큰 짐승 곁(사슴) → 우리식: **흰 사슴·범·해태**를 곁에

### 1-5. 반복 무늬(모티프) 하나로 통일
한 벌에 같은 무늬를 여러 곳에 되풀이: 장미(손목·가슴·허리), 하트(코르셋·리본·장식), 월계 잎(가슴단·띠), 깃털(머리·치마).
→ 우리식: 매화, 연꽃, 별, 방울, 엽전, 부적, 구름 중 **하나를 골라 3곳 이상** 되풀이.

### 1-6. 색
- **주색 2개 + 금속 1개**(금 또는 은). 예: 흰+하늘+금, 검정+보라+은, 빨강+검정+금.
- 비치는 천(망사 숄, 시스루 소매, 얇은 겉치마)으로 겹을 만들어 노출을 부드럽게.

### 1-7. 주제가 있는 스킨
스킨마다 한 줄 이야기와 상황이 있다(여름 바닷가, 온천, 사무실, 하녀, 봄 춤, 별의 여왕 등).
→ 우리식 주제 후보(겹치지 않게 돌려 씀):
| 주제 | 옷 방향 |
|---|---|
| 단오 | 창포물 머리, 그네, 짧은 저고리 + 날리는 치마, 수리취 무늬 |
| 칠석 | 은하수·까치·별 자수, 비치는 남보라 천 |
| 여름 계곡 | 물에 젖은 얇은 모시, 대나무 발·부채, 수박 |
| 한가위 | 달·토끼·송편 무늬, 금박 한복을 짧게 |
| 설날·연날리기 | 털 배자, 연·실패 소품, 빨강+흰 |
| 주막 주모 | 앞치마 + 짧은 저고리, 술병·쟁반 소품 |
| 서당·책방 | 안경, 붓·두루마리, 도포를 짧게 고친 차림 |
| 궁중 연회 | 화관·당의 + 깊게 트인 치마, 비단 부채 |
| 무녀 굿판 | 오방색 띠, 방울·부채, 쾌자 자락 |
| 도깨비 장터 밤 | 등불·엽전·도깨비불, 짧은 망토 |

### 1-8. 자세가 옷을 보여 준다
- 다리를 차올림(긴 스타킹·트임이 보임), 팔을 머리 위로(옆선·소매), 앉은 자세(다리 선), 돌아보는 자세(등·리본).
- 우리 게임 그림은 **오른쪽을 보는 공격 자세**가 기본이므로, 그 안에서 옷이 가장 잘 보이는 자세를 고른다(앞다리 굽힘 + 뒷다리 뻗음 = 트임·허벅지 띠가 보임).

## 2. 프롬프트에 쓸 말(영어)
- 윗옷: halter top gathered with a jade knot ring at the center · tie-string triangle silk top with ribbon (daenggi) strings · fur bandeau wrapped with red cords · deep plunging V with criss-cross lacing · corset with a cleavage window · mandarin collar with a keyhole cutout · cropped jeogori ending just under the bust
- 공통 노출: a top that covers about 65% of the bust, showing cleavage and the upper part · bare midriff (stomach uncovered) · the hips lightly covered
- 허리: gold chain belt with dangling norigae tassels / tiny bells / coins over the bare midriff
- 아래: short bottoms with a long open sheer overskirt trailing behind · sarong tied at one hip with tassels · thigh band with a jade ring and ribbon · thigh-high stockings with scale / lace / cloud embroidery pattern
- 실루엣: one oversized signature piece: wide-brim gat / flower crown / moon-wheel halo / magpie-feather wings / tiger-fur collar
- 무늬·색: repeat one motif (plum blossom / lotus / star / bell / coin) in three places · two main colors plus gold (or silver) metal accents · sheer layered fabric

## 3. 새 스킨을 만들 때 순서
1. 기준 캐릭터(얼굴·머리·체형·대표 소품) 고정
2. 노출 고정값(가슴 65%·배 드러냄·엉덩이 살짝) 고정
3. 주제 하나(1-7) → 대표 실루엣 하나(1-4) → 반복 무늬 하나(1-5) → 색 2+1(1-6)
4. 윗옷·허리·아래를 1-1~1-3에서 하나씩 골라 조합(같은 조합이 다른 캐릭터와 겹치지 않게 표에 기록)
5. 오른쪽을 보는 공격 자세 중 옷이 잘 보이는 것(1-8)
6. 인터넷에서 그 주제의 실제 한복·장신구 자료를 더 찾아 세부를 채움
