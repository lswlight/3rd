# 그믐 · 그림 만들기 규칙 (필수)

## 0. 최우선 규칙: 원본 그림체를 훼손하지 않는다 (사용자, 11/21)
- **다른 모든 요청(새 자세·새 옷·새 무기·연출)보다 원본 그림체 유지가 먼저다.** 둘이 부딪히면 그림체를 지키고, 요청은 그 안에서 할 수 있는 만큼만 한다.
- 원본 그림체 = 원본 기준 그림(1-1 표)의 얼굴 생김새, 선 굵기, 채색·광택, 몸 비율, 캐릭터 크기.
- 그림체가 조금이라도 달라 보이면 **사용자에게 보내지 않는다.** 다시 그리고, 그래도 안 되면 "이 요청은 그림체를 지키며 하기 어렵다"고 말한다.
- **얼굴은 정면으로 그리지 않는다.** 원본처럼 3/4 측면이나 옆얼굴로 둔다. 얼굴이 정면을 보면 그림체가 틀어진다(11/21 달래 시안에서 확인: 정면 얼굴인 「위로 뛰어 활」「사슬낫」은 틀어졌고, 측면 얼굴인 「초승달에 앉아 활」「월도」「고리칼」은 원본과 같음). 지시문에 "face in three-quarter view like the reference, not facing the camera" 를 넣는다.
- 바꾸는 폭이 작을수록 그림체가 잘 지켜진다: **색·옷 무늬 바꾸기 → 옷·소품·무기 바꾸기(원본 자세 유지) → 자세 바꾸기** 순서로 위험이 커진다. 큰 변경은 원본을 고쳐 그리는 방식(원본 한 장만 참고로 넣고 "바꿀 부분만 바꾸고 나머지는 그대로")을 먼저 쓴다.

**새 그림은 반드시 기존 그림을 참고로 넣어 그린다. 그림 기법(그림체)은 바꾸지 않는다.** (사용자 결정, 11/21)

## 1. 무엇을 참고로 넣나
첫 번째 참고 그림은 항상 **같은 종류의 기존 그림**입니다(그림체 기준). 옷·자세·캐릭터 참고는 두 번째부터 넣습니다.

| 만드는 그림 | 첫 번째 참고(그림체) | 두 번째 이후 참고 |

| 일러스트·컷인(정사각) | 그 캐릭터의 기존 일러스트(`hc0x`·`hc1_o0`·`hc2n`, 동료 `cut*x`, 새 캐릭터 `art/새캐릭터/일러스트/`) | 옷·소품 |

- 게임 그림을 그릴 때 일러스트를, 일러스트를 그릴 때 게임 그림을 첫 참고로 넣지 않는다(얼굴·선이 달라짐).
- 참고 없이 글로만 그리지 않는다.
- **첫 참고는 언제나 「원본 기준 그림」(아래 1-1 표)이다. 새로 생성한 그림(시안·고른 안 포함)을 첫 참고로 넣지 않는다.** 새 그림을 다시 참고로 넣으면 그릴 때마다 그림체가 조금씩 더 벗어난다(11/21 달래 시안에서 실제로 생김). 고른 시안은 두 번째 참고로 넣어 「옷·색·자세만」 가져온다.

## 2. 지시문 첫 문장 (고정)
```
Copy the EXACT art style of the first reference image: same rendering, same bold clean line art, same saturated cel-plus-gloss coloring, same lighting and same camera scale (character large and close, filling most of the frame). Same face and hair as the reference.
```
그다음에 옷·자세·배경만 적는다. "watercolor", "painterly", "soft" 같은 그림체 말은 쓰지 않는다.

## 3. 보내기 전 확인
1. 새 그림을 **원본 기준 그림 옆에 나란히** 놓고 비교한다(직전 시안과 비교하지 않음): 선 굵기, 채색, 얼굴 생김새, 몸 비율(가슴 등이 원본보다 커지지 않았는지), 캐릭터 크기.
2. 다르면 사용자에게 보내지 않고 다시 그린다.
3. 15세 기준(기획 3): 수영복 수준까지, 몸 강조 구도·누운 자세·다리 벌린 자세·비치는 천 없음.
4. 배경을 지우는 그림은 Higgsfield 배경 제거 후 테두리 1픽셀 다듬기(흰 띠 제거), 어두운 바탕에 확대해서 흰 띠·남은 흰 덩어리가 없는지 본다.
