# 달래 각성 일러스트 시안 (11/21)
그림 규칙대로 기존 달래 각성 일러스트(`../각성/awake_dallae.png`)를 첫 참고로 넣고, 노출 정도는 그대로 둔 채 한 가지씩만 바꿈.
- `A_outfit`: 옷 디자인 변경(비키니+리본 → 봉황 깃털 무늬 갑옷 가슴가리개, 한쪽 어깨 갑옷, 갑옷판 짧은 치마, 무릎 정강이받이). 색은 빨강·금 유지
- `B_pose`: 자세 변경(공중으로 뛰어올라 몸을 틀며 오른쪽 아래로 활 쏨). 옷은 그대로
- `C_color`: 의상과 색 변경(은빛·보라 달빛 의상, 은빛 활·연보라 화살, 푸른 달 배경)

## 2차 (사용자: C안 의상으로, 다른 자세·다른 무기)
C안(은빛·보라)을 첫 참고로, 노출 유지. 등을 돌린 자세 시안은 엉덩이 강조라 15세 기준에 걸려 뺐고, 처음 무기 시안은 자세가 원래와 같아 다시 그림.
- 자세: `P1_jumpup` 앞을 보고 위로 뛰어올라 하늘로 활 / `P2_moonsit` 초승달에 옆으로 앉아 활
- 무기: `W1_glaive` 월도(초승달 날 긴 창칼) 돌려 베기 / `W2_rings` 초승달 고리칼 둘, 날아들며 던지기 / `W3_chain` 달빛 사슬낫, 지붕 위에서 머리 위로 돌림

## 3차 (그림체 고정)
2차는 C안(생성본)을 첫 참고로 넣어 그림체가 더 벗어남 → 원본 `awake_dallae.png` 를 첫 참고, C안은 옷·색 참고로만 넣어 같은 5장을 다시 그려 덮어씀.

## 사용자 판정 (11/21)
- 원본 그림체와 같음: **P2_moonsit(초승달에 앉아 활), W1_glaive(월도), W2_rings(고리칼)**
- 틀어짐: P1_jumpup, W3_chain → 둘 다 얼굴이 정면. 앞으로 얼굴은 3/4 측면으로(그림_규칙 0번)
