# 탈 도깨비 각성 「불 방망이」 (11/23, 달빛 극화체)
참고 = 극화체 기준 T3_front + S4 두 장만, 탈 도깨비는 글로만(원본 `../동료원본/cut3x`, `p3` 보고 옮김). 원본 그림은 다시 그리지 않음.
- `A2_fire_club`: 각성 일러스트(1344×752) → 게임 `../게임용/aw3.webp`. 사용자 확정.
  - 1안(e629cacb)은 가슴을 덮어 원본 디자인과 달라짐 → 사용자 「가슴 덮지 말고 디자인 유지, 노출 안 걸리게」 → 상의만 원본 홀터넥 디자인 + 적당한 V 트임으로 고침(820433ee) = 확정.
  - 불 방망이를 한 손으로 쥐고 어깨에 걸침, 푸른 도깨비불 셋, 주황·검정 장터 광대 갑옷, 오방색 리본, 밤 장터.
- 노출 기준(사용자 11/23): 원본 디자인 유지, 가슴골은 보여도 되나 과하지 않게, 가슴 확대 구도 없음.
