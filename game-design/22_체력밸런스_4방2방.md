# 그믐: 달을 훔친 자 · 기획 22. 체력 밸런스: 잔챙이 4방 · 대장 2방

사용자 요청(11/23): 캐릭터 체력이 너무 많다. **일반 몹 기준 4방, 대장 2방 맞으면 쓰러지게.** 세부 수치는 기획방이 정함.

## 0. 지금 (개발판 코드 기준)
| 항목 | 지금 값 | 실제 맞는 횟수(체력 100 기준) |
|---|---|---|
| 캐릭터 체력 | 85~130 (23명 제각각) | |
| 잔챙이 탄 | 8 × 본편 1.3 = 10 | **10방** |
| 문지기 탄 / 수문장·대장 탄 | 10·12 × 1.3 = 13·16 | 8방 / 7방 |
| 대장 큰 공격(반지름 9 이상) | 25 × 1.3 = 33 | 4방 |
| 몸 부딪힘 | 15 × 1.3 = 20 | 5방 |
| 맞은 뒤 무적 | 0.8초 | |
→ 거의 안 죽음. 교대 동료까지 있어 사실상 20방 가까이 버팀.

## 1. 기준: 「몇 방에 쓰러지나」로 정함
- 피해를 **「보통 체력 100」 기준 몇 방**으로 정하고, 본편 배수(`BALANCE2.dmgK` 1.3)는 **1로** 바꿔 아래 숫자를 그대로 씀(헷갈림 방지).
- 캐릭터 체력은 23명 제각각 → **3단계로 묶음**. 단계마다 정확히 몇 방인지 보이게.

### 1-1. 캐릭터 체력 3단계
| 단계 | 체력 | 잔챙이 | 대장 | 캐릭터 (지금 체력) |
|---|---|---|---|---|
| 가벼움 | **90** | 4방 | 2방 | 달래(85), 구미호(90), 설녀(90), 홍길동(90), 직녀(90) |
| 보통 | **100** | 4방 | 2방 | 한별·나린·탈 도깨비·이무기·쇠 도깨비·두억시니·도깨비 여왕·저승사자·바리공주·우렁각시·처용·세오녀·강림도령 |
| 튼튼 | **115** | **5방** | **3방** | 불가사리(130), 장승 자매(125), 용왕의 장수(115), 해태(125), 산군(120) |
- 가벼움과 보통은 맞는 횟수는 같고, 가벼움은 회복·장비로 한 방 더 버티기가 어려운 정도의 차이. 가벼운 캐릭터는 대신 공격·속도가 높은 캐릭터들.

### 1-2. 받는 피해 (본편, 배수 없이 이 값 그대로)
| 맞는 것 | 피해 | 보통(100) 몇 방 |
|---|---|---|
| 잔챙이 탄 (`mob`) | **26** | 4방 |
| 몸 부딪힘 (`body`, 잔챙이·문지기) | **26** | 4방 |
| 장애물 탄·그 밖 (`def`) | **26** | 4방 |
| 문지기 탄 (`mini`) · 정예 적 | **30** | 4방(조금 더 아픔) |
| 수문장 탄 (`mid`) | **36** | 3방 |
| 대장 탄 (`boss`) | **52** | 2방 |
| 대장 큰 공격 (`big`) | **52** + 밀려남 | 2방 |
| 대장 몸 부딪힘 | **52** | 2방 |
- 대장 탄과 큰 공격 피해는 같게(사용자: 「대장 2방」). 큰 공격은 대신 맞으면 뒤로 밀려나고 화면이 크게 흔들림.
- 탑·끝없는 모드도 같은 값. 도깨비 오락실(아케이드)은 지금처럼 체력이 줄지 않음.

## 2. 한 방이 무거워진 만큼 바꿀 것

### 2-1. 맞은 뒤
| 항목 | 지금 | 바꿈 | 이유 |
|---|---|---|---|
| 맞은 뒤 무적 | 0.8초 | **1.3초** | 탄 많은 곳에서 연달아 2방에 쓰러지는 것 방지 |
| 맞은 순간 주변 탄 지우기 | 없음 | 반경 60 안 적 탄 지움 | 같은 이유 |
| 체력 25% 아래 | 표시 없음 | 화면 가장자리 붉게 맥박 + 심장 소리 | 「한 방 남았다」를 알게 |
| 교대·자동 교대 직후 무적 | — | **1.5초** | 들어오자마자 맞지 않게 |

### 2-2. 회복
| 항목 | 지금 | 바꿈 |
|---|---|---|
| 떡 | +20 | **+26** (잔챙이 한 방) |
| 곶감 | +35 | **+52** (대장 한 방) |
| 떡 드롭 | 본편 3% | **4%** |
| 구간 사이 회복 | 본편 20% | **35%** |
| 쉬는 동료 회복 | 초당 0.2% | 그대로 |
| 봉인 성공 | +8 | **+13** (반 방) |
| 탑 축복 「은하수」 | +40 | **+52** |

### 2-3. 장비·성장 (한 방 단위로 맞춤)
| 항목 | 지금 | 바꿈 | 뜻 |
|---|---|---|---|
| 「목숨 +1」 장비 | 최대 체력 +20 | **+26** | 잔챙이 한 방 더 |
| 캐릭터 Lv7 보상 | +15 | **+13** | 반 방(두 개 모으면 한 방) |
| 받는 피해 감소 상한 | 25% | **15%** | 25%면 잔챙이 6방이 되어 목표가 무너짐 |
| 소금 부적(피해 절반) 상한 | 45% | **30%** | 같은 이유 |
| 저승 명부(쓰러질 때 1번 살아남) | 체력 30 | **체력 26** (한 방) |
| 탑 「질긴 목숨」 | +25 | **+26** |
| 탑 「도깨비와의 거래」 | 최대 체력 −30% | **−26** (한 방 덜) |
- 성장 끝(목숨 장비 + Lv7 + 질긴 목숨)이어도 보통 캐릭터 체력 165 → 잔챙이 7방·대장 4방. 너무 질기지 않게 상한.

### 2-4. 난이도가 갑자기 오르지 않게
| 항목 | 지금 | 바꿈 |
|---|---|---|
| 본편 탄 밀도 `bulletK` | 1.3 | **그대로 1.3** (사용자 11/23) |
| 본편 탄 속도 `seqK` | 1.5 | 그대로 |
| 정예 적 | 구간마다 1~2 | 그대로 |
| 판정 | 그대로 | 그대로(작은 판정 원 유지) |
- 탄 밀도는 그대로 두고 한 방만 무겁게 → 긴장감을 크게 올림. 대신 2-1의 무적 1.3초·탄 지우기·위험 표시로 억울한 연속 피격을 막음.

### 2-5. 수호형 협력·방어 효과 가치 오름
- 축복 방패, 수호형 협력(막고 반격), 우렁각시 소라 방패 등 **막는 효과 한 번 = 한 방 살림**이 되어 가치가 커짐. 수치는 그대로 두고 측정 후 조정.

## 3. 접근성
- 설정에 「쉬움: 받는 피해 ×0.6」(잔챙이 7방·대장 4방). 기본은 꺼짐. 쉬움으로 깬 기록은 순위표에 따로.

## 4. 목표와 측정
| 항목 | 목표 |
|---|---|
| 1층 처음 하는 사람 | 대장까지 가며 맞는 횟수 3~6번, 두 캐릭터 중 하나 쓰러질 수도 |
| 1층 익숙한 사람 | 무피격 또는 1~2번 |
| 대장전 | 대장 큰 공격은 반드시 예고(지금처럼), 예고 없이 2방에 끝나는 일 없게 |
| 측정 | 개발 도구에 「받은 피해 기록」(무엇에 몇 번 맞았나) 표시, 1·3·5층 대장 기준으로 3판씩 기록 |

## 5. 개발 요청 순서
1. `BATTLE.hp` 23명을 3단계(90/100/115)로, `BATTLE.dmg`를 1-2 표로, `BALANCE2.dmgK` 1 → 2-1 무적·탄 지우기·위험 표시
2. 2-2 회복, 2-3 장비·성장 수치 (탄 밀도는 그대로)
3. 3 쉬움 설정, 4 받은 피해 기록 + 측정값 보고
