# 그믐: 달을 훔친 자 · 기획 17. 각성 모습·봉인 연출·대장 기술·버튼 배치·협력 다시 만들기

대상: 기획 16까지 적용판
사용자 반응:
1. 달래 각성 일러스트는 유지(나중에 검토). **확대(줌)는 굳이 안 해도 됨**
2. 각성 뒤 **크기만 커져서 단조로움** → 각성하면 **옷과 움직임이 바뀌어야 함**
3. 수문장 봉인에 **효과가 없어 봉인됐는지 모름**, 봉인하면 **다른 기능이 생겨야 함**
4. 대장 공격 기술이 다 같아 무료함 → **동료일 때 쓰는 기술을 대장도 쓰게**
5. 공격 버튼이 오른쪽 화면을 너무 가림 → **오른쪽 아래 2줄 배열**로
6. **검토판에서는 각성을 계속 쓸 수 있게**
7. 협력 스킬이 재미없음 → **다른 방식으로 다시 기획**

---

## 1. 각성 일러스트: 확대 없앰
- 모든 캐릭터 공통으로 **확대(줌)를 끔.** 일러스트는 화면에 꽉 찬 채로 1.2초.
- 대신 **빛 입자·달빛 후광·옷자락만 살짝 흔들리는 효과**(그림 위에 빛 층을 겹침)와 「달빛 각성」 붓글씨, 대사 띠.
- 달래 일러스트는 그대로 두고 나중에 다시 검토.

## 2. 각성 모습: 옷과 움직임이 바뀌게
| 항목 | 지금 | 바뀐 뒤 |
|---|---|---|
| 겉모습 | 그림이 1.4배 커짐 | **각성 전용 게임 캐릭터 그림으로 바뀜**(각성 일러스트의 옷과 같은 의상, 투명 배경). 크기는 1.15배만 |
| 기본 움직임 | 위아래로 살짝 흔들림 | **공중에 뜬 채 천천히 회전하는 달빛 고리**, 뒤로 **잔상 3겹**(캐릭터 색), 머리카락·리본 쪽에 빛 입자 |
| 이동 | 같음 | 움직이면 **달빛 꼬리**, 빠르게 움직이면 짧은 순간이동 잔상 |
| 공격 | 같은 탄 | 각성 전용 기본 공격(한별: 비취 바람 칼날, 달래: 금빛 화살 3갈래, 나린: 별빛 물방울). 쏠 때마다 몸 앞에 작은 빛 번쩍임 |
| 스킬 | 같음 | 캐릭터 스킬이 **각성판**으로(한별 회오리 → 쌍회오리, 달래 세 발 → 다섯 발 관통, 나린 물줄기 → 은하수 폭포) |
| 끝날 때 | 원래 크기로 | 빛이 터지며 원래 옷으로 돌아오는 0.4초 연출 |

### 그림 작업 (각성 게임 캐릭터 3장)
- 각성 일러스트를 참고로 **게임 캐릭터용 전신 그림(투명 배경, 지금 `hp*.webp` 와 같은 크기)** 을 만듦: 한별·달래·나린.
- 기획 세션에서 Higgsfield로 만들고 배경을 지워 넘김(장당 약 0.25 + 배경 제거 크레딧).
- 그림이 들어오기 전에는 지금 그림에 **각성 색 덧칠 + 잔상 + 고리**로 먼저 구현.

## 3. 봉인: 보이게, 그리고 봉인하면 생기는 힘

### 3-1. 봉인 연출 (지금은 효과가 없음)
| 순간 | 연출 |
|---|---|
| 기회 | 요괴 체력 20% 아래 → 요괴 몸에 **붉은 사슬 무늬**가 감기고 머리 위 「封」이 크게 깜빡 + '딸랑' 방울 소리. 봉인 버튼도 같이 빛남 |
| 던짐 | 노란 부적이 빙글빙글 날아감(0.3초) |
| 성공 | **0.4초 게임 멈춤** → 부적이 요괴에 붙고 사슬이 조여듦 → 요괴가 **소용돌이치며 작아져 부적 속으로 빨려 들어감** → 부적이 주인공에게 날아와 흡수 → 화면 가운데 붉은 **「封印」 도장** + 「○○ 봉인!」 |
| 실패 | 부적이 불타며 재가 흩어지고 「실패!」 + 낮은 소리. 요괴는 그대로 쓰러짐 |
| 화면 표시 | 왼쪽 위 체력바 옆에 **이번 판 봉인 수**(부적 아이콘 ×3) |

### 3-2. 봉인하면 생기는 힘 (판 안에서 바로)
봉인하면 **그 판이 끝날 때까지 그 요괴가 「수호령」이 되어 따라다닙니다.**
| 항목 | 내용 |
|---|---|
| 수호령 | 반투명 푸른 빛의 요괴가 주인공 뒤를 따라다니며 **자기 탄 패턴으로 자동 공격**(약하게) |
| 최대 | 2마리(새로 봉인하면 오래된 쪽과 교체) |
| 수문장 봉인 | 수문장은 수호령 대신 **「요괴 기술」 버튼**이 그 판 동안 생김: 그 수문장의 큰 기술 하나를 1번 쓸 수 있음(예: 불 호랑이 → 불길 돌진, 바위 거인 → 바위 굴리기, 섬 고래 → 물기둥) |
| 영구 | 지금처럼 요괴 부적함에 쌓이고 레벨이 오름(기획 15) |
| 보상 | 봉인 성공마다 체력 +8, 달빛 게이지 +15% |

→ 봉인하는 순간 **바로 내 편이 늘어나는** 것이 눈에 보이게 됩니다.

## 4. 대장이 동료 기술을 쓴다
대장 10명은 나중에 동료가 됩니다. **동료일 때 쓰는 기술을 대장으로 먼저 보여 주면**, 패턴이 다양해지고 "이 기술을 내 편으로 쓰고 싶다"는 동기도 생깁니다.

### 4-1. 규칙
- 대장마다 기존 탄막 패턴 2개 + **동료 기술 3개(대장판)**: 캐릭터 스킬 · 협력 스킬 · 등장 일격을 적 버전으로.
- 기술마다 **예고**(0.8초): 대장 몸이 기술 색으로 빛나고 기술 이름 띠가 위에 뜸.
- 2단계(체력 50%)에서 **대장 필살기**: 대장 컷인(기존 대장 그림) + 화면 큰 기술. 피할 길이 반드시 있음.

### 4-2. 대장별 기술 (기획 14의 동료 기술을 적 버전으로)
| 층 | 대장 | 대장판 기술 3개 | 2단계 필살기 |
|---|---|---|---|
| 1 | 탈 도깨비 | 도깨비불 세 갈래 · 불 춤(대장 둘레 도는 불) · 탈 던지기 | 도깨비불 잔치(화면 가득 불꽃 비, 틈 있음) |
| 2 | 불가사리 | 쇠사슬 철퇴(주인공을 끌어당김) · **탄 먹기(내 탄을 3초 흡수)** · 쇠공 굴리기 | 쇠 소나기 |
| 3 | 구미호 | 여우불 구슬(따라옴) · **분신 둘** · 홀림(주인공 1초 조작 반대로) | 아홉 꼬리 홀림 |
| 4 | 장승 자매 | 장승 내려찍기 · **수호 기둥(대장 앞 탄 막기)** · 쌍 몽둥이 | 수호 장승진 |
| 5 | 설녀 | 눈보라 창 · **얼음 지대(주인공 쪽 느려짐)** · 얼음 파편 | 만년설 눈보라 |
| 6 | 이무기 | 번개 물결 · 번개 세례 · 몸통 박치기 돌진 | 승천하지 못한 파도 |
| 7 | 용왕의 장수 | 월도 물결(밀어냄) · **해일 방벽** · 월도 베기 | 용궁 월도 해일 |
| 8 | 쇠 도깨비 | 칼비 · **벼림(대장 공격력 ↑, 몸이 붉게)** · 망치 내려찍기 | 천 자루 칼비 |
| 9 | 두억시니 | 검은 달 · **어둠 걷기(내 탄 지움 + 순간 이동)** · 그림자 습격 | 검은 달 |
| 10 | 도깨비 여왕 | 금 방망이 · **뚝딱 축복(대장 회복)** · 금 나와라 뚝딱 | 금 나와라 뚝딱 + 동료들 기술 연속 |

- 굵은 글씨는 "보조형 기술"로, 대장이 쓰면 **풀어야 할 상황**이 생김(탄 먹기 중엔 스킬로, 수호 기둥은 연계로 부숨, 뚝딱 축복은 봉인 부적으로 끊기 등).
- 대장을 이기고 동료로 데려오면 「이제 이 기술은 내 것!」 안내.

## 5. 버튼 배치: 오른쪽 아래 2줄
모형: `game-design/mockup/전투개편/버튼배치_2열.png`
```
          [교대] [부적] [각성]
          [협력] [무기] [스킬]   ← 오른쪽 아래 모서리
```
- 버튼 6개를 **3×2 격자**로 오른쪽 아래 모서리에 모음. 지름 78(게임 화면 1280 기준), 간격 10.
- 엄지가 가장 쉽게 닿는 **오른쪽 아래 끝에 「스킬」**, 그 왼쪽 무기, 그 왼쪽 협력. 윗줄은 덜 자주 쓰는 교대·부적·각성.
- **반투명**(배경 55%), 쿨타임 부채꼴.
- 봉인 버튼(기회 있을 때만)과 수문장 「요괴 기술」 버튼은 **격자 위에 잠깐 떠오름**.
- 설정: 버튼 크기(작게·보통·크게), 투명도, **왼손 배치**(좌우 뒤집기).

## 6. 검토판 개발 도구
개발판(`TEST_UNLOCK`)에서 일시정지 화면에 **「개발 도구」** 칸:
| 켜기/끄기 | 내용 |
|---|---|
| 각성 무한 | 달빛 게이지 늘 가득, 각성이 끝나면 바로 다시 쓸 수 있음 |
| 쿨타임 0 | 모든 스킬·협력·무기 쿨 없음 |
| 무적 | 체력이 줄지 않음 |
| 부적 무한 | 필살기·합체 계속 |
| 봉인 100% | 봉인 확률 100%, 체력 조건 없이 언제나 |
| 층·구간 바로 가기 | 아무 층, 대장전 바로 시작 |
| `?dps=1` 표 | 지금 있는 것 유지 |
출시판에서는 이 칸이 보이지 않음.

## 7. 협력 스킬 다시 만들기
지금 협력은 "동료가 효과 하나를 내고 끝" → 손맛이 없음. 동료를 **세 가지 방식**으로 나눠, 버튼을 누르는 방법과 결과가 다르게 합니다.

### 7-1. 세 가지 협력 방식
| 방식 | 누르는 법 | 무엇이 일어나나 | 손맛 |
|---|---|---|---|
| **지휘형** (원거리·마법 동료) | 협력 버튼을 **누른 채 화면 위로 끌어서 위치를 정하고 뗌** | 동료가 그 자리로 날아가 큰 기술을 펼침(범위 표시가 손가락을 따라감) | 원하는 곳에 정확히 떨어뜨리는 맛 |
| **탑승형** (탈것이 될 수 있는 동료) | 협력 버튼 톡 | 동료가 **탈것으로 변해 주인공이 5초 올라탐**. 탈것 동안 이동이 빨라지고 몸통 박치기로 적을 쓸어버림, 탈것 전용 공격 | 질주하며 휩쓰는 맛 |
| **수호형** (방어 동료) | 대장 큰 공격 **예고가 뜰 때** 협력 버튼 | 동료가 앞에 나서 **막고 반격**. 예고 끝 0.3초 안에 누르면 「완벽 반격!」(피해 2배 + 대장 1초 비틀거림) | 타이밍 맞추는 맛(받아치기) |

### 7-2. 동료별 방식
| 방식 | 동료 |
|---|---|
| 지휘형 | 한별(회오리 낙하), 달래(화살비 낙하), 구미호(여우불 폭발), 설녀(얼음 지대), 쇠 도깨비(칼비 낙하), 도깨비 여왕(금 방망이 낙하), 직녀, 세오녀, 처용 |
| 탑승형 | **이무기**(용이 되어 태움), **용왕의 장수**(현무 거북), **산군**(호랑이), **해태**, **나린**(구름 은하수 수레), 탈 도깨비(도깨비불 수레) |
| 수호형 | 장승 자매(장승 방패), 불가사리(쇠 몸으로 막음), 두억시니(어둠으로 삼킴), 우렁각시(껍데기), 저승사자(사슬로 묶어 반격), 바리공주, 홍길동(분신으로 받아침), 강림도령 |

- 탑승형은 기존 동료 그림 중 **탈것을 탄 그림**(이무기, 용왕의 장수·거북 등)을 그대로 쓰고, 주인공 그림을 그 위에 얹음.
- 버튼 모양에 방식 아이콘(손가락 끌기 / 말발굽 / 방패)을 작게 표시해 무엇을 하는지 알 수 있게.

### 7-3. 협력 게이지
- 쿨타임 대신 **협력 게이지**: 동료가 옆에서 지원 사격으로 맞힐 때마다 참. 가득 차면 버튼이 동료 얼굴과 함께 빛나고 동료가 말함(기획 13a).
- 수호형은 예고가 나올 때만 쓸 수 있으므로 게이지가 차 있으면 예고 순간 버튼이 크게 깜빡.

## 8. 요청 순서
1. 6번 개발 도구(검토가 쉬워짐)
2. 5번 버튼 배치 2줄
3. 3번 봉인 연출 + 수호령·요괴 기술
4. 7번 협력 세 방식
5. 4번 대장 동료 기술(1층부터)
6. 1·2번 각성(확대 없앰, 각성 모습·움직임) — 각성 게임 캐릭터 그림은 기획 세션이 만들어 넘김
