# 그믐: 달을 훔친 자 · 기획 1. 첫 10분 경험

대상 코드: `game/geumeum/dokkaebi-shooter.html` (브랜치 `ccr-697f653c-km1tsc`, 커밋 a751965)
목표: 처음 설치한 사람이 **10분 안에 1층 대장을 이기고**, 조작 4가지(이동·기 모으기·부적·교대)를 자연스럽게 익히며, "다음 층도 해 보고 싶다"는 상태로 첫 판을 끝낸다.

## 3. 프롤로그 (새로 추가)

결말(`ENDING`)과 같은 방식(검은 화면 + 글 + "화면을 누르면 넘어갑니다")으로 3장면. 처음 한 번만 나오고 건너뛰기 버튼을 둔다.

1. `그믐밤, 하늘에서 달이 사라졌다.\n도깨비 여왕이 달을 훔쳐 구름 위 탑에 숨겼다는 소문이 돌았다.`
2. `탑의 층마다 세상에서 떼어 간 땅이 갇혀 있고,\n층마다 홀린 문지기가 길을 막고 있다.`
3. `부채 도사 한별 「달을 되찾으러 가겠소. 통행세는 부채 바람으로 치르지.」`

끝나면 캐릭터 선택 화면을 거치지 않고 바로 `newGame(0)` 으로 1-1을 시작한다.

## 4. 게임 속 안내 말풍선 (튜토리얼)

### 4-1. 동작 방식
- 저장: `SAVE.tut = {}` 에 본 안내의 키를 적는다. 한 번 본 안내는 다시 안 나온다.
- 표시: 화면 위쪽 가운데에 반투명 띠 한 줄(기존 `banner()` 보다 작게). **게임은 멈추지 않는다.**
- 버튼 강조: 해당 터치 버튼(`.tb`)에 `pulse` 클래스(테두리가 금색으로 깜빡임).
- 사라지는 조건: 아래 표의 "완료 조건"을 하면 즉시, 아니면 8초 뒤.
- `TEST_UNLOCK` 이 켜진 개발판에서는 안내를 끈다(시험할 때 방해되지 않게). 설정 화면에 "안내 다시 보기" 버튼을 둔다(`SAVE.tut = {}`).

### 4-2. 안내 목록

| 키 | 나오는 때 | 문구 | 강조 버튼 | 완료 조건 |
|---|---|---|---|---|
| `move` | 1-1 시작 1초 뒤 | 화면을 끌어서 움직이세요. 공격은 저절로 나갑니다 | 없음 | 손가락으로 1초 이상 끌기 |
| `coin` | 처음 엽전이 화면에 떨어질 때 | 엽전을 주우면 골드가 쌓입니다 | 없음 | 엽전 1개 줍기 |
| `charge` | 첫 문지기 등장 직후 | 「기」를 꾹 눌렀다 떼면 강한 공격이 나갑니다 | 기 | 기 모으기 1번 쏘기 |
| `bomb` | 수문장 등장 직후, 또는 화면에 탄이 40개를 넘을 때 | 위험할 땐 「부적」! 탄을 지우고 크게 때립니다 | 부적 | 부적 1번 쓰기 |
| `hitbox` | 1-2에서 탄이 몸 가까이(판정 반경 3배 안) 처음 스칠 때 | 맞는 곳은 몸 가운데 흰 점 하나뿐입니다 | 없음 | 8초 뒤 |
| `item` | 처음 힘·부적·목숨 구슬이 나올 때 | 붉은 구슬은 힘, 푸른 구슬은 부적, 초록 구슬은 목숨 | 없음 | 구슬 줍기 |
| `boss` | 1-3 대장 등장 | 대장은 체력이 줄면 모습이 바뀝니다. 부적을 아껴 두세요 | 없음 | 8초 뒤 |
| `swap` | 동료를 처음 데리고 출발한 구간 시작 | 「교대」로 동료와 자리를 바꿉니다. 바꾸는 순간 잠깐 무적! | 교대 | 교대 1번 하기 |
| `arc` | 처음 아케이드 구간(2층 3구간) | (기존 아케이드 설명 화면을 그대로 씀) | | |

### 4-3. 첫 판 보호
- 1층 보통 난이도에서 처음 쓰러지면 한 번은 그 자리에서 **무료로 다시 일어선다**(`SAVE.tut.save1`). 문구: `다시 일어섰다! 처음 한 번은 탑이 봐줍니다`.
- 1-1은 첫 판에 한해 적 탄 속도 0.85배(`G.rank` 에 곱함). 2판째부터는 원래대로.

## 5. 첫 화면 버튼을 단계적으로 열기

진행 조건은 이미 있는 `SAVE.stars`(보통 난이도 구간 번호 0~29)로 판단한다. 열리기 전 버튼은 **숨긴다**(자물쇠로 보여 주지 않는다). 처음 열릴 때 그 버튼이 금색으로 깜빡이고 `새로 열림!` 표시가 붙는다.

| 단계 | 조건 | 새로 보이는 것 | 열릴 때 한 줄 안내 |
|---|---|---|---|
| 0 | 처음 실행 | 출발 버튼만 (프롤로그 후 바로 1-1) | |
| 1 | 1-1 깸 (`stars[0]`) | 캐릭터 3명 고르기, 구간 고르기 | 세 사람은 빠르기·화력·범위가 다릅니다 |
| 2 | 1-3 깸 (`stars[2]`) | 동료 고르기, 교대 버튼, 도깨비 탑 지도, 잠긴 대장 캐릭터 칸 | 쓰러뜨린 대장은 골드로 동료가 됩니다 |
| 3 | 2-3 깸 (`stars[5]`) | 강화, 오늘의 임무 | 골드로 캐릭터를 강하게 만들 수 있습니다 |
| 4 | 3-3 깸 (`stars[8]`) 또는 장비를 처음 얻음 | 장비 | 장비는 모든 캐릭터가 함께 씁니다 |
| 5 | 처음 달조각을 얻음 (임무 완료, 별 30개 등) | 달조각 표시, 상점(결제) | 달조각으로 동료를 바로 데려올 수 있습니다 |
| 6 | 10층 깸 (`stars[29]`) | 난이도, 무한의 탑 | 어려움 난이도와 무한의 탑이 열렸습니다 |

- 첫 구매 묶음(`starter_pack`) 안내는 **5단계 이후, 그리고 대장에게 처음 졌을 때** 한 번만 띄운다.
- 개발판(`TEST_UNLOCK = true`)에서는 지금처럼 모두 보인다.

## 6. 1층 대장 뒤 동료 제안 고치기

지금은 대장을 이기면 바로 "1만 골드로 동료로 삼기 / 한 판 써 보기" 창이 뜬다. 첫 판에 골드는 보통 1만에 못 미치므로 "골드 부족"이 먼저 보인다.

- 1층 대장에 한해 버튼 순서를 바꾼다: **「한 판 써 보기」를 크게(기본 선택)**, 「동료로 삼기 (1만 골드)」는 작게.
- 창 아래에 목표를 보여 준다: `지금 골드 3,240 / 10,000 · 층을 오를수록 골드를 더 받습니다`.
- 체험 판에서는 시작 때 `체험 중 · 이 판이 끝나면 다시 골드로 데려올 수 있습니다` 안내를 띄운다.

## 7. 설명을 앱 안에서 다시 볼 수 있게

- 일시정지 화면에 「도움말」 버튼을 추가해, 지금 숨겨진 `.help` 내용(조작, 세 사람, 알아둘 것)을 같은 글 그대로 띄운다.
- 키보드 조작 줄(방향키, Z, X, C, V, P)은 터치 기기(`pointer:coarse`)에서 숨기고 터치 설명만 보여 준다.

## 8. 잘 됐는지 확인하는 법 (출시 전 시험)

처음 해 보는 사람 2~3명(가족·지인)에게 설명 없이 휴대폰을 건네고 지켜본다.

| 확인할 것 | 목표 |
|---|---|
| 10분 안에 1층 대장을 이겼나 | 3명 중 2명 이상 |
| 「기 모으기」를 누가 알려 주지 않아도 썼나 | 전원 |
| 1-1을 별 둘 이상으로 깼나 | 3명 중 2명 이상 |
| 첫 판이 끝나고 "더 해도 돼?"라고 했나 | 1명 이상 |
| 어디서 멈칫했나 (기록) | 다음 기획에 반영 |
