# 그믐: 달을 훔친 자 · 기획 30. 메인 게임을 「달밤 진법」으로 (안)

사용자 요청(11/25): 달밤 진법(오토배틀러)을 **메인 게임**으로 바꾸고 싶다. 롤토체스처럼 재미있으니까. 그리고 **공격 이펙트(기획 29)가 진법 싸움에 적용**되게.

## 0. 한 줄 요약
게임을 켜면 바로 「달밤 진법」으로 들어가고, 본편의 이야기(10층 대장·달조각)는 **진법의 「장(章)」** 으로 옮긴다. 지금의 슈팅 본편은 장터의 **곁 모드**로 남긴다. 진판 싸움에서 캐릭터가 **무기에 맞는 탄(기획 29)을 쏘고 맞을 때 이펙트**가 터진다.

## 1. 게임 구조
| 지금 | 바뀜 |
|---|---|
| 타이틀 → 장터 → 출격(슈팅 본편 10층) | 타이틀 → 장터 → **가운데 큰 건물 = 진법 마당(메인)** |
| 진법 마당: 2층 대장 뒤에 열림, 오락실 안의 오락기 | **처음부터 열림**, 장터 화면 가운데·가장 크게, 「출격」 부적 탭 = 진법 |
| 슈팅 본편 | **곁 모드 「달맞이 사냥」**(장터 한쪽 건물). 탑·끝없는 모드·오락실도 곁 모드로 그대로 |
| 처음 10분(기획 1) | 진법 배우기 3밤을 첫 10분으로: 달래·한별·나린 셋으로 시작 → 1장 1밤 |

## 2. 이야기 = 「장」 10개
- 본편 1~10층을 진법 **1~10장**으로. 한 장 = 한 판(15밤 대신 **장마다 7밤**, 마지막 밤이 그 층 대장).
  - 1장 새벽 산마루 … 10장 그믐(본편 층 순서·배경·대장 그대로 씀, 진판 배경만 장마다 색이 바뀜)
- 장 사이 이야기(기획 13a 대사)는 장 시작·끝에 짧게(컷인 + 대사 2~3줄).
- 15밤 판(지금 정식판)은 **「달밤 진법: 긴 밤」** 으로 따로: 장을 다 깬 뒤 매일 하는 판(기록·순위·주간 달 행사).
- 어려움: 장을 깨면 「보름 장」(요괴 ×1.2, 보상 1.5배), 「그믐 장」(목숨 5, 보상 2배).

## 3. 성장 (판 밖)
| 항목 | 내용 |
|---|---|
| 캐릭터 모으기 | 그대로(얻는 곳 기획 15·28). **주막에 나오는 캐릭터 = 가진 캐릭터만**(처음 주인공 3 + 장마다 그 장 대장 출신 동료 합류) → 모을수록 진이 다양해짐 |
| 캐릭터 레벨 | 진법 판에서 쓴 캐릭터 인연 경험치 → 레벨마다 진법 체력 +3%(최대 +15%), 7레벨 「시작 짝」: 판 시작 주막에 그 캐릭터 2장 고정 1번 |
| 장비 40종 | 진법에서는 **「진 부적」 3칸**으로 줄여 씀: 판 시작 전 3개를 골라 판 내내 효과(예: 시작 진 엽전 +3, 연계 일격 +15%) |
| 달조각 | 장 첫 클리어·밤 막기 보상 → 캐릭터 얻기·스킨·진 부적 |

## 4. 공격 이펙트를 진법 싸움에 (기획 29 적용)
| 항목 | 규칙 |
|---|---|
| 기본 공격 그림 | 캐릭터마다 `fx/cNNn`(평소·짝) / `fx/cNNa`(각성, 4장 모았을 때) |
| 나가는 자리 | 진판 캐릭터 무기 끝(MUZ·MUZW를 진판 크기 1.6배에 맞춰 줄임) |
| 쏘는 캐릭터 | 탄이 날아가 적에게 맞음(기획 29 종류별 움직임: 볼텍스 관통, 부채 3갈래, 구슬 산탄·유도, 번개 튐, 회전 원반) |
| 막는·베는 캐릭터 | 적 앞까지 다가가서 **같은 이펙트를 짧게(1칸 거리)** 휘두름: 칼날은 눈앞에서 베고 사라짐, 충격·할퀴기·물보라는 바로 앞에서 터짐 |
| 맞을 때 | `fx/hitA~N`을 캐릭터 색으로 물들여 0.2초(커지며 사라짐) + 작은 흔들림 |
| 크기 | 진판에서 탄 그림 길이 = 캐릭터 키의 40%(각성 55%). 작은 화면에서 흐려지지 않게 바깥 빛을 조금 진하게 |
| 캐릭터 스킬 | 기획 24 스킬 그대로 + 스킬 탄 그림(t*.webp) |
| 연계 일격(26 21절) | 두 캐릭터 사이에서 속성별 큰 이펙트: 같은 속성의 맞을 때 그림을 3배로 키워 쓰고 속성 색 |
| 성능 | 동시에 날아가는 탄 최대 40개, 넘으면 오래된 것부터 지움 |

## 5. 싸움 손맛 (메인이라 더 다듬을 것)
- 밤 싸움 20~30초, 속도 ×1/×2(×3 추가).
- 처치 순간 적이 깨지며 진 엽전 튀어나옴, 마지막 적 처치는 0.3초 느리게 + 확대.
- 짝(2장)·각성(4장) 순간: 카드가 합쳐지는 연출 + 각성은 기존 각성 컷인을 짧게(0.8초).
- 밤 시작 전 「요괴 진 미리 보기」 그대로(배치 고민의 핵심).

## 6. 지금 슈팅 본편은?
- 지우지 않고 **「달맞이 사냥」** 곁 모드로: 그동안 만든 층·대장·봉인·협력 컷인을 그대로 즐길 수 있음. 달조각 보상은 진법의 절반.
- 슈팅에서 쓰던 협력 컷인·각성 컷인 그림은 진법 연출에 그대로 다시 씀.

## 7. 개발 요청 순서 (사용자 확인 후)
1. 4 공격 이펙트를 진판 싸움에 적용 (바로 체감되는 것부터)
2. 1 구조: 타이틀 → 장터 가운데 진법 마당, 처음부터 열림, 슈팅은 곁 모드
3. 2 장 10개(7밤, 마지막 밤 층 대장) + 장 사이 대사

## 8. 이름 바꾸기: 장 → Stage, 밤 → Round (11/25 사용자 결정)
사용자: "밤이라는 개념이 어렵다. Stage로, Stage 아래는 Round로. Stage 목록이 글자로 쭉 써 있어 보기 어려우니 화면이 넘어가는 식으로 넓게."

### 8-1. 말 바꾸기
| 지금 | 바뀜 |
|---|---|
| 제1장 새벽 산마루 | **STAGE 1** 새벽 산마루 |
| 제3밤 / 7 | **ROUND 3 / 7** (옆에 달 모양 점 7개, 깬 Round는 채운 달) |
| 마지막 밤(층 대장) | **BOSS ROUND** (7번째, 붉은 글씨) |
| 밤 시작 | **싸움 시작** |
| 밤마다 1회 무료 / 카드 바꾸기 1번 무료 | Round마다 1회 무료 |
| 오늘 밤의 장수 | 이번 Round 장수 |
| 밤을 놓쳤다… | Round를 놓쳤다… |
| 긴 밤(15밤) | **STAGE EX 「긴 밤」 · 15 Round** (모든 Stage를 깬 뒤 매일 하는 판, 5·10·15 Round 대장) |
| 진법 배우기 3밤 | 진법 배우기 3 Round |
- 게임 이름 「달밤 진법」, 달 모양 규칙(초승·보름 등)은 그대로. 숫자·STAGE·ROUND·BOSS 는 영어 대문자, 나머지는 한글.

### 8-2. Stage 고르기 화면 (넘기는 화면)
지금은 진법 마당 한 화면에 장 10개 버튼·진 부적·메뉴가 작은 글씨로 몰려 있음 → **Stage 한 개가 한 화면**, 좌우로 넘김.
| 자리 | 내용 |
|---|---|
| 가운데 큰 카드(화면 너비 70%) | 그 Stage 층 배경 그림 + 대장 그림(본편 대장 그림 재사용), 위에 **STAGE N** 큰 글씨, 아래 장소 이름 |
| 카드 아래 | Round 진행 달 점 7개, 깬 표시 ✔, 보상 한 줄 「깨면 ○○이 동료로」(처음 깰 때만) · 달조각 |
| 카드 양옆 | 이전·다음 Stage 카드가 작게 반쯤 보임 + ◀ ▶ 화살표. 손가락으로 밀어 넘김(스와이프) |
| 화면 맨 아래 | 쪽 점 11개(STAGE 1~10 + EX), 지금 쪽만 금색 |
| 잠긴 Stage | 카드가 어둡고 자물쇠 + 「STAGE N−1을 깨면 열림」 |
| 큰 버튼 | **출진** (카드 바로 아래, 넓게) |
| 위 오른쪽 작은 아이콘 | 진법 배우기 · 진법 책 · 기록과 보상 · 그림자 겨루기(잠김) |
- 화면을 열면 아직 안 깬 첫 Stage 쪽으로 바로 감.
- 이어 하기 판이 있으면 그 Stage 카드에 「이어 하기 · ROUND n부터」 버튼을 출진 위에 먼저 보임.

## 9. 장터 개편: 왼쪽 슈팅 · 가운데 「도깨비체스」 (11/25 사용자 결정)
사용자: "오락실에 게임이 별로 없다. 장터에서 왼쪽은 슈팅(탑 오르기)으로 직관적으로, 가운데는 롤토체스를 떠올릴 수 있는 이름으로." → 이름 **「도깨비체스」** 확정.
- 롤토체스·오토체스는 다른 회사 게임 이름이라 쓰지 않는다.

| 자리 | 지금 | 바뀜 |
|---|---|---|
| 가운데(가장 크게) | 출격 · 진법 마당 | 간판 **「도깨비체스」**(큰 글씨) + 아래 작게 「달밤 진법」. 누르면 지금과 같이 진법(§8 Stage 고르기)으로 |
| 왼쪽(두 번째로 크게) | 「달맞이 사냥」 글자 + 오른쪽 따로 「탑」 | **탑 그림(tower10) 하나로 합침**, 간판 **「슈팅 · 탑 오르기」**. 누르면 지금의 슈팅 출격 화면(층 고르기)으로. 오른쪽에 따로 있던 「탑」 건물은 없앰 |
| 오른쪽 끝 | 오락실(짝 맞추기 1대 + 제작 중 4대) | 작은 노점 **「짝 맞추기」**로 줄임. 누르면 바로 짝 맞추기. 「제작 중」 오락기 안내 화면은 뺌 |
| 그 밖 | 대장간·복주머니 가게·정자·게시판·책방 | 그대로(겹치지 않게 자리만 조정) |
- 화면 안의 이름도 바꿈: 「달맞이 사냥」 → 「슈팅 · 탑 오르기」(출격 화면 탭 이름 「사냥」 → 「슈팅」), 진법 메뉴 제목 → 「도깨비체스」.
- 게임 이름 「그믐: 달을 훔친 자」는 그대로. 도깨비체스는 그 안의 메인 모드 이름.
