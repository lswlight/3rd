## 1. 스치기 (아슬아슬하게 피하면 이득)
판정은 이미 있으므로 **보상만 붙입니다.** (`b.gz` 가 처음 켜지는 순간)

| 보상 | 값 |
|---|---|
| 점수 | 50 × 연속 배수(2번) |
| 기 모으기 | 모으는 중이면 +0.15초 (축복 「아슬아슬」을 고르면 +0.3초로 두 배) |
| **부적 조각** | 스칠 때마다 1개. **40개 모으면 부적 +1** (최대 5개). 화면 아래 부적 칸 옆에 작은 원 게이지 |

- 연출: 스친 자리에 작은 불꽃 + 「스침!」 대신 짧은 '팅' 소리만(글자는 화면을 어지럽힘). 연속으로 스치면 소리 높이가 점점 올라감.
- 결과 화면: 「스친 탄 ○개」 표시.
- 균형: 부적이 너무 많아지면 40 → 60으로 올림.

## 2. 연속 처치 「연(連)」 배수
| 항목 | 규칙 |
|---|---|
| 이어지는 조건 | 마지막 처치·대장 타격 후 **1.6초 안에** 다음 처치 또는 대장 타격 |
| 표시 | 화면 위 가운데 「連 23」, 숫자가 커질수록 글자가 커지고 색이 바뀜(흰 → 금 → 붉은) |
| 배수 | 10연 ×1.5, 30연 ×2, 60연 ×3, 100연 ×4 (최대) |
| 적용 | **점수**에 배수 전부. **골드(엽전)** 는 경제 균형(기획 2)을 지키기 위해 배수의 절반만, 최대 +50% |
| 끊김 | 맞으면 0. 방패(장승의 가호 등)에 막히면 절반 |
| 필살기 | 필살기로 잡은 것도 이어짐 (필살기가 연을 살리는 수단) |
| 엽전 모양 | ×2부터 떨어지는 엽전이 은빛, ×3부터 금빛 (그림 대신 색만 바꿈) |

- 결과 화면: 최대 연, 점수, **점수 등급**(S·A·B·C). 등급 기준은 구간마다 "최대 점수의 몇 %"로 정하고 측정으로 맞춤.
- S 등급을 처음 받으면 달조각 5 (구간당 한 번). 순위표(기획 8)에 구간 최고 점수 올림.

## 3. 동료 합체 필살기
동료와 함께 있을 때, 조합이 맞으면 필살기가 **두 사람의 합동 기술**로 바뀝니다.

### 3-1. 쓰는 법
- 부적이 **2개 이상**이고 지금 조합이 합체 목록에 있으면, 부적 버튼이 **금빛 테두리**로 빛남.
- 부적 버튼을 **길게 누르면** 합체 필살기(부적 2개 소모). 짧게 누르면 평소 필살기.
- 컷인: 화면을 대각선으로 나눠 **두 사람의 컷인 그림을 동시에** 띄움(기존 `cut`/`hc` 그림 재사용, 새 그림 없음). 기술 이름 띠.

### 3-2. 합체 목록 (처음 6개)
| 조합 | 기술 이름 | 효과 |
|---|---|---|
| 한별 + 설녀 | 눈보라 부채 | 화면 탄을 모두 4초 동안 얼리고(멈춤), 큰 회오리 3개가 화면을 가로지름 |
| 달래 + 구미호 | 여우불 화살비 | 따라가는 화살 40발 + 여우불이 적에 붙어 지속 피해 |
| 나린 + 이무기 | 은하수 승천 | 화면을 위아래로 가르는 물기둥 5줄, 지나간 자리 탄 지움 |
| 탈 도깨비 + 도깨비 여왕 | 도깨비 잔치 | 화면의 모든 탄을 엽전으로 바꾸고 금 방망이가 화면을 내려침 |
| 불가사리 + 쇠 도깨비 | 쇠 먹는 대장간 | 3초 동안 다가오는 탄을 빨아들인 뒤, 빨아들인 수만큼 칼을 되쏨 |
| 장승 자매 + 용왕의 장수 | 수호진 | 6초 동안 앞에 물결 방벽(탄 막음) + 장승 기둥 셋이 대장을 내리침 |

- 조합은 **조종 캐릭터와 동료의 순서 상관없이** 성립.
- 처음 쓰면 「합체 기술 발견!」 + 도감의 **「합체 기술」 탭**에 등록. 6개 모두 찾으면 보상(달조각 30).
- 힌트: 정자에서 동료를 누르면 가끔 "○○랑 같이 하면 재밌을 텐데…" 같은 대사.
- 나중에 조합을 늘려 업데이트 거리로 씀(동료 13명 → 조합 후보가 많음).

## 4. 대장 약점(부위) 파괴
대장마다 **약점 1~2곳**을 둡니다. 그림은 그대로 두고, 약점 자리에 **빛나는 핵(작은 빛 구슬)** 을 그려 표시합니다.

| 층 | 대장 | 약점 | 부수면 |
|---|---|---|---|
| 1 | 탈 도깨비 | 이마의 탈 | 2단계로 바로 넘어가지만 도깨비불 패턴이 약해짐 |
| 2 | 불가사리 | 쇠공 | 쇠공 패턴 사라짐 |
| 3 | 구미호 | 꼬리 끝 여우구슬 | 분신 수 −1 |
| 4 | 장승 자매 | 장승 몽둥이 | 기둥 패턴 간격 넓어짐 |
| 5 | 설녀 | 얼음 왕관 | 눈 탄 속도 −20% |
| 6 | 이무기 | 여의주 | 파도 패턴 한 줄 줄어듦 |
| 7 | 용왕의 장수 | 월도 | 초승달 탄이 갈라지지 않음 |
| 8 | 쇠 도깨비 | 가슴의 용광로 | 칼비 예고 시간 +0.3초 |
| 9 | 두억시니 | 삼킨 달(배) | 「검은 달」 어둠 시간 절반 |
| 10 | 도깨비 여왕 | 금 방망이 | 3단계 동료 기술 하나 빠짐 |

- 약점 체력: 대장 체력의 15~20%. 약점에 맞은 피해는 대장 체력에도 절반 들어감(약점만 노려도 손해가 없게).
- 부수면: 큰 폭발 + 부적 1개 + 엽전 한 무더기 + 점수 보너스 + 「약점 격파!」.
- 기획 5의 대장 체력·시간 목표와 맞추기 위해, 약점을 부수면 대장전이 약 10~15% 짧아지게 수치를 잡음.
- 코드: 대장에 `weak: [{ox, oy, r, hp}]` 를 붙이고, 내 탄 판정에서 약점 원을 먼저 검사.

## 5. 구간 끝 갈림길 (다시 할 때만)
- 이미 깬 구간을 다시 할 때, 1·2구간이 끝나면 **두 길**이 뜸: 「편한 길」 / 「험한 길」.
- 험한 길: 다음 구간 적 체력 +30%, 탄 속도 +15%, 대신 **골드 ×2, 메달 구출 대상 +1, 점수 ×1.5**.
- 그림: 두 갈래 길 표지판 두 개(먹물 띠 글자). 처음 깨는 판에는 나오지 않음(첫 경험을 단순하게).

## 6. 손맛 덤 (작은 것들)
| 항목 | 내용 |
|---|---|
| 처치 크기 단계 | 잔챙이 작은 폭발, 문지기 중간 + 짧은 멈춤(0.03초), 수문장·대장 큰 폭발 + 화면 흔들림 |
| 마지막 일격 | 대장을 쓰러뜨리는 순간 0.6초 느린 화면 + 하얀 번쩍임 |
| 힘 최대(4단계) | 캐릭터 둘레에 은은한 기운, 기본 공격 색이 진해짐 |
| 엽전 줍기 소리 | 연속으로 주우면 음이 한 칸씩 올라감 |

## 8. 요청 순서
1. 2번 연속 처치 배수 + 1번 스치기 보상 + 결과 화면(최대 연, 스친 수, 점수 등급)
2. 6번 손맛 덤
3. 4번 대장 약점 (1층부터 차례로)
4. 3번 합체 필살기 (목록 6개, 도감 「합체 기술」 탭)
5. 5번 갈림길
6. 측정: 구간별 평균 연, 스친 수, 등급 분포 → 등급 기준·부적 조각 수 조정
