# 그믐: 달을 훔친 자 · 기획 23. 연계 협력 공격 · 스킬 컷인 · 봉인 요괴 소환

사용자 요청(11/23):
1. 협력은 **둘이 합친 연계 공격**으로. 공격 이펙트도 달라야 함(지금은 반짝이기만 하고 효과가 안 보임).
2. 스킬 공격에 **일러스트가 없음** → 만들어야 함.
3. 몹을 봉인하면 **그 요괴로 공격**하는 형태가 있어야 함. 봉인 요괴 공격에도 이펙트, **1회성**.

지금 개발판 상태(코드 확인): 협력은 기획 17-4만 들어가 원·빛·글자뿐. 기획 18-2~18-5 연출은 미적용. 스킬 컷인(18-3) 미적용. 봉인은 잔챙이 = 약한 자동 수호령(판 끝까지), 수문장 = 키보드 G 요괴 기술 1번(화면 버튼 없음).

이 문서는 기획 18(협력 연출)·21(각성 협력·인연) 위에 얹는다. **새 그림은 그리지 않는다**(이미 있는 일러스트·게임 그림·요괴 그림만 씀, 크레딧 없음).

## 1. 연계 협력 공격: 두 속성이 합쳐진다

### 1-1. 흐름 (기획 18-2의 1.3초 안에서)
| 순간 | 시간 | 연출 |
|---|---|---|
| ① 맞손 컷인 | 0.5초 | 기획 18 그대로(두 일러스트 대각선, 「협력!」) + 아래에 **연계 이름**(예: 「증기 폭발」) |
| ② 나란히 서기 | 0.3초 | 동료가 주인공 옆에. 둘 사이 빛의 실이 **두 속성 색**으로 꼬임 |
| ③ 따로 쏨 | 0.2초 | 주인공 속성 탄 + 동료 속성 탄이 각각 날아감(두 색이 보이게) |
| ④ **합쳐짐** | 0.3초 | 두 탄이 목표 지점에서 **부딪혀 합쳐지며 연계 이펙트**(1-3 표)가 터짐 + 「合」 도장 |
| ⑤ 남는 효과 | 1~3초 | 연계마다 남는 효과(불길·얼음 바닥·전기 그물 등)가 화면에 남아 계속 피해 |
- 방식(지휘·탑승·수호)은 그대로. 지휘형은 ④가 손가락으로 정한 자리, 탑승형은 탈것이 지나간 길 전체, 수호형은 반격 광선 끝에서 ④.
- 피해: 기획 16 협력 일격 30 → **연계 일격 40 + 남는 효과 초당 10**. (기획 22 이후 적 체력 기준, 측정 후 조정)

### 1-2. 속성 이펙트 (지금 반짝이만 있는 것 → 속성마다 모양을 다르게)
| 속성 | 탄 모양 | 맞을 때 | 남는 것 | 소리 |
|---|---|---|---|---|
| 🌀 바람 | 초승달 칼날 | 칼자국 X + 잎 흩날림 | 작은 회오리 | 휙 |
| ✦ 표식 | 화살·빛 점 | 적 머리 위 붉은 과녁 | 과녁(다음 공격 +피해) | 딱 |
| 💧 물 | 물방울 줄기 | 물보라 튐 | 물웅덩이(젖음) | 철썩 |
| 🔥 불 | 불덩이 | 불꽃 폭발 + 불티 | 바닥 불길 | 퍽 |
| ❄ 얼음 | 얼음 송곳 | 얼음 결정 깨짐 | 얼음 바닥(적 느려짐) | 쨍 |
| ⚡ 번개 | 지그재그 줄기 | 번쩍 + 화면 잠깐 하얗게 | 전기 불꽃 | 지직 |
| ⛓ 묶임 | 사슬·쇠 | 사슬이 감김 | 사슬 기둥 | 철컹 |
| ⬛ 무거움 | 큰 덩어리 | 땅 갈라짐 + 흔들림 | 금 간 바닥 | 쿵 |
- 이 표는 협력뿐 아니라 **기본 탄·캐릭터 스킬·봉인 소환에도 같이** 씀(속성마다 늘 같은 모양 → 보면 무슨 속성인지 앎).

### 1-3. 연계표 (주인공 속성 × 동료 속성)
주인공: 한별 = 바람, 달래 = 표식, 나린 = 물. 동료 속성은 기존 코드(`elOf`) 그대로.

| 동료 속성 | 한별(바람)과 | 달래(표식)와 | 나린(물)과 |
|---|---|---|---|
| 🔥 불 | **불 회오리**: 회오리가 적을 끌어모아 태움, 바닥 불길 | **불화살 과녁**: 과녁 붙은 적마다 불 폭발 | **증기 폭발**: 넓은 흰 김 폭발, 적 2초 앞 못 봄(탄 덜 쏨) |
| ❄ 얼음 | **눈보라**: 화면 탄 2초 느리게 + 적 얼림 | **얼음 화살**: 과녁 적 얼려 깨뜨림(얼은 적 피해 2배) | **결빙**: 젖은 적 모두 1.5초 꽁꽁 |
| ⚡ 번개 | **번개 폭풍**: 회오리 안에서 번개가 적 사이를 튐 | **벼락 과녁**: 과녁마다 벼락이 내리꽂힘 | **감전 연쇄**: 젖은 적 전부에게 전기가 이어짐 |
| 💧 물 | **물 회오리**: 물기둥이 휘돌며 탄 지움 | **물화살 비**: 화살비 + 젖음 | **해일**: 화면을 가로지르는 큰 파도 |
| 🌀 바람 | **쌍회오리**: 회오리 둘이 화면을 가로지름 | **바람 화살**: 관통 화살이 적을 꿰뚫고 계속 감 | **물보라 바람**: 넓은 물보라, 탄 밀어냄 |
| ✦ 표식 | **칼바람 과녁**: 과녁 적에게 바람 칼날이 몰림 | **쌍과녁**: 과녁 두 겹, 다음 공격 피해 2배 | **물 과녁**: 과녁 적에게 물기둥 |
| ⛓ 묶임 | **모래 사슬**: 회오리가 사슬을 감아 적 묶음 | **사슬 과녁**: 과녁 적 묶고 화살비 | **진흙 늪**: 바닥이 늪, 적 느려지고 묶임 |
| ⬛ 무거움 | **모래 폭풍**: 적을 밀어내고 1초 기절 | **쇠 화살**: 큰 쇠 화살 한 발, 대장 1초 비틀거림 | **물대포**: 무거운 물덩이 한 방, 큰 흔들림 |
- 동료가 주인공(한별·달래·나린)일 때도 같은 표(예: 달래 + 한별 = 「바람 화살」).
- 기존 합체 기술 6개(눈보라 부채 등)는 따로 그대로 둠(B 버튼).
- 각성 협력(기획 21) 때는 연계 이펙트 크기 1.5배 + 각성 무기 모양으로 바뀜.

## 2. 스킬 일러스트 컷인

### 2-1. 캐릭터 스킬 (X 버튼)
| 순간 | 연출 |
|---|---|
| 누르는 순간 | 화면 **왼쪽 아래에서 캐릭터 일러스트 상반신이 비스듬한 띠로 0.5초** 미끄러져 들어왔다 나감 + 스킬 이름 붓글씨. 게임은 멈추지 않고 **0.15초만 느리게** |
| 쓰는 그림 | 평소 = 원본 일러스트(주인공 `hc*`, 동료 `cut*x`·`cut*`), **각성 중 = 각성 일러스트 `aw*`** |
| 띠 | 캐릭터 색 테두리 + 속성 무늬(1-2 표의 속성 아이콘) |
| 반복 | 10초 안에 또 쓰면 띠를 0.25초로 짧게(생략 대신 짧게) |
| 스킬 이펙트 | 1-2 속성 이펙트로 바꿈(지금 반짝이 → 속성 모양) |

### 2-2. 무기 스킬 (E 버튼)
- 무기 그림(장비 아이콘)을 크게 가운데에 0.3초 + 칼날 섬광. 일러스트 없음.

### 2-3. 캐릭터 정보 화면
- 스킬 칸마다 **일러스트를 배경으로 깐 카드**(얼굴 쪽으로 잘라서) + 스킬 이름·설명·속성.

### 2-4. 새 그림이 필요한가
- 지금은 **필요 없음**(원본·각성 일러스트 23명분이 다 있음).
- 나중에 원하면 「스킬 전용 일러스트」(스킬 쓰는 장면) 23장을 따로 그릴 수 있음: 한 장 약 0.75 + 배경 1 → 약 40크레딧. 사용자가 원할 때만.

## 3. 봉인 요괴 소환 (1회성)

### 3-1. 바뀌는 것
| 지금 | 바꿈 |
|---|---|
| 잔챙이 봉인 → 판 끝까지 따라다니는 약한 수호령 | **없앰** |
| 수문장 봉인 → 키보드 G로 요괴 기술 1번 | **소환으로 통합** |
| | 봉인하면 그 요괴가 **「소환 부적」 한 장**이 됨. 부적을 쓰면 요괴가 나타나 **자기 기술로 한 번 크게 공격하고 사라짐**(부적은 불타 없어짐) |

### 3-2. 버튼
- 기존 **봉인 버튼 자리**를 같이 씀: 봉인 기회(「封」)가 없을 때 소환 부적이 있으면 버튼이 **가장 오래된 부적의 요괴 얼굴**로 바뀜. 톡 = 소환.
- 버튼 옆에 작은 숫자로 남은 소환 부적 수. 최대 **3장**. 4번째 봉인을 하면 가장 오래된 부적이 **자동으로 바로 소환**됨(버리지 않음).
- 키보드: G = 소환.
- 판이 끝나면 남은 소환 부적은 사라짐(영구 요괴 부적함·레벨은 기획 15 그대로).

### 3-3. 소환 연출 (약 1.5초, 게임은 계속)
| 순간 | 시간 | 연출 |
|---|---|---|
| ① 부적 | 0.2초 | 주인공 앞에 노란 부적이 떠올라 **불타며 「召」 글자**가 빛남 |
| ② 등장 | 0.3초 | 부적 불꽃 속에서 요괴가 **푸른 테두리 빛의 반투명 모습으로 1.6배 크게** 솟아오름(요괴 게임 그림 그대로, 색만 덧칠) + 요괴 이름 |
| ③ 공격 | 0.7초 | 요괴의 **자기 기술**(3-4 표)을 1-2 속성 이펙트로 크게 |
| ④ 사라짐 | 0.3초 | 요괴가 연기처럼 흩어지고 재가 된 부적 조각이 날림 + 「封」 도장이 깨지는 소리 |

### 3-4. 소환 기술 (요괴 속성으로 정함)
| 요괴 속성 | 기술 | 모양 |
|---|---|---|
| 🔥 불 | 불길 돌진 | 요괴가 화면 끝까지 돌진, 지나간 자리 불길 |
| 💧 물 | 물기둥 | 화면에 물기둥 3개 차례로 솟음 |
| ❄ 얼음 | 얼음 폭풍 | 화면 앞쪽 절반 얼음 결정이 휘몰아침, 적 얼림 |
| ⚡ 번개 | 벼락 내리기 | 적 5마리에 벼락이 하나씩 |
| 🌀 바람 | 회오리 | 큰 회오리가 적을 끌어모아 위로 날림 |
| ⛓ 묶임 | 바위 굴리기 | 큰 바위가 굴러가며 적을 깔고 지나감 |
| ✦ 표식 | 요기 폭발 | 모든 적에 표식 → 0.5초 뒤 동시 폭발 |
| ⬛ 무거움 | 내려찍기 | 요괴가 높이 뛰어 내려찍어 화면 흔들림 + 충격파 |

### 3-5. 세기
| 소환한 요괴 | 피해 | 비고 |
|---|---|---|
| 잔챙이 | 합계 약 60(기획 22 이후 적 체력 기준) | 잔챙이 무리를 한 번에 정리하는 정도 |
| 문지기 | 약 100 | |
| 수문장 | 약 180 + 대장이면 1초 비틀거림 | 아껴 두었다 대장전에 쓰는 맛 |
| 금빛 요괴 | ×1.5 | |
| 요괴 부적함 레벨(기획 15) | 레벨마다 +15% | 영구 성장과 연결 |
- 대장전: 소환은 대장 체력 10% 아래로 깎지 않음(마무리는 주인공이).

## 4. 개발 요청 순서 (기획 18·21·22와 합친 순서)
1. 기획 22 체력 밸런스
2. **1-2 속성 이펙트 8종**(모든 공격 공통 바탕)
3. 기획 18-2 협력 발동 연출 + **1-1·1-3 연계 협력 공격 24종**
4. **2 스킬 일러스트 컷인**(캐릭터 스킬, 무기 스킬, 정보 화면 카드)
5. **3 봉인 요괴 소환**(수호령 없앰, 소환 부적·버튼·연출·기술 8종)
6. 기획 18-3~18-5 방식별 연출·준비 표시
7. 기획 21 각성 협력 + 인연
8. 측정: 1·3·5층 대장 기준 피해 비중(기본·스킬·무기·협력·소환), 스크린샷(연계 협력 3종, 스킬 컷인, 소환 2종)
