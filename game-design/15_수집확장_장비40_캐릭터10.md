# 그믐: 달을 훔친 자 · 기획 15. 수집 확장 (요괴 봉인·소환 · 장비 40종 · 새 캐릭터 10명 · 캐릭터 정보 화면)

전제: 기획 14(전투 개편: 체력바, 캐릭터·무기·협력 스킬, 속성 연계)가 들어간 상태.
사용자 요청: ① 요괴 봉인·소환(기획 아이디어 추천 2번) ② 장비 4종류(무기·부적·장신구·옷)를 **각 10개씩** ③ 캐릭터 **10명 더** ④ 참고 이미지(다른 모바일 RPG의 캐릭터 정보·스킨 보기 화면)처럼 수집 화면 강화.
개발판은 모두 열린 상태로, 단계적 열기·획득 조건은 출시판에서만.

## 1. 요괴 봉인·소환
쓰러뜨리는 요괴를 **부적에 봉인해 모으고**, 전투 중 **불러내 함께 싸우게** 합니다. 이미 그려 둔 문지기 30종·수문장 19종(총 49종)과 요괴 도감을 그대로 살립니다.

### 1-1. 봉인하기 (약하게 만든 뒤 부적으로)
| 항목 | 내용 |
|---|---|
| 대상 | 문지기 30종, 수문장 19종 (대장은 이미 동료가 되므로 제외) |
| 봉인 기회 | 요괴 체력이 20% 아래로 떨어지면 머리 위에 붉은 「封」 글자가 3초 동안 깜빡임 |
| 봉인 방법 | 그동안 **봉인 버튼**(부적 그림)을 누르면 부적이 날아가 붙음 → 요괴가 부적 속으로 빨려 들어가는 연출 |
| 성공률 | 문지기 70%, 수문장 40%. 처음 보는 요괴는 +20%. 실패하면 부적이 타 버리고 요괴는 그대로 쓰러짐 |
| 비용 | 봉인 부적(필살기 부적과 별개, 구간마다 3장 지급, 떡처럼 적이 떨어뜨리기도 함) |
| 놓쳐도 | 그냥 처치한 것과 같음(손해 없음) |

- 요령이 생깁니다: 강한 스킬로 한 번에 잡지 말고 **약하게 만든 뒤 봉인** → 같은 적을 대하는 방식이 달라짐.
- 1% 확률로 **금빛 요괴**(같은 그림에 금빛 덮개)가 나오고, 봉인하면 능력 1.5배.

### 1-2. 요괴 부적함
- 봉인한 요괴는 **요괴 부적(카드)** 으로 쌓입니다. 장터 **책방**(도감) 안 「요괴 부적함」 탭에서 봅니다. 봉인한 요괴는 도감에서 금테.
- 같은 요괴를 다시 봉인하면 **요괴 레벨 +1**(최대 5): 소환 시간과 피해가 올라감.
- 49종을 다 모으면 보상(전설 장비 하나 + 칭호), 10·25종마다 달조각.

### 1-3. 소환하기 (전투 중)
| 항목 | 내용 |
|---|---|
| 데려가기 | 출격 화면에서 요괴 부적 **2장**을 골라 감 (요괴 칸 2) |
| 소환 버튼 | 화면 오른쪽(협력 스킬 위)에 요괴 얼굴 버튼 2개. 쿨 30초 |
| 소환 | 부적이 불타며 요괴가 연기 속에서 등장 + 이름 띠. **문지기 10초, 수문장 8초** 동안 주인공 옆에서 싸움 |
| 싸우는 방식 | 그 요괴가 적일 때 쓰던 **탄 패턴을 그대로 아군 쪽으로** 쏨(기존 `pat` 재사용). 탄 색만 아군색(푸른빛) |
| 피해 | 캐릭터 기본 공격의 60%(Lv1) ~ 120%(Lv5). 수문장은 1.5배 |
| 속성 | 요괴마다 속성 하나 → 기획 14 **연계**에 참여(예: 눈사람 도깨비 ❄, 불 호랑이 🔥, 번개 가오리 ⚡) |
| 마무리 | 끝날 때 작은 폭발 + 「돌아간다」 연기 |

- 요괴마다 쓰임이 달라 **"이 층에는 어떤 요괴를 데려갈까"** 고민이 생김(예: 탄을 막는 소라게 성채, 범위 공격 문어 단지, 빠른 연사 갈매기 도깨비).
- 그림 추가 없음: 문지기·수문장 그림과 기존 탄 패턴 재사용. 아군 표시용 푸른 테두리만.

### 1-4. 화면
- 출격 화면(기획 10 D1)에 「요괴 2칸」 추가: 요괴 얼굴, 이름, Lv, 속성.
- 봉인 버튼은 봉인 기회가 있을 때만 크게 빛나고, 평소엔 작게.

## 4. 캐릭터 정보 화면 (참고 이미지 구조)
장터 거리의 정자 → 캐릭터를 누르면 열리는 화면.


| 탭 | 내용 |
|---|---|
| 정보 | 설정 글, 속성, 체력, 얻은 날 |
| 스킬 | 캐릭터 스킬·협력 스킬·등장 일격 설명 + 짧은 미리보기 움직임 |
| 장비 | 기획 4·14의 장비 4칸 |
