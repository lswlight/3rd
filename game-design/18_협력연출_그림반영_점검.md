## 1. 그림 반영 점검 (2·3·5번)

### 1-1. 먼저 확인할 것
- 사용자가 받은 APK가 그림 넣기 커밋(05e120a, 01:41) **이전 빌드**일 수 있음. 최신 커밋으로 APK를 다시 만들고, 시작 화면 구석에 **빌드 번호(커밋 앞 7자리)** 를 작게 표시. 다음부터 어느 판을 보고 말하는지 바로 알 수 있게.
- 새 일러스트(흰 배경 지운 판)로 `cut13`~`cut22` 를 다시 바꿈.

### 1-2. 새 캐릭터 그림이 나와야 하는 곳 (전부 확인)
| 화면 | 쓰는 그림 |
|---|---|
| 캐릭터 탭 목록 카드 | 일러스트(얼굴 쪽 잘라서) |
| 캐릭터 정보 화면 큰 그림 | 일러스트 전체 |
| 출격·동료 고르기 | 일러스트 얼굴 |
| 협력·합체·필살기 컷인 | 일러스트 |
| 게임 중 캐릭터 | 스프라이트 `p13`~`p22` |
| 도감·말풍선 얼굴 | 일러스트 얼굴 |

임시 인형 그림이 남은 곳이 있으면 모두 바꿈. 개발판에 `?art=1` 을 붙이면 위 화면들을 캐릭터 23명 전부 한 장씩 넘겨 보는 점검 화면이 나오게 함(그림 빠진 곳을 한 번에 찾기).

### 1-3. 캐릭터 스킬에도 그림 (3번)
| 순간 | 연출 |
|---|---|
| 캐릭터 스킬 쓰는 순간 | 화면 **왼쪽 아래에서 캐릭터 일러스트 상반신이 비스듬히 0.5초** 들어왔다 나감(띠 모양, 스킬 이름 붓글씨). 게임은 멈추지 않음 |
| 같은 스킬을 연달아 쓸 때 | 10초 안에 다시 쓰면 컷인 생략(지루함 방지) |
| 캐릭터 정보 화면 「스킬」 칸 | 스킬마다 **일러스트를 배경으로 깐 카드** + 스킬 이름·설명 |

### 1-4. 각성 그림 (5번)
- 주인공 3명: 각성 중에는 게임 그림이 `aw0p`·`aw1p`·`aw2p` 로 **바뀌어야 함**. 바뀌는지, 끝나면 원래 그림으로 돌아오는지 확인.
- 각성 순간 화면 가득 나오는 그림도 `aw0`·`aw1`·`aw2`(각성 일러스트)인지 확인.
- **동료 10명·새 캐릭터 10명은 아직 각성 그림이 없음** → 지금은 색 덧칠·잔상만 바뀜. 사용자가 동료로 각성했다면 안 바뀐 것처럼 보였을 수 있음. 각성 그림은 아래 4번 순서대로 그림.

## 2. 협력 공격을 화려하게 (4번)

### 2-1. 왜 안 보이나
지금 협력은 동료 작은 컷인 0.6초 + 동료 색 일격입니다. 기본 탄·스킬 효과 속에 묻혀 **"둘이 같이 한다"는 장면이 없습니다.** 협력은 한 번 쓸 때마다 **짧은 이벤트처럼** 보여야 합니다.

### 2-2. 협력 발동 연출 (모든 방식 공통, 약 1.3초)
| 순간 | 시간 | 연출 |
|---|---|---|
| ① 맞손 컷인 | 0.5초 | 게임 멈춤. 화면이 **대각선으로 둘로 갈라지며** 왼쪽 위에 주인공, 오른쪽 아래에 동료 일러스트가 서로를 향해 들어옴. 가운데 금빛 선에서 **두 손이 맞부딪히는 섬광** + 「협력!」 붓글씨 + 두 이름 |
| ② 나란히 서기 | 0.3초 | 게임으로 돌아오면 동료가 **주인공 옆에 같은 크기로** 날아와 나란히 섬. 두 캐릭터 사이를 **빛의 실(두 캐릭터 색이 꼬인 줄)** 이 이음 |
| ③ 합동 공격 | 0.5초 | 둘이 동시에 쏨. 주인공 색과 동료 색 탄이 **두 겹 나선으로 꼬여** 날아가 맞으면 두 색 고리가 겹쳐 터짐 + 「合」 도장 + 화면 흔들림 |
| ④ 피해 숫자 | | 금색 큰 숫자 + 작게 「협력」. 같은 협력 안에서 맞힌 횟수만큼 「×3」처럼 늘어남 |
| 소리 | | 두 음 화음(주인공 음 + 동료 음) → 맞을 때 북 한 번 |

### 2-3. 방식별 추가 연출 (기획 17의 세 방식 위에 얹음)
| 방식 | 추가 연출 |
|---|---|
| 지휘형 (끌어서 위치 지정) | 끄는 동안 **동료 색 줄이 손가락을 따라감**, 놓은 곳에 큰 과녁 표시 → 동료가 그 자리로 **잔상을 남기며 돌진** |
| 탑승형 (5초 올라타기) | 올라타는 순간 **흰 섬광 + 탈것이 1.5배로 커지며 포효**, 5초 동안 화면 가장자리에 탈것 색 테두리, 남은 시간 원형 표시 |
| 수호형 (막고 반격) | 막을 때 **두 색 방패 막(반구)** 이 펼쳐짐. 「완벽 반격」 때는 0.3초 느리게 + 화면 가운데 「완벽!」 + 반격 광선이 두 색으로 꼬임 |

### 2-4. 협력 준비를 알아보게
| 항목 | 연출 |
|---|---|
| 협력 게이지 | 협력 버튼 테두리를 따라 차오름. 다 차면 **버튼에 동료 얼굴 + 주인공 얼굴이 맞붙은 그림**으로 바뀌고 두 색으로 맥박치듯 빛남 |
| 알림 | 다 찬 순간 동료 말풍선 「같이 가자!」(캐릭터별 대사, 기획 13a) + 짧은 종소리 |
| 처음 한 번 | 출시판에서는 처음 찼을 때 게임이 0.5초 느려지며 버튼을 가리키는 손가락 안내 |
| 연속 협력 | 각성 중 협력하면 컷인 대신 **두 캐릭터 각성 그림이 겹치는 특별 컷인**(나중 그림 작업) |

### 2-5. 화면이 너무 어지럽지 않게
- 협력 연출 중(약 1.3초)에는 **기본 탄을 반투명 40%** 로 낮추고 적 탄은 그대로 보임(피할 수 있게).
- 맞손 컷인은 같은 판에서 3번째부터 0.3초로 줄임(익숙해지면 짧게). 설정에 「협력 컷인: 길게/짧게/끄기」.

### 2-6. 필요한 그림
| 그림 | 수량 | 비고 |
|---|---|---|
| 맞손 컷인 | 새로 그리지 않음 | 각 캐릭터 일러스트를 대각선으로 잘라 씀 |
| 「협력!」·「合」 붓글씨 | 2개 | 기존 붓글씨 글꼴로 |
| 버튼용 두 얼굴 아이콘 | 코드로 합성 | 일러스트 얼굴 두 개를 원 안에 반씩 |
