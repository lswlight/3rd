# 그믐: 달을 훔친 자 · 기획 27. 본편 화면 정리: 협력 작은 일러스트 위치 · 캐릭터 크기

사용자 의견(11/24, 본편 슈팅):
1. 협력 공격 때 나오는 **작은 일러스트가 화면 중·하단에 떠서 캐릭터를 가림** → 위로 올려서 안 가리게.
2. 캐릭터를 좀 더 키울 방법.

## 1. 협력 작은 일러스트 위치
| 항목 | 지금 | 바꿈 |
|---|---|---|
| 자리 | 화면 중·하단(캐릭터 근처) | **화면 위쪽 띠**(위에서 6~26% 높이), 체력바·점수와 겹치지 않게 그 아래 |
| 가로 | — | 주인공 쪽 일러스트는 위 왼쪽, 동료 일러스트는 위 가운데~오른쪽 |
| 투명도 | — | 80%, 들어오고 나갈 때 페이드(기획 25와 같은 방식) |
| 캐릭터와 겹칠 때 | — | 캐릭터가 위쪽 띠로 올라가면 그동안 일러스트를 40%로 더 투명하게 |
- 큰 맞손 컷인(게임 멈춤, 2.3초)은 화면 전체라 그대로. 이건 **게임이 움직이는 동안 나오는 작은 일러스트**(스킬 띠·협력 띠 등)만 해당. 캐릭터 스킬 일러스트 띠도 같은 규칙으로 위쪽에.

## 2. 캐릭터 크기
지금 `SZ.p = 1.6`(그림 높이 = CH.h × 1.6, 약 100~125px / 화면 높이 360).
| 안 | 내용 | 장단점 |
|---|---|---|
| **A (추천)** | **그림만 1.25배**(SZ.p 1.6 → 2.0), **맞는 판정 원은 그대로** | 보기에 크고 시원함, 난이도 그대로. 판정이 그림 가운데 작은 점이라는 걸 보이게 하려고 몸 가운데 작은 빛점(판정 표시) 유지 |
| B | 그림·판정 같이 1.25배 | 피하기가 어려워짐(기획 22로 한 방이 아파서 비추천) |
| C | 그림 1.25배 + 화면 왼쪽 고정 위치를 조금 오른쪽·가운데로 | 위아래 끝에서 그림이 잘리지 않게 이동 범위를 그림 크기만큼 안쪽으로 |
- A로 하되 C의 「위아래 끝 잘림 방지」를 같이 적용.
- 동료(옆에 따라다니는 작은 그림)는 1.15배만.
- 각성 그림(aw*p)도 같은 배율.
- 무기 끝 발사 자리(MUZ·MUZW)는 그림 배율에 맞춰 같이 곱함.
