## 1. 협력 컷인: 페이드아웃 (검토 결과: 바꾸는 게 맞음)
지금(기획 24-1): 들어옴 0.3 → 보여 줌 1.4 → 나감 0.3(옆으로 빠지며 끝, 게임 바로 재개). 들어올 때는 부드러운데 나갈 때 0.3초에 툭 끊겨 보임.

| 구간 | 지금 | 바꿈 |
|---|---|---|
| 들어옴 | 0.3초 | 0.3초 그대로(페이드인 + 대각선으로 미끄러져 들어옴) |
| 보여 줌 | 1.4초 | 1.4초 그대로(천천히 다가감·1.05 확대) |
| **사라짐** | 0.3초 옆으로 빠짐 | **0.6초 페이드아웃**: 두 일러스트 투명도 1→0, 확대 1.05→1.12로 계속 커지며, 가운데 금빛 선이 하얗게 번지며 흩어짐(빛가루) |
| 게임 재개 | 사라짐 끝에 한 번에 | 페이드아웃 **뒤쪽 0.3초 동안 게임 화면이 서서히 밝아지며 느리게(0.3배→1배) 다시 움직임** → 툭 끊김 없음 |
| 전체 | 2.0초 | **2.3초** (반복 1.4 → 1.6초, 각성 협력 2.4 → 2.7초, 짧게 1.0 → 1.2초) |
| 건너뛰기(톡) | 바로 다음 | 바로 페이드아웃 0.3초로 넘어감 |
- 같은 방식을 각성 일러스트(각성 순간 1.2초)·스킬 컷인 띠에도 적용(사라질 때 0.2초 페이드).

## 3. 캐릭터 스킬 탄 그림 (개정 11/23)
- 처음 안(스킬 쓰는 장면 일러스트 sk*.webp)은 사용자 뜻과 달라 **취소**, sk1 삭제. 개발방도 sk1 빼기.
- 사용자 뜻: 캐릭터 스킬을 누르면 날아가는 **탄(미사일)에 그림이 없음**(지금 코드로 그린 빛 원·선뿐).
- 계획: 23명 스킬 탄 그림(달빛 극화체). 한 장에 탄 4~6개를 남색 배경에 그려 무료로 잘라 냄 → 약 5~6장, 4~5크레딧. 개발방은 날아가는 방향으로 돌리고 기획 23 속성 이펙트(꼬리·맞을 때)를 위에 얹음. 사용자 확인 후 시작.
