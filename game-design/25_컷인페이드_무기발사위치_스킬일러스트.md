# 그믐: 달을 훔친 자 · 기획 25. 협력 컷인 페이드아웃 · 기본 탄 발사 위치 · 캐릭터 스킬 일러스트

사용자 의견(11/23):
1. 협력 일러스트가 페이드인처럼 나오다가 **갑자기 끝나서 이상함** → 페이드아웃으로 사라지면 어떤가 검토.
2. 게임 속 기본 공격 탄이 **무기에서 안 나오고 몸통에서 나와** 이상함.

## 1. 협력 컷인: 페이드아웃 (검토 결과: 바꾸는 게 맞음)
지금(기획 24-1): 들어옴 0.3 → 보여 줌 1.4 → 나감 0.3(옆으로 빠지며 끝, 게임 바로 재개). 들어올 때는 부드러운데 나갈 때 0.3초에 툭 끊겨 보임.

| 구간 | 지금 | 바꿈 |
|---|---|---|
| 들어옴 | 0.3초 | 0.3초 그대로(페이드인 + 대각선으로 미끄러져 들어옴) |
| 보여 줌 | 1.4초 | 1.4초 그대로(천천히 다가감·1.05 확대) |
| **사라짐** | 0.3초 옆으로 빠짐 | **0.6초 페이드아웃**: 두 일러스트 투명도 1→0, 확대 1.05→1.12로 계속 커지며, 가운데 금빛 선이 하얗게 번지며 흩어짐(빛가루) |
| 게임 재개 | 사라짐 끝에 한 번에 | 페이드아웃 **뒤쪽 0.3초 동안 게임 화면이 서서히 밝아지며 느리게(0.3배→1배) 다시 움직임** → 툭 끊김 없음 |
| 전체 | 2.0초 | **2.3초** (반복 1.4 → 1.6초, 각성 협력 2.4 → 2.7초, 짧게 1.0 → 1.2초) |
| 건너뛰기(톡) | 바로 다음 | 바로 페이드아웃 0.3초로 넘어감 |
- 같은 방식을 각성 일러스트(각성 순간 1.2초)·스킬 컷인 띠에도 적용(사라질 때 0.2초 페이드).

## 3. 캐릭터 스킬 일러스트 23장
지금 스킬 컷인(기획 23-2)은 원본 일러스트를 띠로 잘라 씀 → 「스킬 쓰는 장면」이 아님.

| 항목 | 내용 |
|---|---|
| 그림 | 캐릭터마다 1장, **기획 24 표의 그 캐릭터 스킬을 쓰는 순간**(예: 달래 = 활을 당겨 조준선을 모으는 순간) |
| 크기 | 16:9(1344×752), 배경 있음(배경 지우기 없음 → 크레딧 절약). 얼굴·손·무기가 가운데 띠 안(세로 30~75%)에 오게 |
| 그림체 | 달빛 극화체(기준 T3_front·S4 두 장 + 글로 캐릭터 설명, 그림 규칙 그대로). 옷은 **평소 옷**(각성 중엔 각성 일러스트 그대로 씀) |
| 쓰는 곳 | 스킬 컷인 띠(1.0초), 캐릭터 정보 화면 스킬 카드 |
| 파일 | `게임용/sk<번호>.webp` (예: `sk1.webp` 달래) |
| 크레딧 | 1장 0.75 × 23 ≈ 17 + 고치기 → 약 25 |
| 순서 | 주인공 3명(달래 → 한별 → 나린) → 동료 10명 → 새 캐릭터 10명. 한 장씩 사용자 확인 |
