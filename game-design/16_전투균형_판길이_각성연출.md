# 그믐: 달을 훔친 자 · 기획 16. 전투 균형 · 판 길이 · 각성 연출

대상 코드: 브랜치 `claude/amazing-johnson-jj1z6o` 커밋 2b8b3c6 (기획 14·15-2까지)
사용자 반응 (장비 40종 업데이트판을 해 본 뒤):
1. 기본 공격(자동)이 너무 강하고 **무기 공격이 너무 약함**
2. **협력 공격이 언제 나가는지 알 수가 없음**
3. 기본 공격 탄이 강해지면 **화면 전체를 가려서** 다른 공격이 안 보임 → 다른 공격은 눈에 띄는 효과가 있어야 함
4. 체력바와 여러 공격 방법이 생겼는데 **한 판이 너무 짧고 쉬움**
5. 각성이 캐릭터가 커지는 것으로 끝남 → **각성 전용 일러스트(노출 의상·다른 자세)를 띄우고 확대**하는 연출을 원함

## 1. 공격 비중 다시 잡기

### 1-1. 목표: 누가 피해를 얼마나 주나 (대장전 기준)
| 공격 | 지금 (체감) | 목표 비중 |
|---|---|---|
| 기본 공격 (자동) | 대부분 | **35%** |
| 캐릭터 스킬 | | 20% |
| 무기 스킬 | 거의 없음 | **20%** |
| 협력 스킬 | 안 보임 | 10% |
| 연계·필살기·각성·요괴 소환 | | 15% |

"자동으로 쏘기만 해도 이기는" 상태를 없애고, **버튼을 눌러야 이기는** 게임으로 만듭니다.

### 1-2. 기본 공격 약하게, 덜 가리게
| 항목 | 바꾸는 안 |
|---|---|
| 피해 | 지금의 **50%** |
| 힘 단계(1~4) | 오를수록 **탄 수가 늘지 않고**, 탄이 조금 굵어지고 피해만 오름(단계마다 +15%). 갈래는 최대 3줄로 고정 |
| 따라다니는 도깨비불 | 피해 50%, 탄 크기 절반 |
| 그믐의 탑 「갈래 하나 더」 축복 | 갈래 대신 피해 +20%로 바꿈(화면 가림 방지) |
| 겉모습 | 기본 탄은 **반투명(70%)·작게**, 그리기 순서를 **적과 스킬 효과보다 아래**로 |
| 측정 | 개발판에 `?dps=1` 을 붙이면 대장전이 끝날 때 공격 종류별 피해 비중을 표로 보여 줌 → 1-1 목표와 비교해 조정 |

### 1-3. 무기 스킬 강하게, 눈에 띄게
| 항목 | 바꾸는 안 |
|---|---|
| 피해 | 지금의 **3배** (쿨 6~10초 기준, 한 번에 대장 체력 4~6%) |
| 효과 | 무기마다 **전용 색과 모양**, 화면 맨 위 층에 그림. 맞을 때 히트스톱 0.05초 + 화면 흔들림 + 큰 피해 숫자(무기색) |
| 사용 표시 | 쓰는 순간 캐릭터 앞에 무기 그림이 크게 번쩍(0.3초) + 무기 이름 붓글씨 |
| 준비 표시 | 쿨이 끝나면 버튼이 한 번 빛나고 '챙' 소리 |

### 1-4. 스킬 효과 구분 원칙 (화면이 가려지지 않게)
| 공격 | 색·모양 | 층 |

## 2. 협력 스킬이 보이게
| 순간 | 연출 |
|---|---|
| 준비됨 | 협력 버튼의 동료 얼굴이 밝아지며 테두리가 빙글 돎 + 동료 말풍선 「지금이야!」(기획 13a) |
| 쓰는 순간 | 화면 아래쪽에 **동료 작은 컷인 0.6초**(동료 그림 + 기술 이름 띠), 동료가 주인공 앞으로 날아 나와 시전 |

## 3. 판 길이와 난이도

### 3-1. 한 층 = 한 판 (이어서 하기)
| 항목 | 지금 | 바꾸는 안 |
|---|---|---|
| 판 구성 | 구간 하나(1~2분)가 한 판 | **한 층(3구간)을 쉬지 않고 이어서 한 판**, 6~9분. 구간 사이에는 짧은 휴식 화면(체력 +20%, 요괴 부적 바꾸기)만 |
| 저장 | 구간마다 | 구간마다 이어 하기 지점은 유지(나갔다 오면 그 구간부터) |
| 별·메달 | 구간마다 | 층 단위로 합산 |

### 3-2. 더 어렵게 (체력바가 있으니 맞아도 되는 만큼)
| 항목 | 바꾸는 안 |
|---|---|
| 구간 길이 | 적 무리 수 ×1.5, 문지기 3 → 4, 수문장 1 → 2 |
| 적 체력 | ×1.6 (기본 공격 약화와 함께 맞춤) |
| 적 탄 | 밀도 ×1.3, 받는 피해 ×1.3 |
| 회복 | 잔챙이 떡 확률 6% → 3%, 구간 사이 회복 30% → 20% |
| 정예 적 | 구간마다 1~2마리, 금테 + 체력 3배 + 특수 패턴(돌진, 보호막, 분열) |
| 목표 | 처음 하는 1층: **체력 30~50% 남기고 깸**. 5층: 처음 도전 50% 성공 |

수치는 `BALANCE2` 한곳에. 개발판 측정 기록(기획 2·5)에 "층 클리어 시간, 남은 체력, 공격별 피해 비중"을 남겨 맞춥니다.

## 4. 각성 연출: 전용 일러스트 + 확대

### 4-1. 흐름 (약 2초 + 각성 8초)
| 순간 | 연출 |
|---|---|
| 발동 | 게임이 멈추고 화면이 어두워짐(0.2초) |
| 일러스트 등장 | **각성 전용 일러스트**가 화면 전체에 들어옴. 처음엔 전신 → 1.5초 동안 천천히 **확대하며 위로 이동**(얼굴과 무기 쪽으로), 빛 입자·달빛 후광 |
| 대사 | 아래쪽 띠에 각성 대사 한 줄 + 「달빛 각성」 붓글씨 |
| 게임 복귀 | 캐릭터가 **각성 모습**(빛나는 기운, 각성 의상 색)으로 8초 |
| 끝 | 작은 각성 일러스트가 사라지며 원래 모습 |

### 4-2. 각성 일러스트 기준 (15세 등급 유지)
- 각성 의상은 **평소보다 화려하고 노출이 큰 의상**(수영복 수준까지) + 역동적인 기술 자세.
- **확대는 얼굴·무기·손의 빛 쪽으로.** 가슴이나 엉덩이 쪽으로 확대·정지하는 연출, 누워 있거나 몸을 꼬는 자세는 넣지 않음. (기획 3 「몸 강조 구도」 기준, 등급 설문과 스토어 심사 때문)
- 이 기준 안에서 각성 일러스트를 **보상 겸 수집 요소**로: 처음 각성할 때 캐릭터 정보 화면 「스킨」 탭 옆에 「각성」 그림이 열림.
