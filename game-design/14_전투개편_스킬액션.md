# 그믐: 달을 훔친 자 · 기획 14. 전투 개편 — 슈팅 + 액션 스킬

모형: `game-design/mockup/전투개편/버튼배치.png`
사용자 반응: 고전 슈팅이라 기능이 단조로워 지루함. **달빛 각성은 괜찮음.** 공격을 다양하게, 체력바·협력 기술·장비 특수 공격 등 무엇이든 제안해도 됨.
사용자 허락: 필요하면 구조를 전체적으로 바꿔도 됨(00_결정사항).

## 0. 원칙
- 고전 탄막 슈팅(한 방 죽음, 버튼 3개) → **슈팅 + 액션 스킬**(체력바, 스킬 버튼, 협력·연계).
- **개발판(`TEST_UNLOCK = true`)에서는 모든 기능을 처음부터 다 연다.** 단계적으로 여는 것(7번)은 **출시판에서만** 켠다. 검토할 때 한 번에 다 써 볼 수 있어야 하기 때문.
- 숫자는 한곳(`BATTLE` 상수)에 모은다.
- 기획 12의 숫자 장치(連, 스치기)는 화면에서 줄인 채 유지. 기획 13의 각성·합체 4막·돌발 사건·대장 연출은 그대로 살린다.

## 1. 체력바

| 항목 | 값 |
|---|---|
| 체력 | 캐릭터마다 80~130 (아래 3번 표) |
| 받는 피해 | 잔챙이 탄 8, 문지기 탄 10, 수문장·대장 탄 12, 대장 큰 공격(레이저·내려찍기) 25, 몸 부딪힘 15 |
| 맞은 뒤 | 0.8초 무적 + 캐릭터 깜빡임 + 화면 가장자리 붉게 |
| 회복 | 떡 +20, 곶감 +35 (적이 떨어뜨림), 나린 스킬, 구간 사이 +30% |
| 교대 | **캐릭터마다 체력 따로.** 쉬는 쪽은 초당 2% 회복 → 체력이 낮으면 교대해서 버티는 판단이 생김 |
| 둘 다 0 | 쓰러짐 → 이어 하기(달조각, 기존) |
| 목숨·별 | 목숨 개념은 없앰. 별은 "받은 피해 합계"로: 30 이하 ★★★, 80 이하 ★★, 그 밖 ★ |
| 판정 | 기획 7의 판정을 그대로 쓰되, 체력제라 조금 더 키워도 됨(측정으로 맞춤) |

화면 왼쪽 위: 조종 캐릭터 얼굴 + 체력바(빨강) + 달빛 게이지(각성), 그 아래 동료 얼굴 + 동료 체력바(파랑).

## 2. 버튼 배치 (모형 그대로)
| 자리 | 버튼 | 크기 |
|---|---|---|
| 왼쪽 절반 아무 데나 | 끌어서 이동 (기본 공격은 자동) | |
| 오른쪽 아래 가장 큰 원 | **캐릭터 스킬** | 엄지가 가장 쉽게 닿는 곳 |
| 그 왼쪽 아래 | **무기 스킬** | 중간 |
| 그 위 | **협력 스킬**(동료 얼굴이 버튼에 보임) | 중간 |
| 캐릭터 스킬 위 | **부적**(필살기, 길게 누르면 합체) | 작은 |
| 위쪽 | **교대**(등장 일격), **각성**(달빛 가득 차면 빛남) | 작은 |

- 쿨타임은 버튼 위에 시계 방향으로 어두운 부채꼴이 걷히는 모양 + 남은 초.
- 기존 「기 모으기」(꾹 눌렀다 떼기)는 **없애고 캐릭터 스킬로 바꿈**(톡 누르기).

## 3. 캐릭터 13명: 스킬 세 가지씩
- **캐릭터 스킬**: 조종할 때 쓰는 고유 기술 (쿨 5~8초)
- **협력 스킬**: 동료로 옆에 있을 때 버튼으로 쓰는 기술 (쿨 10~14초)
- **등장 일격**: 교대로 들어올 때 자동으로 나가는 한 방

각 기술에는 **속성 표시**(4번 연계용)가 붙습니다: ❄얼림 · 💧젖음 · 🔥불 · ⚡번개 · 🌀바람 · ⛓묶임 · ✦표식

## 4. 연계 (속성이 만나면 반응)
내 스킬이나 동료 스킬로 적에게 속성이 붙은 뒤 **3초 안에** 다른 속성 기술을 맞히면 「연계!」가 터집니다. 특정 동료 짝이 아니라 **속성 규칙**이라 어떤 조합으로도 찾을 수 있습니다.

| 먼저 | 다음 | 연계 이름 | 효과 |
|---|---|---|---|
| ❄ 얼림 | 아무 강한 타격(⛓, 금 방망이, 내려찍기) | **산산조각** | 피해 2배 + 얼음 파편이 주변 적에 튐 |
| 💧 젖음 | ⚡ 번개 | **감전 연쇄** | 번개가 주변 젖은 적에게 줄줄이 옮겨 감 |
| 🔥 불 | 🌀 바람 | **화염 회오리** | 회오리가 불로 바뀌어 범위 2배 |
| 💧 젖음 | ❄ 얼림 | **꽁꽁** | 3초 동안 완전히 얼어 못 움직임 (대장은 1초) |
| ⛓ 묶임 | 관통(회오리·창·세 발) | **꿰뚫기** | 피해 2.5배 |
| ✦ 표식 | 따라가는 공격(칼비·여우구슬) | **표식 폭발** | 표식 터지며 범위 피해 |
| 🔥 불 | 💧 젖음 | **수증기** | 화면 일부 안개, 그 안의 적 탄이 사라짐 |

- 연계가 터지면 화면 가운데 큰 글씨 + 짧은 멈춤(0.05초) + 달빛 게이지 크게 참.
- 처음 터뜨리면 도감 「연계」 탭에 등록. 7개 모두 찾으면 보상.
- 대장 보호막(5번)은 연계로만 깨짐 → 연계를 쓸 이유가 생김.

## 5. 장비: 무기마다 특수 공격 (무기 스킬 버튼)
지금 무기는 "화력 +%" 숫자뿐 → 무기마다 **기술 하나**를 붙입니다(화력 %는 그대로 유지).

| 무기 | 무기 스킬 | 쿨 |
|---|---|---|
| 무쇠 바늘검 | **돌진 찌르기**: 앞으로 짧게 돌진하며 관통, 돌진 중 무적 | 6 |
| 방울 청동검 | **방울 울림**: 주변 적 1초 멈춤 + 탄 느리게 | 9 |
| 은비녀 창 | **비녀 던지기**: 큰 창이 날아가 박힘, ⛓ 묶음 | 7 |
| 벼락 박달봉 | **벼락**: 앞 적 셋에 ⚡ 번개 | 7 |
| 월광 칠성검 | **칠성**: 별 7개가 날아가 ✦ 표식 된 적 우선 공격 | 8 |
| 그믐 달낫 | **그믐 가르기**: 화면을 가로로 베는 초승달, 탄 지움 | 10 |
| (무기 없음) | **기본 일격**: 짧은 근접 휘두르기 | 5 |

- 부적·장신구·옷은 지금처럼 능력치(패시브).
- 새 무기를 얻는 것이 곧 새 기술을 얻는 것 → 상점·보상의 가치가 커짐.

## 6. 스킬을 쓰게 만드는 적
| 적 | 특징 | 답 |
|---|---|---|
| 방패 든 문지기 | 앞에서 쏜 기본 공격 막음 | 관통 스킬, 돌진 찌르기, 위아래 공격 |
| 떼 잔챙이 | 10~20마리 한꺼번에 | 범위 스킬(회오리, 번개 세례) |
| 빠른 잔챙이 | 지그재그로 피함 | 따라가는 공격, 표식 |
| 대장 보호막 | 2단계에 생김, 피해 90% 줄임 | **연계로만 깨짐** → 깨지면 3초 동안 피해 1.5배 |
| 치유 요괴 | 주변 적 회복 | 우선 처치(표식) |

각 층 잔챙이 배치에 이 적들을 섞습니다(기획 5의 층별 장애물과 함께).

## 7. 성장과 출시판 단계적 열기
- **스킬 강화**: 캐릭터 강화(기존 Lv)에 스킬 효과를 묶음. Lv4 스킬 쿨 −15%, Lv7 협력 스킬 효과 +30%, Lv10 캐릭터 스킬이 한 단계 진화(예: 회오리 2개).
- 그믐의 탑 축복에 스킬 관련 축복 추가(쿨 감소, 연계 피해 증가 등).
- **출시판에서만** 단계적 열기: 1층 = 기본 공격 + 캐릭터 스킬 + 체력, 2층 = 교대·등장 일격, 3층 = 협력 스킬, 첫 무기 획득 = 무기 스킬, 동료 2명 = 연계 안내. **개발판은 모두 열림.**

## 8. 기존 기능 정리
| 기존 | 바뀐 뒤 |
|---|---|
| 기 모으기(꾹 눌렀다 떼기) | 캐릭터 스킬로 바뀜(없앰) |
| 목숨 | 체력으로 바뀜 |
| 동료 자동 지원 사격 | 유지(약하게) + 협력 스킬 버튼 |
| 동료 고유 능력(자동: 탄 얼리기, 탄 먹기 등) | 협력 스킬로 옮김 |
| 교대 | 유지 + 등장 일격 |
| 필살기·합체 필살기 | 유지(부적) |
| 달빛 각성 | 유지. 연계로도 게이지가 참 |
| 스치기·連 | 유지(화면 작게). 스치기는 스킬 쿨 0.2초 줄여 주는 보상으로 바꿈 |

## 9. 요청 순서
1. 체력바와 피해·회복, 별 기준 변경 (1번)
2. 버튼 배치와 쿨타임 표시, 기 모으기 → 캐릭터 스킬 (2번)
3. 캐릭터 13명 캐릭터 스킬 → 협력 스킬 → 등장 일격 (3번)
4. 속성 표시와 연계 7종 (4번)
5. 무기 스킬 7종 (5번)
6. 스킬을 쓰게 만드는 적 5종, 대장 보호막 (6번)
7. 스킬 강화와 출시판 단계적 열기 (7번), 기존 기능 정리 (8번)
- 각 단계마다 검토용 APK. 개발판은 모든 캐릭터·무기·기능이 열린 상태로.
