## 1. 구조

```
            ┌──────────── 메인: 장터 거리 (A) ────────────┐
            │ 하늘의 탑 · 문 「출격」 · 대장간 · 복주머니 가게 │
            │ 정자(동료) · 게시판(임무) · 오락실 · (책방=도감) │
            └──────────────────────────────────────────────┘
   문·탑 ↓         정자 ↓          대장간 ↓          가게·게시판·오락실·책방 ↓
 [D 출격]      [D 캐릭터·동료]   [D 장비·겉모습]      거리 위에 족자 창(팝업)
   └──── 아래 부적 탭: 市 장터로 · 出 출격 · 人 캐릭터 · 裝 장비 ────┘
```

- **메인은 장터 거리(A)** 입니다. 글자 메뉴 대신 건물·사물을 누릅니다.
- **자주 오가는 세 화면(출격·캐릭터·장비)** 은 D안 전체 화면입니다. 아래 부적 탭으로 서로 바로 오가고, 첫 부적 「市 장터로」를 누르면 거리로 돌아갑니다.
- **가끔 쓰는 것(가게·임무·오락실·도감)** 은 거리 위에 족자 창으로 뜹니다. 닫으면 바로 거리입니다.

## 2. 거리의 건물과 들어가는 곳

| 거리의 것 | 누르면 | 화면 |
|---|---|---|
| 가운데 문 「출격」(지금 구간 표시) | 출격 화면 | D 전체 |
| 하늘의 탑 | 출격 화면 (탑 쪽으로 확대) | D 전체 |
| 정자 (데려온 동료들이 앉아 있음) | 캐릭터·동료 | D 전체 |
| 대장간 (모루, 불꽃) | 장비·겉모습 | D 전체 |
| 복주머니 가게 | 가게 | 족자 창 |
| 게시판 | 오늘의 임무 / 오늘의 탑 / 이번 주의 시련 (기획 8) | 족자 창 |
| 오락실 | 「개장 준비 중」 안내 → 나중에 오락실 허브 (기획 9) | 족자 창 → 전체 |
| 책방 (새로 추가) | 요괴 도감 (기획 8) | 족자 창 |
| 주인공 | 누르면 한마디 (진행·임무에 맞는 대사) | |

## 3. 거리 화면 세부

- **건물은 진행에 따라 하나씩 문을 엽니다.** 기획 1의 "단계적으로 열기"를 거리로 보여 줍니다. 처음엔 문 「출격」만 불이 켜져 있고, 대장간·정자·가게는 덧문이 닫혀 있습니다. 열릴 때 덧문이 열리고 등불이 켜지는 연출을 넣습니다(새 그림 대신 어둡게→밝게 + 반짝임으로도 충분).
- **알림:** 빨간 점 대신 건물 위에 **도깨비불**이 떠서 깜빡입니다(받을 보상, 살 수 있는 동료, 새 임무).
- **간판 글자 크기:** 휴대폰 실제 화면에서 손가락 두 개 이상의 크기. 건물 그림과 간판 둘 다 누를 수 있게 영역을 넓게 잡습니다.
- **주인공:** 고른 캐릭터와 겉모습(기획 4)이 그대로 서 있습니다. 데려온 동료는 정자에 앉아 있어서, 동료가 늘수록 거리가 붐빕니다.
- **시간 변화(나중에):** 깬 층 수에 따라 노을 → 밤 → 보름달로 하늘이 바뀝니다. 배경 그림 3장(`bgS4h` 계열)으로 가능.
- **빠른 출발:** 문 「출격」을 **길게 누르면** 마지막에 한 구간으로 바로 출발합니다(출격 화면을 건너뜀). 익숙한 사람용.

## 4. 화면 전환 연출
1. 건물을 누름 → 0.25초 동안 그 건물 쪽으로 화면이 확대
2. 족자가 가운데서 양옆으로 펼쳐짐(0.3초) → D 화면
3. 「市 장터로」 → 족자가 말리며 거리로 돌아옴
- 전환은 0.6초 이내로 짧게. 설정에 "연출 줄이기"를 두면 바로 넘어갑니다.

## 5. D 화면 공통
- 위: 엽전·달조각(그림 + 숫자), 일시정지·소리
- 아래: 부적 탭 4장 `市 장터로 · 出 출격 · 人 캐릭터 · 裝 장비`. 고른 부적은 들려 올라가며 빛남
- 가운데: 족자(종이) 위에 내용. 글자는 최소 18px(게임 화면 1280 기준)
- 각 화면 내용은 모형 그대로: 출격(탑 + 구간 카드 + 동료 + 구름 출발), 캐릭터(13명 격자 + 능력 그림 막대 + 강화), 장비(몸에 이어진 4칸 + 목록 + 겉모습)

|---|---|---|
| 장터 거리 배경 (가로 넓게) | 메인 | 지금 `bgS4h` 를 써도 되지만, 건물 자리가 정해진 전용 그림이 좋음 |

## 7. Tenkai 방 요청 순서
1. D 화면 3장(출격·캐릭터·장비)과 부적 탭: 기존 기능을 옮기는 작업이라 먼저
2. 거리 화면: 처음엔 `bgS4h` 배경 + 지금 있는 그림(모루, 복주머니, 탑)으로 모형 그대로
3. 가게·임무·오락실·도감 족자 창
4. 건물 단계적 열림, 도깨비불 알림, 전환 연출
5. 거리 전용 그림·건물 그림이 나오면 교체
