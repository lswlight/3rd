# 그믐: 달을 훔친 자 · 기획 21. 협력 업그레이드: 각성 협력 + 인연 단계

사용자 확정(11/23): 협력 업그레이드 제안 4개 중 **① 각성 협력**과 **② 인연 단계 강화**로 진행.
바탕: 기획 17(협력 세 방식·게이지), 기획 18(협력 연출 1.3초), 기획 20(모든 캐릭터 각성 무기).
그림: **새로 그리지 않음**. 각성 일러스트(`aw*`)와 각성 게임 그림(`aw*p`)을 그대로 씀. 크레딧 없음.

---

## 1. 각성 협력

### 1-1. 언제 바뀌나
| 상황 | 협력 종류 | 바뀌는 것 |
|---|---|---|
| 둘 다 평소 | 평소 협력 | 지금과 같음(기획 17·18) |
| 주인공 **또는** 동료가 각성 중 | **각성 협력** | 동료가 각성 모습(`aw*p`)으로 나오고 기술이 각성판으로 바뀜(1-3 표) |
| 주인공 **과** 동료가 **둘 다** 각성 중 | **쌍각성 협력** | 각성 협력 + 특별 컷인 + 마지막 합동 일격(1-4) |

- 동료 각성: 협력 게이지가 가득 찬 상태로 **협력 버튼을 1초 누르고 있으면** 동료가 각성(동료 각성은 판당 1번, 8초). 평소처럼 톡 누르면 평소 협력.
- 주인공 각성 중에 협력을 쓰면 동료는 자동으로 각성 모습으로 나옴(동료 각성 횟수는 쓰지 않음).

### 1-2. 연출 (기획 18의 1.3초 위에 얹음)
| 순간 | 평소 협력 | 각성 협력 |
|---|---|---|
| ① 맞손 컷인 0.5초 | 두 캐릭터 원본 일러스트 대각선 | **각성 일러스트(`aw*`)** 로 바꿈 + 금빛 선이 동료 색으로 타오름 |
| ② 나란히 서기 0.3초 | 동료 원본 게임 그림 | 동료 **각성 게임 그림(`aw*p`)**, 무기 변신 0.3초 섬광 |
| ③ 합동 공격 0.5초 | 두 색 나선 탄 | 동료 **각성 무기 모양 탄**(1-3 표)이 주인공 탄과 꼬여 날아감 |
| ④ 숫자 | 금색 숫자 + 「협력」 | 붉은 금색 숫자 + 「각성 협력」 |
| 세기 | 기준 1 | **2배**(기획 16의 협력 10% → 각성 협력 쓰는 판은 15~18% 목표) |

### 1-3. 동료별 각성 협력 기술
방식(지휘·탑승·수호)과 누르는 법은 그대로, 기술만 각성 무기로 바뀝니다.

| 동료 | 방식 | 평소 협력 | **각성 협력** |
|---|---|---|---|
| 한별 | 지휘 | 회오리 낙하 | **쌍선 회오리**: 정한 자리에 회오리 둘이 위아래로 굴러가며 끌어모은 뒤 바람 일섬 |
| 달래 | 지휘 | 화살비 낙하 | **그림자 쌍검 낙하**: 정한 자리에 진홍 반달 칼바람 X자 6번 |
| 구미호 | 지휘 | 여우불 폭발 | **아홉 꼬리 불기둥**: 정한 자리에 여우불 9개가 모였다가 불기둥 |
| 설녀 | 지휘 | 얼음 지대 | **얼음 낫 지대**: 얼음 지대 + 낫 회전, 끝에 얼음 가시 |
| 쇠 도깨비 | 지휘 | 칼비 낙하 | **쌍망치 내려찍기**: 정한 자리에 불칼 5자루 + 쌍망치 2연 내려찍기 |
| 도깨비 여왕 | 지휘 | 금 방망이 낙하 | **황금 여의봉 뚝딱**: 정한 자리에 여의봉 내려침 + 엽전 폭죽 |
| 직녀 | 지휘 | (기획 17) | **은실 채찍 거미줄**: 정한 자리 적을 은실로 묶고 까치 떼 돌진 |
| 세오녀 | 지휘 | (기획 17) | **해 원반**: 정한 자리에 해 원반이 떨어져 넓게 밝아지며 표식 |
| 처용 | 지휘 | (기획 17) | **처용탈 넷**: 정한 자리 둘레를 탈 넷이 돌며 쏜 뒤 합쳐 폭발 |
| 나린 | 탑승 | 구름 은하수 수레 | **은하 물의 창 수레**: 수레 앞에 물의 창, 박치기할 때마다 물기둥 |
| 탈 도깨비 | 탑승 | 도깨비불 수레 | **불 방망이 수레**: 수레가 지나간 자리에 불길, 끝에 불기둥 |
| 이무기 | 탑승 | 용이 되어 태움 | **번개 여의주 승천**: 용이 위아래 물결로 돌진, 번개 3갈래 |
| 용왕의 장수 | 탑승 | 현무 거북 | **해룡 월도 거북**: 거북 앞에서 월도 물결 베기, 끝에 해일 |
| 산군 | 탑승 | 호랑이 | **범 발톱 질주**: 호랑이 발톱 바람 3줄 + 범 울음(탄 지움) |
| 해태 | 탑승 | (기획 17) | **불꽃 뿔창 돌격**: 불 장막을 끌며 돌진, 끝에 낙인 |
| 장승 자매 | 수호 | 장승 방패 | **쌍기둥 수호**: 장승 기둥 둘이 막고, 반격은 큰 장승 낙하 |
| 불가사리 | 수호 | 쇠 몸으로 막음 | **쇠공 갑주**: 막은 탄을 먹고, 반격은 쇠공 두 개 굴리기 |
| 두억시니 | 수호 | 어둠으로 삼킴 | **검은 달 쌍고리**: 어둠으로 삼키고, 반격은 쌍고리에서 검은 초승달 관통 |
| 우렁각시 | 수호 | 껍데기 | **소라 방패**: 소라 방패가 몸 둘레를 돌며 막고, 반격은 물폭발 |
| 저승사자 | 수호 | 사슬로 묶어 반격 | **명부 낫**: 묶은 뒤 명부 낫 초승달 베기 |
| 바리공주 | 수호 | (기획 17) | **꽃 방울 지팡이**: 막는 동안 생명수로 체력 회복, 반격은 꽃 폭발 |
| 홍길동 | 수호 | 분신으로 받아침 | **구름 검 분신**: 분신 다섯이 받아치고 동시 베기 |
| 강림도령 | 수호 | (기획 17) | **번개 할버드**: 막은 뒤 할버드로 찔러 번개 기둥 |

- 수호형 「완벽 반격」 조건(예고 끝 0.3초)은 그대로. 각성 협력의 완벽 반격은 2배 대신 **3배**.

### 1-4. 쌍각성 협력 (둘 다 각성 중)
- 맞손 컷인 대신 **두 각성 일러스트가 겹치는 특별 컷인 0.8초**: 화면 가운데 금빛 달이 뜨고, 왼쪽 주인공 `aw*` · 오른쪽 동료 `aw*`가 달 앞에서 엇갈림 + 「쌍각성」 붓글씨.
- 협력 기술 뒤에 **합동 일격** 한 번: 두 캐릭터 각성 무기 모양 탄이 하나로 합쳐져 화면을 가로지름(대장 피해 150, 잔챙이 화면 전체).
- 판당 1번만(두 번째부터는 일반 각성 협력).

## 2. 인연 단계 (오래 하는 재미)

### 2-1. 인연은 무엇에 쌓이나
- **주인공(달래·한별·나린)과 동료 한 명의 짝마다** 인연이 따로 쌓임.
- 쌓이는 방법: 그 짝으로 협력 성공 +3, 각성 협력 +6, 쌍각성 협력 +10, 그 짝으로 대장 처치 +15, 정자에서 대화 +1(하루 3번).

### 2-2. 단계와 효과
| 단계 | 필요 인연 | 협력에 생기는 것 | 그 밖 |
|---|---|---|---|
| 1 아는 사이 | 0 | 지금 협력 그대로 | |
| 2 믿는 사이 | 60 | 협력 범위 +20%, 피해 +20%, 게이지 차는 속도 +10% | 정자 인연 대사 1 열림 |
| 3 등 맡기는 사이 | 180 | 협력 끝에 **마무리 일격**(동료 색 큰 일격, 대장 피해 40) | 인연 대사 2, 맞손 컷인에 두 이름 사이 매듭 문양 |
| 4 생사를 함께 | 400 | 각성 협력 세기 2배 → **2.4배**, 동료 각성 지속 8초 → 10초 | 인연 대사 3, 도감에 짝 그림(두 각성 일러스트 나란히) |
| 5 달빛 맹세 | 800 | 쌍각성 협력 판당 1번 → **2번**, 쌍각성 컷인에 붉은 실 연출 | 칭호 「○○의 짝」, 달조각 30 |

- 빠르기 목표: 한 짝만 쓰면 3단계 약 6판, 5단계 약 30판.
- 인연은 떨어지지 않음.

### 2-3. 보이는 곳
| 곳 | 표시 |
|---|---|
| 정자 | 동료 카드에 매듭 1~5개. 누르면 지금 주인공과의 인연 막대 |
| 출전 고르기 | 동료 옆에 매듭 수. 인연 3단계 이상 짝은 금 테두리 |
| 전투 | 협력 버튼 두 얼굴 아이콘 아래 작은 매듭 수 |
| 단계 오름 | 판 끝 결과 화면에서 「인연이 깊어졌다!」 + 두 캐릭터 일러스트 + 새 대사 한 줄 |

### 2-4. 인연 대사 (기획 13a 말투 기준, 단계 2·3·4)
- **작성 완료(11/23)**: 대사집 13a 4번 표, 66짝 × 3줄 = 198줄. 새 캐릭터 10명 말투는 임시.
- 작성 전까지는 공통 대사로 대신: 2단계 「제법이네.」 / 3단계 「등은 내가 맡을게.」 / 4단계 「끝까지 같이 가자.」

## 3. 균형
| 항목 | 목표 |
|---|---|
| 협력 피해 비중 | 평소 판 10%(지금) → 인연 3단계 짝 12%, 각성 협력 쓰는 판 15~18% |
| 쌍각성 협력 | 한 판의 큰 장면 1번. 마지막 대장(10층)은 체력 15% 아래로 깎지 않음(합체 규칙과 같음) |
| 출시판 열기 | 각성 협력 = 각성을 처음 쓴 판부터, 인연 = 협력이 열리는 3층부터. 개발판은 모두 처음부터 |

## 4. 개발 도구
- 개발 도구에 **인연 단계 바꾸기(1~5)**, **동료 각성 무한**, **쌍각성 바로 켜기** 추가(검토용).

## 5. 요청 순서
1. 1-1·1-2 각성 협력 공통(동료 각성 길게 누르기, 각성 그림으로 컷인·나란히 서기, 세기 2배)
2. 1-3 동료별 각성 협력 기술(지휘형 → 탑승형 → 수호형)
3. 1-4 쌍각성 협력(특별 컷인, 합동 일격)
4. 2 인연 단계(쌓기·효과·표시), 공통 대사로 먼저
5. 4 개발 도구, 3 균형 측정(1층 대장 기준 협력 비중)
6. (기획방) 인연 대사 작성 → 13a에 추가
