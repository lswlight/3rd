# 그믐: 달을 훔친 자 · 기획 8. 엔딩 이후 콘텐츠

목표: 10층 첫 엔딩(결제 없이 약 7일) 뒤에도 **새 그림을 거의 그리지 않고** 몇 달 동안 할 거리를 만든다. 지금 있는 대장 10명, 문지기·수문장 50종, 동료 13명, 아케이드 9종을 다시 조합하는 것이 핵심이다.

## 1. 다른 게임 사례에서 가져올 것

| 게임 | 엔딩 이후 장치 | 배울 점 | 주의할 점 |
|---|---|---|---|
| **하데스** (로그라이트 액션) | 첫 탈출 뒤 「형벌의 서약」: 조건을 골라 쌓을수록 「열기」가 오르고, 무기별로 열기에 따라 보상. 조건이 숫자만 올리는 게 아니라 대장전 자체를 바꿈(예: 첫 대장이 셋이 함께 나옴). 개발자는 반복 플레이를 처음부터 최우선 목표로 둠 | 난이도를 **스스로 골라 쌓게** 하고, 캐릭터별로 기록 | 최상단은 개발사도 균형을 안 맞춘 영역이라는 평 → 단계 수를 적당히 |
| **슬레이 더 스파이어** | 「승천」: 20단계, 단계마다 제약이 하나씩 쌓임. 「매일 등반」: 모두 같은 시드에 변수 몇 개, 점수 경쟁 | 하루 한 판 이유(매일 같은 판), 쌓이는 단계 | 숫자만 오르는 단계는 지루하다는 평 → 단계마다 **규칙** 하나씩 |
| **뱀파이어 서바이버즈** | 업적을 깨면 새 무기·캐릭터·맵이 열림. 특정 조건으로 「아르카나」(판을 바꾸는 강화)가 열림. 거꾸로 모드, 도전 맵 | 조건 달성 → 새 강화가 **뽑기 풀에 추가**되는 해금 | 다 열고 나면 동기를 잃는다는 평 → 해금을 천천히 |
| **스카이 포스 리로디드** (슈팅) | 스테이지마다 메달 4개: 무피격, 적 70% 처치, 적 전부 처치, 숨은 사람 구출. 메달이 다음 진행 조건 | 같은 스테이지를 **다른 목표로** 다시 하게 함 | 메달을 진행 조건으로 너무 세게 묶으면 반복이 노동이 됨 |
| **피닉스 2** (모바일 탄막) | 매일 모두 같은 미션, 미션별 순위표, 지난 미션은 순위만 남음 | 매일 같은 판 + 순위표 | 하루 한 판으로 수입을 묶으니 오래 하기 싫어진다는 평 |
| **1945 에어포스** (모바일 비행 슈팅) | 캠페인 외에 대장 모드, 이벤트, 시즌 이벤트, 대전 | 대장만 모은 모드 | 이벤트 해금 대기가 길다는 불만 |
| **탕탕특공대·아처로** (하비) | 설날 등 명절 이벤트, 시련 모드, 패스. 아처로는 첫날 재방문율이 매우 높았지만 수익이 빨리 꺾였다는 분석 | 명절 행사, 단계형 시련 | 이벤트 단계가 너무 많아 번거롭다는 불만. 운영 없이 출시만으로는 오래 못 감 |

정리하면 세 갈래입니다.
1. **매 판이 다르게** (로그라이트 탑)
2. **같은 판을 다른 목표로** (메달, 서약, 매일·매주 도전)
3. **모으는 재미와 이야기** (도감, 동료 이야기, 명절 행사)

## 2. 그믐의 탑 (로그라이트 무한의 탑)

> **결정 (11/19):** Tenkai 방에서 「무한의 탑」 자리에 넣은 **짝 맞추기 카드 게임은 별도 게임으로 유지**합니다(도깨비 오락실의 오락기 하나, 기획 9). 무한의 탑 자리는 아래의 **그믐의 탑(로그라이트 슈팅)** 으로 다시 채웁니다. 카드 게임의 보상(골드, 달조각, 「그믐밤 무희복」 해금 조건)은 그대로 둡니다.

지금의 「무한의 탑」(대장이 정해진 순서로 계속 나옴)을 바꿉니다.

### 2-1. 한 판의 흐름
```
입장: 캐릭터·동료 고르기 (장비·옷은 그대로 적용)
  ↓
1층: 무작위 층의 한 구간 (잔챙이 + 문지기)
  ↓  끝나면 「달빛 축복」 3개 중 1개 고르기
2층: 무작위 구간
  ↓  축복 고르기
3층: 무작위 대장  ← 3층마다 대장
  ↓  축복 고르기 + 휴식(목숨 1 회복 또는 부적 2 중 고르기)
… 같은 방식으로 계속 …
쓰러지면 끝: 오른 층만큼 골드·달조각, 「탑의 기억」 점수
```
- 한 층은 지금 구간 하나(1~2분). 10층이면 15~20분, 한 번 앉아서 하기 좋은 길이입니다.
- 3층마다 대장, 9층마다 **두 대장 연속**. 대장은 열 명 중 무작위로, 같은 판에 겹치지 않게 나옵니다.
- 오를수록 기존 `towerLoop()` 처럼 체력과 탄 속도가 오릅니다.
- 6층마다 아케이드 하나가 무작위로 나오고, 성공하면 축복을 하나 더 고릅니다.

### 2-2. 달빛 축복 (판 안에서만 유지되는 강화)
처음 20개로 시작하고, 「탑의 기억」으로 늘려 갑니다.

| 분류 | 축복 | 효과 |
|---|---|---|
| 공격 | 갈래 하나 더 | 기본 공격 갈래 +1 (최대 2번) |
| | 날 선 탄 | 기본 공격 피해 +20% |
| | 꿰뚫는 기운 | 기본 공격이 적 1명을 관통 |
| | 빠른 손 | 공격 속도 +15% |
| 기 모으기 | 순간 집중 | 기 모으는 시간 -30% |
| | 두 번 터짐 | 모으기 공격이 끝에서 한 번 더 터짐 |
| | 기의 메아리 | 모으기 공격을 쓰면 동료도 모으기 공격 |
| 부적·필살기 | 부적 주머니 | 시작 부적 +1 |
| | 되돌아오는 부적 | 필살기를 쓰고 10초 뒤 부적 1개 회복 (층당 1번) |
| | 긴 필살기 | 필살기 지속 +50% |
| 방어 | 장승의 가호 | 층마다 방패 1 |
| | 아슬아슬 | 탄이 판정 가까이 스치면 기가 조금 참 |
| | 마지막 숨 | 쓰러질 때 1번 버팀 (판당 1번) |
| 동료 | 손발이 맞음 | 동료 지원 사격 2배 |
| | 짧은 교대 | 교대 대기 6초 → 3초 |
| | 교대 충격파 | 교대할 때 충격파 피해 3배 |
| 경제 | 엽전 자석 | 엽전을 멀리서도 끌어옴, 골드 +20% |
| 위험 (강하지만 대가) | 도깨비와의 거래 | 피해 +40%, 대신 목숨 -1 |
| | 그믐의 그림자 | 대장 체력 +25%, 대신 대장 처치 보상 2배 |
| | 맨손 | 부적을 못 씀, 대신 기 모으는 시간 -50% |

- 같은 분류를 몰아 고르면 **조합 보너스**: 예) 기 모으기 축복 3개 → 「기공 달인」: 다 모인 상태를 1초 유지하면 자동 발사.
- 캐릭터에 따라 어울리는 축복이 달라지도록 했습니다. 달래(빠른 손·관통), 무쇠(두 번 터짐), 한별(갈래).
- 화면: 카드 3장이 가로로 뜨고, 카드에는 아이콘(지금 장비 아이콘 그림체), 이름, 한 줄 효과. 고를 때까지 게임 멈춤.

### 2-3. 층 변수 (그 층에만 붙는 규칙)
4층부터 층마다 30% 확률로 하나. 기획 5의 층별 장애물(`w`, `p`, `u`, `f`, `n` 등)을 그대로 씁니다. 보상 축복이 4개 중 고르기로 늘어납니다.

| 변수 | 내용 |
|---|---|
| 그믐밤 | 화면 가장자리가 어두움 |
| 맞바람 | 계속 약한 바람 |
| 성난 문지기 | 문지기가 둘씩 나옴 |
| 빠른 탄 | 적 탄 속도 +25% |
| 황금 층 | 엽전이 3배, 대신 적 체력 +30% |

### 2-4. 탑의 기억 (판이 끝나도 남는 것)
- 오른 층수와 처치 수로 「탑의 기억」 점수를 받습니다.
- 점수로 **새 축복을 뽑기 풀에 추가**하거나(뱀파이어 서바이버즈 방식), 시작할 때 축복 1개를 고르고 들어가는 칸을 엽니다.
- 축복 해금 조건 예시: 「달래로 15층」 → 「백야의 화살」(모으기 화살 5발), 「동료 없이 10층」 → 「외로운 늑대」(동료 없을 때 피해 +30%).
- 최고 층 기록은 기존처럼 5층마다 달조각, 그리고 구글 플레이 게임즈 순위표(4번).

## 3. 그믐의 맹세 (하데스 「서약」, 슬레이 더 스파이어 「승천」 방식)

탑과 일반 층 모두에 쓰는 **스스로 고르는 어려움**입니다. 첫 엔딩 뒤 열립니다.

- 맹세 10가지 중 원하는 만큼 켜고, 켠 맹세마다 「맹세 점수」가 붙습니다.
- 숫자만 올리는 것이 아니라 **규칙이 바뀌는** 맹세를 절반 이상 둡니다.

| 맹세 | 점수 | 내용 |
|---|---|---|
| 단단한 요괴 | 1~3 | 적 체력 +20%씩 |
| 성급한 탄 | 1~2 | 적 탄 속도 +15%씩 |
| 부적 금지 | 2 | 시작 부적 0 |
| 홀로 가는 길 | 2 | 동료 없음 |
| 대장의 분노 | 2 | 대장이 처음부터 2단계로 시작 |
| 두 대장 | 3 | 3구간 대장이 다른 대장과 함께 나옴 (하데스 "세 복수의 여신" 방식) |
| 빈 주머니 | 1 | 엽전이 나오지 않음 |
| 한 번의 목숨 | 3 | 목숨 0으로 시작 |
| 짧은 기 | 1 | 기 모으는 시간 +50% |
| 어두운 하늘 | 2 | 모든 층에 「그믐밤」 |

- 보상: **캐릭터마다** 깬 최고 맹세 점수를 기록합니다. 점수 5·10·15·20에 달조각, 칭호, 의상(기획 4의 3차 의상 o5 「그믐밤 무희복」을 여기로).
- 기존 어려움·악몽은 "맹세 묶음"으로 바꿔 보여 줄 수 있습니다(어려움 = 단단한 요괴 2 + 성급한 탄 1 같은 식).

## 4. 매일·매주 도전과 순위표 (슬레이 더 스파이어 「매일 등반」, 피닉스 2)

| 도전 | 내용 | 보상 |
|---|---|---|
| **오늘의 탑** | 매일 같은 시드: 같은 층 순서, 같은 축복 후보, 같은 변수. 하루 3번까지 도전, 최고 기록만 남음 | 달조각 5~15 (층에 따라) |
| **이번 주의 시련** | 매주 고정 조건 하나. 예: "달래만, 부적 없이 5층", "무쇠로 대장 연전 3분 안에", "동료 설녀 필수, 그믐밤 고정" | 달조각 30 + 칭호 |

- 순위표: 구글 플레이 게임즈 순위표 사용(서버 없이 가능). 오늘의 탑, 이번 주의 시련, 그믐의 탑 최고 층.
- 피닉스 2에서 나온 불만을 피하기 위해 **도전 횟수 제한은 보상에만** 둡니다. 연습 삼아 몇 번이든 할 수 있게 합니다.
- 기존 「오늘의 임무」와 같은 화면(임무 창)에 탭으로 둡니다.

## 5. 구간 메달 (스카이 포스 방식)

지금의 별 3개(안 죽으면 셋)에 **메달 3개**를 더합니다. 같은 구간을 다른 목표로 다시 하게 만듭니다.

| 메달 | 조건 |
|---|---|
| 무피격 | 한 번도 안 맞음 (방패에 막힌 것도 맞은 것으로) |
| 소탕 | 잔챙이를 90% 이상 처치 |
| 구출 | 구간마다 숨어 있는 「갇힌 마을 사람」 1명(초롱 안에 갇혀 날아감)을 맞혀서 구함 |

- 구출 대상 그림 하나(초롱 속 사람)만 새로 그리면 됩니다. 이야기와도 맞습니다(층마다 갇힌 땅의 사람들).
- 메달은 **진행 조건으로 쓰지 않습니다**(스카이 포스에서 반복이 노동이 된다는 평). 모으면 도감·의상·달조각 보상만 줍니다.
- 메달 90개(30구간 × 3) 중 30·60·90개에 보상.

## 6. 요괴 도감과 동료 이야기 (모으는 재미, 글로 만드는 콘텐츠)

### 6-1. 요괴 도감
- 이미 그린 잔챙이·문지기 30·수문장 19·문지기 여성 10·대장 10 = **70종 이상**.
- 처음 잡으면 그림자 → 등록, 10마리·100마리 잡으면 설명 줄이 하나씩 열림.
- 설명은 한국 설화 한 줄 + 게임 속 사연 한 줄. 예) 「메기 요괴 — 큰 메기가 몸을 흔들면 땅이 흔들린다는 옛말. 2층 강나루의 물길을 막고 있었다.」
- 도감 10·30·50·70종 완성에 보상. 아무 데서나 열 수 있는 메뉴(아래 메뉴 줄에 「도감」).

### 6-2. 동료 이야기 (하데스처럼 진행에 따라 열리는 이야기)
- 동료마다 짧은 이야기 3장면(지금 컷인 그림 + 대사 4~6줄).
- 그 동료와 함께 구간 10·30·60번 돌파로 열림.
- 마지막 장면을 보면 그 동료의 「인연 능력」(동료 능력 +20%)이 켜짐.
- 결말의 "사람과 도깨비가 함께 사는 밤"으로 이어지는 뒷이야기라, 엔딩 뒤 이야기 갈증을 채웁니다.

## 7. 대장 연전 (1945 에어포스의 대장 모드)

- 10명의 대장을 **연속으로**. 사이에 휴식 없음, 부적은 대장마다 1개 회복.
- 기록은 시간. 순위표에 올림.
- 처음 깨면 달조각 50과 칭호 「달을 되찾은 자」.
- 만드는 데 드는 것: 기존 대장 패턴 그대로, 연속 등장 흐름만.

## 8. 명절 행사 (탕탕특공대의 명절 이벤트)

이 게임은 **달**이 주제라 명절과 잘 맞습니다.

| 명절 | 행사 | 내용 | 새로 그릴 것 |
|---|---|---|---|

### 지켜볼 숫자
- 처음 받은 사람 중 **다음 날, 7일 뒤, 30일 뒤**에도 들어오는 비율(구글 플레이 콘솔에서 볼 수 있음).
- 첫 엔딩까지 간 비율, 엔딩 뒤 그믐의 탑을 한 번이라도 한 비율.
- 아처로 사례처럼 처음 반응이 좋아도 운영이 없으면 금방 꺾이므로, 출시 뒤 첫 한 달은 **매주 무언가(시련 조건, 작은 수정)** 를 바꿉니다.
