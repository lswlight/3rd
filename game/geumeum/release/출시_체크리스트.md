## 3. PC에서 앱 만들기 (출시가이드 1~3단계)
- [ ] Node.js, Android Studio 설치
- [ ] `npm install` 명령들, `cordova-plugin-purchase` 설치, `npx cap add android`, `npx cap sync android`
- [ ] 가로 고정(AndroidManifest), MainActivity.java 덮어쓰기, 앱 아이콘 넣기
- [ ] `android/app/build.gradle`에서 versionCode 1, versionName "1.0.0" 확인
- [ ] **Android 16(API 36) 대상 필수** (2026년 8월 31일부터 새 앱 조건): `android/variables.gradle` 의 compileSdkVersion·targetSdkVersion 이 36인지 확인. Capacitor 는 최신 버전(8 이상)을 설치
