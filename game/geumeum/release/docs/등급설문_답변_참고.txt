플레이 콘솔 '콘텐츠 등급' 설문(IARC) 답변 참고
※ 아래는 현재 게임 내용을 바탕으로 한 참고안입니다. 질문 문구는 바뀔 수 있으니, 실제 화면의 질문을 읽고 사실대로 답하세요.

- 카테고리: 게임
- 폭력: 예 — 판타지 캐릭터(도깨비·요괴)를 탄으로 쓰러뜨리는 만화풍 폭력. 피나 신체 훼손 표현 없음. 사람(현실적인 인간)을 해치는 장면 없음.
- 성적인 내용/노출: 예 — 일부 여성 캐릭터가 수영복 수준의 노출 의상을 입음. 성행위·나체 표현 없음.
- 언어: 거친 말 없음
- 약물·술·담배: 없음 (3층 문지기 '담뱃대 두꺼비'는 현재 다른 캐릭터로 교체되어 게임에 나오지 않음)
- 도박: 실제 돈을 거는 도박 없음. 장터의 '복주머니', 용궁 '보물 상자'는 게임 안에서 번 골드로 받는 무작위 보상이며 현금 구매 불가.
- 이용자 간 소통·개인정보 공유: 없음
- 위치 정보: 사용하지 않음
- 디지털 상품 구매: 예 — 게임 안 화폐(달조각)를 실제 돈으로 살 수 있음
- 무작위 아이템(뽑기·확률형 상품)을 돈으로 사는가: 아니요 — 모든 유료 상품은 내용이 정해져 있음
→ 예상 등급: 12세 또는 15세 이용가 (노출 의상 항목에 따라 달라짐)

'데이터 보안' 양식
- 수집하거나 공유하는 데이터: '구매 내역(앱 내 구매)' 항목은 Google Play 결제 과정에서 처리됨.
  개발자 서버로 보내는 데이터는 없음. 거래 번호는 중복 지급을 막으려고 기기에만 저장함.
  → 양식에서 '구매 내역'을 '수집함 / 앱 기능 / 기기 밖으로 전송 안 함(공유 안 함)'으로 답하는 것을 권장.
    정확한 기준은 양식의 설명을 읽고 사실대로 고르세요.
- 게임 기록은 기기에만 저장됨
- 데이터 암호화(전송 중): 개발자 서버로 보내는 데이터가 없으므로 해당 없음
- 데이터 삭제 요청: 앱을 삭제하면 모든 기록이 지워짐
