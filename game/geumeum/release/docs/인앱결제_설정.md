# 인앱 결제(달조각) 설정 방법

게임 코드에는 결제 연결이 이미 들어 있습니다. 앱에서 실행하면 구글 플레이 결제 창이 뜨고,
웹(개발용 페이지)에서는 '시험 결제' 창이 떠서 실제 돈 없이 달조각만 들어옵니다.

## 1. 플레이 콘솔에 상품 만들기
플레이 콘솔 → 앱 선택 → 수익 창출 → 제품 → **인앱 상품** → 상품 만들기.
아래 **상품 ID를 글자 하나 틀리지 않고** 그대로 만드세요. (ID는 나중에 바꿀 수 없습니다)

| 상품 ID | 이름 | 내용 | 가격(예시) |
|---|---|---|---|
| `moon_60` | 달조각 한 줌 | 달조각 60 | 1,200원 |
| `moon_330` | 달조각 주머니 | 달조각 330 + 덤 30 | 5,900원 |
| `moon_700` | 달조각 상자 | 달조각 700 + 덤 100 | 12,000원 |
| `moon_1500` | 달조각 궤짝 | 달조각 1,500 + 덤 300 | 25,000원 |
| `starter_pack` | 첫 구매 묶음 | 달조각 300 + 은비녀 창(희귀 무기), 한 번만 | 2,500원 |

- 가격은 예시입니다. 콘솔에서 바꾸면 게임 상점에도 콘솔 가격이 그대로 나옵니다.
- 상품을 만든 뒤 **활성화**를 눌러야 앱에서 보입니다.
- 인앱 상품은 결제 프로필(판매자 계정)을 만들어야 등록할 수 있습니다. 판매 수익을 받을 계좌와 사업자 정보가 필요할 수 있습니다.

## 2. 결제 부품 설치
```
npm install cordova-plugin-purchase
npx cap sync android
```
게임은 `window.CdvPurchase`가 있으면 앱 결제를, 없으면 시험 결제를 씁니다. 따로 코드를 고칠 필요는 없습니다.

## 3. 시험하기
1. 플레이 콘솔 → 설정 → **라이선스 테스트**에 본인 구글 계정을 넣습니다. (실제 돈이 나가지 않는 시험 카드가 생깁니다)
2. 앱을 **내부 테스트** 트랙에 올리고, 같은 계정으로 휴대폰에서 설치합니다. (USB로 바로 설치한 앱에서는 결제가 안 될 수 있습니다)
3. 상점 → 달조각 → 상품을 눌러 결제 창이 뜨고, 달조각이 들어오는지 확인합니다.

## 4. 알아둘 점
- **기록은 기기에만 저장됩니다.** 앱을 지우면 산 달조각도 사라집니다. 이용자가 많아지면 서버 저장(예: Firebase)을 붙이는 것을 권장합니다.
- 기기 안 저장은 고치기(해킹)가 가능합니다. 지금 단계에서는 감수하고, 매출이 생기면 서버 영수증 확인을 붙이세요.
- 같은 결제가 두 번 들어오지 않도록 거래 번호를 기기에 적어 둡니다.
- 게임 안 상점에 환불 안내가 있고, 스토어 설명에 "유료 아이템 판매"가 적혀 있습니다. `docs/환불_안내.txt`의 연락처를 채우세요.
- 뽑기(확률형) 상품은 없습니다. 나중에 넣는다면 확률 공개 의무가 생깁니다.
