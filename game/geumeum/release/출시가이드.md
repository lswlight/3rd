# 그믐: 달을 훔친 자 — 안드로이드 출시 가이드

이 묶음은 플레이스토어에 올릴 **출시판**입니다. 개발용 페이지와 달리 캐릭터와 구간이 잠긴 상태로 시작합니다.

## 묶음 안의 파일
| 파일 | 내용 |
|---|---|
| `www/` | 게임 본체 (index.html + 그림·영상) |
| `capacitor.config.json` | 앱 이름과 앱 ID 설정 |
| `android_patch/MainActivity.java` | 전체 화면, 컷인 영상 자동 재생 설정 |
| `docs/개인정보처리방침.html` | 스토어에 링크해야 하는 문서 (빈칸을 채워서 웹에 올리기) |
| `docs/스토어_소개글.txt` | 스토어 이름·설명 문구 |
| `docs/등급설문_답변_참고.txt` | 등급 설문과 데이터 보안 양식 참고 답변 |
| `docs/인앱결제_설정.md` | 달조각 상품 등록과 결제 연결 방법 |
| `docs/환불_안내.txt` | 게임 안·스토어에 적을 환불 안내 문구 |

스토어 그림(아이콘, 대표 이미지, 스크린샷)은 따로 보낸 `store_assets` 묶음에 있습니다.

## 1단계. PC 준비 (한 번만)
1. **Node.js** 설치 (공식 사이트의 LTS 버전)
2. **Android Studio** 설치 (설치하면서 Android SDK도 함께 설치)
3. 글꼴은 게임 안에 이미 들어 있습니다(무료 공개 글꼴, 라이선스 파일: www/assets/fonts/OFL-*.txt). 따로 받을 필요가 없습니다.

## 2단계. 앱 프로젝트 만들기
이 묶음을 푼 폴더에서 명령 창(터미널)을 열고 차례로 입력합니다.
```
npm init -y
npm install @capacitor/core@latest @capacitor/cli@latest @capacitor/android@latest
npm install cordova-plugin-purchase
npx cap add android
npx cap sync android
```
- `capacitor.config.json`의 `appId`(com.graftkorea.geumeum)는 **스토어에 한 번 올리면 바꿀 수 없습니다.** 원하는 주소로 먼저 바꾸세요. (예: com.회사도메인.geumeum)
- `cordova-plugin-purchase`는 구글 플레이 결제를 붙이는 부품입니다. 설치 뒤 `npx cap sync android`를 한 번 더 실행하세요. 자세한 내용은 `docs/인앱결제_설정.md`.

## 3단계. 안드로이드 설정 세 가지
1. **가로 고정**: `android/app/src/main/AndroidManifest.xml`의 `<activity` 줄에 다음을 추가
   `android:screenOrientation="sensorLandscape"`
2. **전체 화면 + 영상 재생**: `android_patch/MainActivity.java` 내용을
   `android/app/src/main/java/(앱 ID 경로)/MainActivity.java`에 덮어쓰기. 첫 줄 `package`를 앱 ID와 같게 맞추기.
3. **앱 아이콘**: Android Studio에서 `app` 폴더 오른쪽 클릭 → New → Image Asset → `icon_A_512x512.png` 선택

## 4단계. 휴대폰에서 시험
```
npx cap open android
```
Android Studio가 열리면 휴대폰을 USB로 연결(휴대폰 '개발자 옵션 → USB 디버깅' 켜기)하고 ▶ 실행.
**꼭 확인할 것**: 소리, 끊김, 필살기 컷인 영상, 저장(앱을 껐다 켜도 골드가 남는지), 가로 화면.

## 5단계. 출시 파일(.aab) 만들기
Android Studio → Build → Generate Signed App Bundle / APK → Android App Bundle
- 처음이면 **업로드 키**를 새로 만듭니다. 키 파일(.jks)과 비밀번호는 **절대 잃어버리면 안 됩니다.** 두 곳 이상에 보관하세요.
- 결과물: `app-release.aab`

## 6단계. 플레이 콘솔 등록
1. 개발자 계정: 자동가계부 때 만든 GRAFT 조직 계정(graftkorea)을 그대로 씁니다
2. 앱 만들기 → 이름, 기본 언어(한국어), 게임, 무료 (무료 앱 안에 인앱 상품이 있는 형태)
3. 스토어 등록정보: `docs/스토어_소개글.txt` + store_assets 그림
4. 개인정보처리방침: `docs/개인정보처리방침.html`의 빈칸을 채워 웹에 올리고 그 주소 입력
   (회사 홈페이지 graftkorea.com 아래에 올리면 됩니다. 예: https://graftkorea.com/geumeum/privacy)
5. 콘텐츠 등급 설문, 데이터 보안 양식: `docs/등급설문_답변_참고.txt` 참고 (인앱 구매 '있음'으로 답하기)
6. **인앱 상품 등록**: `docs/인앱결제_설정.md`의 상품 ID 다섯 개를 그대로 만들기. 인앱 상품은 결제 프로필(판매자 계정)을 만든 뒤에 등록할 수 있습니다.
7. 대상 연령: 18세 이상 또는 16세 이상 권장 (노출 의상이 있으므로 아동 대상으로 고르지 않기)
8. **테스트**: GRAFT 조직 계정이라 개인 계정의 '12명 × 14일 비공개 테스트' 조건은 없습니다. 내부 테스트로 결제까지 확인한 뒤 바로 프로덕션을 신청합니다.
9. 테스트를 마치면 '프로덕션'으로 출시 신청 → 심사

## 업데이트할 때
게임을 고치면 `www/`만 새 파일로 바꾸고
```
npx cap sync android
```
그다음 `android/app/build.gradle`의 `versionCode`를 1 올리고(`versionName`도 함께), 5단계부터 다시 하면 됩니다.

## 출시판에서 꺼 둔 것 / 바뀌는 것
- 결제: 웹(개발용 페이지)에서는 '시험 결제' 창이 뜨고 실제 돈이 나가지 않습니다. 앱에서는 구글 플레이 결제 창이 뜹니다.
- 시험용 전체 해금 (캐릭터·구간이 잠긴 상태로 시작)
- 유도탄
- 화면 아래 조작 안내 글 (게임 안 도움말은 그대로)
