# 코드 나누기 계획 (기획 9의 5번) — 구성안만, 아직 옮기지 않음

지금 게임은 `dokkaebi-shooter.html` 한 파일(약 2,700줄, CSS 약 310줄 + 스크립트 약 2,150줄)입니다.
오락기를 늘리기 전에 아래처럼 나눕니다. **게임 동작은 바꾸지 않는 정리 작업**이고, 끝나면 슈팅이 지금과 똑같이 되는지(지금 쓰는 시험 스크립트 전부) 먼저 확인합니다.

## 2. 나누는 방식
- **빌드 도구 없이** 일반 `<script src>` 여러 개를 순서대로 불러옵니다(지금처럼 전역 변수 사용). 출시판 만들기(`build_release.py`)에서 하나로 합쳐 `release/www/index.html` 에 넣으면 앱에서도 파일 하나라 지금과 같습니다.
- 오락기 사이의 경계는 `core` 가 제공하는 몇 개 함수(`addGold`, `SAVE`, `look`, `sfx`, `toast`, 입력 상태)로만 넘나들게 합니다. 슈팅 전용 전역(`G`, `P`, `enemies` 등)은 `games/shooter` 안에서만 씁니다.
- 저장: `SAVE` 를 처음 읽을 때 `SAVE.games` 가 없으면 지금 값을 `SAVE.games.shooter` 로 옮기고, 화폐·의상·동료처럼 공통인 것은 바깥에 둡니다.

## 3. 순서 (출시 뒤)
1. CSS 4개 파일로 나누기 → 화면 캡처 비교
2. `core/` 로 소리·그림·입력·저장 옮기기 → 시험 스크립트 전부 통과
3. 상점·장비·로비 옮기기 → 시험 통과
4. 슈팅 본체를 `games/shooter/` 로 → 시험 통과, 검토용 APK로 손맛 확인
5. `build_release.py` 를 "여러 파일 → 하나로 합치기"로 바꾸기
